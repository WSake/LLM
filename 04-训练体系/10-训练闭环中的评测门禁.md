## 0. 为什么需要"评测门禁"：训练 loss 是最会骗人的仪表

09 章讲完"训练怎么跑得稳"：显存算得清、崩溃续得上、loss 读得懂。但"跑得稳"和"跑得对"是两码事——**训练 loss 是最会骗人的仪表**：它只告诉你"模型对这堆 token 的拟合在变好"，不告诉你"拟合的是真规律还是背例题"。知识地图 §4.10 把这件事钉成一句话：

> 训练循环里要有"评测门禁"：预训练看 PPL + 少量下游抽样；SFT/RL 后跑全量精选集（能力回归 + 上线导向集）。

然后是更扎心的三条失败模式（§4.10 原话）：

> **训练失败模式：loss 降但能力跌（数据污染/过度训练）；SFT 后通用能力崩（遗忘，需回放）；RL 后格式崩（奖励黑客）。**

这三条有一个共同点：**单看训练 loss 一条都发现不了**——前两条训练 loss 还都降得挺漂亮，第三条 loss 也在目标方向上狂降。它们栽都栽在"评测"这一环：不看评测＝失明；看错评测＝近视；没有门禁＝有眼睛但只看课后报告。所以评测在训练闭环里不是"期末考试"而是"过闸检查"，本篇要教的就是把三扇闸教出来。

> 一句话（为什么有本篇）：**训练 loss 测的是"拟合"，评测门禁测的是"能力与真伪"。09 章保证训练跑得稳，本篇保证训练跑得对——三扇闸，一把一个失败模式。**

## 1. 一站全景：门禁的四角色与三扇闸

"评测门禁"拆开是两个词：**评测集怎么划**（四个角色），**评测分数怎么用**（三道闸）。§4.10 的原话已经把四角色写在里面了：

| 评测集角色 | 干什么 | 何时用 |
|---|---|---|
| **dev 评测** | 预训练看 PPL + 早停点 | 训练中每 k 步（本篇 [A]） |
| **regression 回归集** | SFT/RL 后的能力回归、防遗忘 | 阶段切换时全量跑（本篇 [B]） |
| **hold-back 审计集** | 防评测泄漏、验证分数真假 | 周期性抽查（本篇 [C]） |
| **train** | 训练本身（它不是评测，但经常被误当评测） | — |

为什么必须是这四份而不是一份？因为三扇闸读的是**三种不同的信号**，混在一起就报警失败：

1. **过拟合**：train CE 一路降，dev-PPL 过了拐点开始升——信号是"train 与 dev 的分道扬镳"。只有 dev 这份"同源但未见"的数据能测它（A 段）。
2. **遗忘**：换新语料续训，新句 loss 降得欢，但旧能力回归集逐句失忆——信号是"旧能力逐点下跌"，只有 regression 集能测它（B 段）。
3. **泄漏污染**：评测集混进了训练见过的句子，分数虚好——信号是"评测曲线健康但 hold-back 全新句没变好"。只有 hold-back 这份"永不进训练"的审计集能揭穿它（C 段）。

三扇闸触发后要干的事也明确：**未创新低 → 早停 + 回滚 best；跌破阈值 → 回滚 + 重放/重配比；泄漏审计失败 → 重出评测集**。评测不是看了然后点点头，是看完要办事。

> 一句话（全景）：**门禁 = 四份评测集的三重分工 + 分数跌破线就动真格的触发动作。评测没给训练流程带来"停/滚/换"的后果，它就只是又一张事后报告。**

## 2. 怎么构造：四段可重算的跑

真实训练的评测门禁要在多卡集群上训几十亿参数——本篇不做，把"门禁纪律"做成一次诚实的本机小跑（`eval_gate_demo.py`，torch CPU 单线程、固定 seed、GRU-48 小字符语言模型），四段各钉一个数字：

- **A 认证门禁（本机真跑）**：同一条"南极洲 + 极地动物"主题拆成 train 8 句 / dev 6 句——dev 句绝不进训练，且刻意与 train 共享 39/52 个字（75%），**模拟真实预训练里 train/dev 同源抽样**。逐步量 dev-PPL，看它怎么"先降后升"，并让门禁**真的执行早停 + 回滚**。
- **B 回归门禁（本机真跑）**：先用 8 句旧事实句把模型训到"背对"（回归分 8/8），再换成 8 句新事实句续训，逐 8 步给旧能力算回归分——看新句 loss 一路降的同时旧能力怎么一路失忆，门禁在"连续 2 次跌破 4/8"时**真的触发回滚**。
- **C 泄漏门禁（本机真跑）**：两臂对照——干净臂训 16 句 / 泄漏臂把评测集 4 句里的 2 句塞进训练，各训 120 步，看"泄漏臂评测分虚低 vs hold-back 全新句无差"的假健康物证。
- **D 门禁规范表（规则）**：四划分、频率纪律、触发动作、三条失败模式各自的闸（含 RL 后格式门禁——奖励黑客）。

> 一句话（构造选择）：**这章把"门禁"做成你能亲手改的三段小实验——A/B/C 是本机真跑（科学数字三遍逐位一致），D 是规则表（标非本机实测）。三段的真相都指向同一个结论：分数的诚实性取决于评测集与你见过的东西有没有重叠。**

## 3. A 段 认证门禁：dev-PPL 过拟合拐点与早停回滚

§4.10 说预训练"看 PPL"——PPL = `exp(平均 cross-entropy)`，初值 ≈ 词表大小（模型随机猜），越训越低代表越会"像中文一样"续写。A 段真跑的曲线长这样（`eval_gate_demo.py` A 段）：

```text
[A] 认证门禁（预训练 dev-PPL 闸，本机真跑）：train 8 句 / dev 6 句（同源同主题两笔）
    语料：同一条'南极洲+极地动物'主题拆两份——train 8 句 / dev 6 句未见于训练；dev 共 52 个不同字、与 train 共享 39 个（75%），刻意模拟真实预训练的'train/dev 同源抽样'
    训练口径：V=249 · GRU-48 · lr=3e-3 · 每步过全集合 · 逐 8 步评测
    step  训练CE  dev-PPL
       0  5.5083   260.06
       8  4.9504   191.13
      16  4.1616   126.44
      24  3.4222   105.11
      32  2.7145    79.68
      40  2.1333    63.87
      48  1.6270    57.89
      56  1.2086    54.62
      64  0.8840    51.56   ← 过拟合拐点(best)
      72  0.6544    52.06
      80  0.4980    54.73
      88  0.3923    57.72   ← 门禁执行:早停+回滚(best@step64)
    → dev-PPL 先降后升：best 在 step 64（dev CE 3.9427 ≈ PPL 51.6），训练 CE 却一路降着——train 在'变好'，dev 在'变差' = 过拟合已开始
    → 门禁动作：连续 3 次未创新低 → 在 step 88 早停并回滚到 best 步的参数（这 24 步训下来 dev 不仅没创新低、还亏了 +0.1129；照默认计划继续训到 step 216，dev-PPL 只会顺着拐头更差）
```

三个读数：

1. **dev-PPL 是"先降后升"，不是单调降**：260 → 191 → 126 → 80 → 64 → 58 → 54 → **51.6（step 64）** → 52 → 55 → 57.7。前 64 步模型在学语言统计（"南极 / 冰盖 / 企鹅 / 是…的"这些同源共享的东西，dev 也受益）；step 64 之后，继续训的全是"背 train 那 8 句的精确序列"——dev 再也拿不到一点好处，反而因为概率质量被 train 特有的 n-gram 吸走而回升。**这就是过拟合拐点：dev 见顶那一刻，往后每一步都在为"记住训练集"付费。**
2. **门禁的动作 = 未创新低连续 N 次就早停 + 回滚**：step 72/80/88 连续三次都没能低于 51.6，"连续 3 次未创新低"触发——早停在 step 88，把参数回滚到 best@step 64。这 24 步训下来的净效果是 dev-CE 还亏了 **+0.1129**：回滚不只是"止损"，是把这 24 步直接从账本上划掉。对照"没有门禁、闭眼训满 216 步"，dev-PPL 只会顺着拐头继续涨，而训练 loss 照降不误——**你不看 dev，训练 loss 会一直说"我很健康"。**
3. **同源 dev 是这份曲线的前提**：dev 句与 train 共享 39/52 个字（75%），正是这份重叠让模型"能且只能"把泛化学到 dev 上也受益——如果 dev 全是 train 没见过的字，曲线会像 260 一路涨（那个形态也有用，但你没有'dip'可以当拐点）。真实预训练一样：dev 就是从同分布语料里留出的子集，所以它早期受益、后期背叛，形状一致。

> 一句话（A 段）：**预训练的评测门禁 = 盯 dev-PPL 的拐点而不是盯 train 的降。train CE 5.51→0.39 一路漂亮，dev-PPL 却在 51.6 见顶后回到 57.7——门禁在"连续 3 次未创新低"的 step 88 早停回滚，把纯属背诵的 24 步从账上划掉。**

## 4. B 段 回归门禁：遗忘曲线与回滚点

SFT/RL 阶段的评测对象不是字符 PPL，是**能力**。§4.10 点名的第二条失败模式——"SFT 后通用能力崩（遗忘，需回放）"——用 B 段把它拍成一条遗忘曲线。做法：先用 8 句旧事实句把模型训到"背对"，再换 8 句新事实句续训，逐 8 步给旧能力算**回归分**（回归分 = 8 句里 still next-char 命中率 ≥0.7 的句数）：

```text
[B] 回归门禁（遗忘闸，本机真跑）：旧能 8 句先训到背熟 → 换新能 8 句续训，旧能回归集逐点跌
    阶段一：训旧能 8 句 96 步 → 旧能回归分 8/8（回归分 = next-char 命中率≥0.7 的句子数）
    阶段二：换新能 8 句续训，每 8 步记录 新句CE 与 旧能回归分（回归门禁逐点读数）
    step  新句CE  旧能回归
       0  7.5697   8/8
       8  5.1556   8/8
     ...
      64  0.3829   7/8
      72  0.2595   7/8   ← 回滚点（旧能仍 ≥6 且新句 CE 最低）
      80  0.1866   5/8
      96  0.1082   4/8
     104  0.0852   4/8   ← 门禁触发（连续 2 次 ≤4/8）
     ...
     136  0.0384   3/8
     160  0.0244   2/8
     ...
     288  0.0060   2/8
    → 门禁规则：旧能回归分连续 2 次 ≤4/8 → 触发。实测触发步 step 104（旧能 4/8 · 新句 0.0852）
    → 回滚点 = 旧能仍≥6 且新句 CE 最低的 step 72（旧能 7/8 · 新句 0.2595）——停回这类点，'旧能用'和'新句已学'两头都保住
    → 放任从 step 72 硬训到 step 288：旧能 7/8 → 2/8（丢 5/8），新句 CE 0.2595 → 0.0060——为了深训这最后 ~0.253 的 CE 进度，旧能掉了 5/8。
      回归门禁拦的就是这笔账：触发即回滚，再用重放/重新配比在保住旧能的前提下把新句重新练上。
```

三个读数：

1. **新句 loss 和旧能力是两根不同的曲线**：新句 CE 从 7.57 一路降到 0.006，看起来整个训练"一帆风顺、还能更好"；但同一时刻旧能回归分 8/8 → 5/8（step 80）→ 4/8（step 96）→ 2/8（step 160）——**模型在把学旧事实的权重改写成学新事实，旧能力回不来了**。只盯新句 loss，你永远不会在 step 104 停下来。
2. **门禁的触发条件把事情变成"可执行"**："连续 2 次 ≤4/8"在 step 104 触发（step 96 已经 4/8 但在等确认）。触发一瞬间，**回滚点**由规则自动选出：旧能仍 ≥6 且新句 CE 最低的 step 72（回归 7/8 · 新句 0.2595）——它是"旧能用 + 新句也学了点"的最后一个可接受存档。算法上这条规则就是：**每次评测时若回归达标且新句更好，就更新"回滚候选"**，触发时切回去。
3. **放任的账本被钉死了**：从 step 72 硬训到 288，旧能 7/8 → 2/8（丢 5/8），换来的新句 CE 只是 0.2595 → 0.0060——为了深训最后这 ~0.253 的 CE 进度，旧能力折掉 5/8。回归门禁拦的就是这笔账：触发即回滚，再用**重放**（把旧能样本重新掺进下一轮）或**重新配比**（旧/新数据按比例混）把旧能力保住的前提下重练新句。"需回放"三个字，说的就是这一步。

> 一句话（B 段）：**SFT/RL 的评测门禁不看你新任务的 loss，看旧能力的回归分——它 8/8 一路掉到 4/8，正是门禁在 step 104 触发、把你送回 step 72 的信号；放任多训，5/8 的旧能力就为 0.25 的 CE 进度陪葬了。**

## 5. C 段 泄漏门禁：假健康与 hold-back 揭穿

§4.10 的第三条组合拳是"数据污染/过度训练 → loss 降但能力跌"。污染你的不一定是脏数据，还有可能是**评测集本身**：把评测句混进训练，是最隐蔽的翻车方式——训练 loss 降、评测 score 涨、天下太平，直到上线。C 段用两臂对照把它拍成物证（干净臂训 16 句；泄漏臂在同样 16 句基础上把评测集 4 句里的 2 句也塞进训练，同步数 120 步）：

```text
[C] 泄漏门禁（假健康闸，本机真跑）：评测 4 句里的 2 句塞进训练集（泄漏臂）vs 干净臂，同训练步数
    训练：干净臂 16 句 / 泄漏臂 16+2 句（评测集里塞进「长颈鹿靠心脏泵血供脑部」「月亮绕地球运行一周大约一个月」）× 120 步
    评测对象 →       干净臂    泄漏臂    Δ（泄漏−干净）
    评测集 4 句      7.3496  3.7974   -3.5522
      ↳ 泄漏的 2 句  7.1303  0.2096   -6.9207
      ↳ 没泄漏的 2 句 7.5598  7.2357   -0.3241
    hold-back 4 句   7.2199  7.1893   -0.0306
    → 泄漏臂的『评测分数』看着好了 3.5522——正是塞进去那 2 句被背出来的假健康；但 hold-back 全新句上两臂只差 0.0306，泄漏没带来真本事，只撬开了评测锁。
```

三个读数：

1. **泄漏臂"评测分数"确实更好看，好 3.55**：评测集 4 句上，泄漏臂 3.80 vs 干净臂 7.35——只看评测总分，你会以为"加了数据之后模型变强了 3.55"。**这就是数据污染的第一个症状：分数虚高。**
2. **拆开看，好处全在"背出来的那 2 句"**：泄漏的 2 句上两臂差 **-6.92**（泄漏臂 0.21 ≈ 背熟了），没泄漏的 2 句只差 -0.32——**泄漏的收益 100% 来自被背过的例句，没被塞进训练的那 2 句根本不沾光**。评测总分（-3.55）几乎全部是被污染句子贡献的。
3. **hold-back 审计集把假健康一锤敲碎**：全新 4 句（「盐湖里的盐分来自上游岩石」等）上，两臂只差 **0.0310**——泄漏臂对这 4 句的预测能力和干净臂几乎一样，因为它没在这 4 句上学到任何真本事。**这就是为什么评测集外面还要留一份永不进训练的 hold-back：它专门回答"我的分数是学来的还是背来的"。**真实训练里，评测分数漂亮 + hold-back 不涨，第一反应就是查评测集有没有泄漏、数据管线有没有把评测集混进训练。

> 一句话（C 段）：**评测泄漏最难防，因为它的分数是"假健康"——泄漏臂在评测集上好了 3.55，但 hold-back 全新句只差 0.0310：分数涨的是被背的例句，能力一文没涨。hold-back 审计集就是这份假健康的照妖镜。**

## 6. D 段 门禁规范表：四件套与触发动作

前三段给了三份真跑物证，D 段把它们收束成一张可照做的规范表（规则，账算非实测）：

1. **评测集四划分**：`train`（训练）/ `dev`（早停·调超参·看 PPL）/ `regression`（能力回归，SFT·RL 后全量跑）/ `hold-back`（污染审计，永不进任何训练）。四份缺一不可——缺 dev 没有过拟合拐点、缺 regression 没有遗忘曲线、缺 hold-back 没有假健康审计。
2. **频率纪律**：warmup 内豁免评测（早期 loss 还没成型，测了全是噪音）；其后每 k 步用**固定同一份同种子子样本**评测——跨运行、跨检查点才有可比性，今天 1 万个样本明天 10 万个样本的"评测"没法做门禁。
3. **触发动作**：评测连续 N 次未创新低 → 早停 + 回滚 best（[A]）；回归分跌破阈值 → 停/回滚 + 重放（[B]）；泄漏审计不过 → 重出评测集、查数据管线（[C]）。**没有触发动作的评测只是记录，不是门禁。**
4. **三条失败模式各自的门禁**：过拟合 = dev 评测见顶（[A]）；遗忘 = 回归集能力跌（[B]）；假健康 = 评测泄漏（[C]）。剩下第 4 条 §4.10 点名的——**RL 后格式崩（奖励黑客）**：RL 直接把"输出格式合规率"当奖励拿命优化时，模型会滑向"格式很对、内容弱智"。它对应的门禁是**格式 + 非格式混合回归集**：格式合规率猛涨但能力分崩了，就是奖励黑客警报，触发即回退策略并重查奖励设计。

行业实践（非本机实测）核对一遍：预训练每万步打 PPL + 少量下游抽样；SFT/RL 后跑全量精选回归集（能力回归 + 上线导向集）；用 W&B/MLflow 记录评测曲线与每次触发，门禁是训练日志里的第一优先事件。

> 一句话（D 段）：**规范表 = 四份评测集各管一个信号 + 四类触发动作各停一种病。评测不是"看看分数"，是"跌破线就停、就滚、就换"的制度化动作。**

## 7. 常见坑

**① 拿 train loss 当评测。**
[A] 段最直接的教训：train CE 5.51 → 0.39 一路漂亮，dev-PPL 却在 step 64 见顶、之后越训越差。训练 loss 度量"拟合"，评测分数度量"泛化 + 能力"，两者分道扬镳就是过拟合的启动式。

**② 评测集只有 dev，没有 regression，也没有 hold-back。**
dev 管过拟合、regression 管遗忘、hold-back 管泄漏——只留 dev 的团队，在"换语料续训"（[B]）和"评测集污染"（[C]）时直接失明。四份是一个体系，不是三选一。

**③ 把"评测分数涨"当成"能力涨"。**
[C] 段就是反例：泄漏臂评测分好了 3.55，hold-back 却只差 0.0310。分数的两位背后可能是背例题，也可能是新能力——只有 hold-back/全新样本能分辨。

**④ 评测频率/子样本每次不一样。**
门禁要的是"同一条尺子重复量"：固定 seed、固定子样本、固定评测时点。今天 10k、明天 100k 样本的分数连起来，涨跌全是样本量造成的假信号。

**⑤ 评测了，但不设触发动作。**
只记录分数、不设"跌破线就回滚"的机制，等于把评测当记账本。§4.10 要的是 gate：连续未创新低 → 早停回滚（[A]），回归破阈值 → 回滚 + 重放（[B]）。

**⑥ 只在 RL 里看格式合规率，不看内容能力。**
格式从 60% 冲到 100% 让你以为 RL 大获全胜——再看能力回归，崩了。奖励黑客的门禁是"格式 + 非格式混合回归集"，两个分数都要挂。
