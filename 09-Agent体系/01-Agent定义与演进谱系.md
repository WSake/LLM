## 0. 为什么第 1 课是「定义与演进谱系」？

9 章后面还有 12+ 篇要写：Planning、ReAct、记忆分层、工具与 MCP、反思、多智能体、Computer Use、浏览器 Agent、Coding Agent、评测、安全、生态趋势——它们**没有一篇在回答「Agent 是什么」**，全是在 Loop 的某个环节上加料。地图 §9.2 的诫命是「**先画 Loop 再谈一切**」，而画 Loop 之前必须先画一张更大的图：**这个系统到底算不算 Agent、算哪一档的 Agent**。

> 章末成篇后，本课的头号作用是当「定位器」：09-04 讲 ReAct 时你说「这是最简洁的 Agent」，09-08 讲 Multi-Agent 时你说「这是 Agent 的协作版」，09-12 讲评测时你说「不评测的不是 Agentic」。**三个「你说」都靠本课的判别器撑腰。**

所以本篇是一片**坐标纸**，不是一片砖；它解决的是整个 09 章（和 2026 年科技新闻）最泛滥的用词混乱。把这片纸画准了，后面 12 篇都是「在某环节加料」，不会再回头吵定义。

## 1. 先把问题拆开：Agent 这个词被用滥了

今天到处都在喊 Agent：聊天窗带了个按钮叫 Agent、CRM 自动化叫 Agent、AutoGPT 叫 Agent、Operator 也叫 Agent。它们显然不在一个能力档。地图 §9.0 给出干净的锚：

**Agent = LLM（大脑） + 工具（手脚） + 循环（机制） + 记忆（状态） + 目标（任务）。**

但「有这些就叫 Agent」还不够——**Workflow 也有工具、也有步骤**。真正分界常用一句话（§6.7）：

> **Workflow 是确定性的，Agent 是决策性的。** 任务是「能枚举步骤」→ Workflow；「要在运行中决定下一步」→ Agent。

本课把这句话翻译成一个**可计算的判别器**（账 B）：拿 6 个特征位（工具 / 决策点 / 记忆 / 多主体 / 评测门 / 人工审批）就能把 12 个真实系统分进 5 个类，并且类与类之间能说出**最容易判错的那条线在哪**。

## 3. 实验 A · 演进谱系：7 世代能力梯（世代增量账）

地图 §9.1 给了演进链：Chatbot → Tool Calling(2023) → Workflow → ReAct(2022) → Agent(2023-2024) → Multi-Agent → Agentic System(2025-2026)。探针把它建模成**能力梯**：每一世代「新增」能力原语，「累计」到下一世代。

把 13 个能力原语拆出来（SINGLE 单轮 / SESSION 会话 / TOOL 工具 / ORCH 编排 / LOOP 循环 / PLAN 自主规划 / MEM 记忆 / REFL 反思 / MULTI 多角色 / ENV 环境执行 / EVAL 评测门 / APPROVE 审批 / GOV 治理），跑出的世代增量账：

| 世代 | 新增原语数 | 累计 | 补齐的缺口 |
|---|---|---|---|
| Chatbot 单轮 | +1 | 1 | 单轮完事，没有可迭代状态 |
| Tool Calling | +2 | 3 | 「只会说不会做」 |
| Workflow | +1 | 4 | 「单步串联要人肉」 |
| ReAct | +1 | 5 | 「调完工具不会再想」 |
| Agent | +3 | 8 | 「一次想完不迭代 · 无记忆 · 错了不回头」 |
| Multi-Agent | +1 | 9 | 「一个脑袋干不了多角色」 |
| Agentic System | +4 | 13 | 「不可信、不可测、进不了生产」 |

（stdout 完整表：`agent_evolution_demo.py` 账 A）

三个结论，每一个都是可计算的事实：

1. **增量榜首 = Agentic System(+4)、次席 = Agent(+3)。** Agent 一次补「规划 / 记忆 / 反思」三件套（从「会循环」到「能自主迭代」）；Agentic System 一次补「环境 / 评测 / 审批 / 治理」四件套（从「能跑」到「能进生产」）。**两次跃迁的方向不同：Agent 补的是能力，Agentic 补的是可靠性。**
2. **能力梯次序 ≠ 发明年份。** 地图把 Tool Calling 排在 ReAct 前面，但 ReAct 论文（2022）早于 OpenAI Function Calling API（2023-06）。这恰恰是教学的黄金坑：**「思考→行动→观察」的循环范式其实更早，但循环跑得动的前提是「工具抓手」先有**——能力梯是「解锁顺位」，不是出版年谱。
3. **13 个原语里，最后 4 个（ENV/EVAL/APPROVE/GOV）全部落在 Agentic System。** 这就是 §9.14 说的「2026 进入 Agent 生产化」的可计算含义——可靠性与治理是**最后才被解锁的原语**，不是最先的。

## 4. 实验 B · 定义判别器：这个系统算哪一类？（12 系统 → 5 类）

把 §6.7 的口诀变成确定性规则：

```
多主体 + 评测门 + 人工审批       → Agentic System（企业级治理版）
多主体                          → Multi-Agent
决策点 + 评测门 + 人工审批       → Agentic System（生产单 Agent 版）
决策点                          → Agent
有工序无决策（哪怕带了工具检索）  → Workflow
无工具无决策（哪怕有多轮会话）   → Chatbot
```

拿它跑 12 个代表性系统，**判别断言 12/12**：

| 系统 | 判类 |
|---|---|
| 裸 LLM 聊天窗（单轮）｜多轮客服对话（有会话无工具） | **Chatbot** ×2 |
| 固定工序客服分流（IF-ELSE）｜RAG 单轮检索问答 | **Workflow** ×2 |
| ReAct 带工具（无记忆）｜LangGraph 带记忆重试客服（里程碑 012）｜代码解释器多步执行｜OpenAI Operator | **Agent** ×4 |
| AutoGen Group Chat 三 Agent 互聊｜CrewAI 写书团队 | **Multi-Agent** ×2 |
| 生产 Agentic RAG（+评测门+人工审批）｜企业多 Agent 治理平台 | **Agentic System** ×2 |

最容易判错的 3 对边界，探针显式打了出来：

1. **「多轮客服对话」vs「ReAct 带工具」＝ Chatbot vs Agent。** 同是多轮，分界不在「多轮」而在「**运行中要不要决定下一步**」——固定话术叫客服，循环决策叫 Agent。
2. **「RAG 单轮检索问答」vs「ReAct 带工具」＝ Workflow vs Agent。** 都调检索，分界在「检索后直接答」还是「**把结果回喂再想**」——有 LOOP 才进 Agent。这一对直接串起 08-RAG 的 12 篇实测和 09 章的 ReAct 篇。
3. **「OpenAI Operator」vs「AutoGen Group Chat」＝ Agent vs Multi-Agent。** 都是决策体，分界在「单决策主体的**动作面深**（GUI）」vs「多决策主体的**协同面广**」。

> 📌 一个边界案件直说：ChatGPT 上挂插件（web browsing）会加 TOOL 特征，但它默认没有独立决策循环，判 Workflow 下的 RAG 档；一旦你在自己的应用里为它接上「观察→再决定」的循环（07-02 的 LangGraph 就是干这个的），它立刻升档为 Agent。**判类不是贴标签，是暴露「你缺哪个原语」。**

## 7. 把这张地图怎么用（一页带走 + 掌握度检验）

一页带走（四条硬记忆）：

```
① 判类四问：可枚举？→Workflow ｜ 决策点？→Agent ｜ 多主体？→Multi-Agent ｜ 有评测+审批？→Agentic
② 一句话分界：Workflow 确定、Agent 决策；Agent 的「手脚/循环/记忆/目标」在 06/07/02 章都有实测锚点
③ 一个刻度：Agentic System = Agent + 环境执行 + 评测门 + 人工审批 + 治理——2026 年的生产台阶
```

## 8. 常见坑（Agent「定义病」的 6 个）

1. **把「有工具」当「是 Agent」**：RAG 单轮检索也调工具，但它是固定工序（账 B 判 Workflow）——**有 LOOP（观察回喂再决策）才进 Agent**。这是 08-RAG ↔ 09 章之间最常踩的线。
2. **把「多轮」当「是 Agent」**：多轮客服对话没有决策点，仍是 Chatbot——**分界在运行中要不要决定下一步**，不在轮数。
3. **把「多 Agent」当「更高级」**：账 C 通路「循环→成本」——多 Agent = 多倍 token 与延迟（07-10 行队成本），**先证明单 Agent 不行再上多**（§6.9）。「一个清晰的 Loop 胜过三个混乱的 Agent」（§9.8）。
4. **把「能循环」当「能生产」**：Agent 补齐的是能力（PLAN/MEM/REFL），Agentic System 补齐的才是可靠性（EVAL/APPROVE/GOV）——**账 A 的最后 4 个原语是最后才解锁的，不是最先的**。
5. **用「像不像 ChatGPT」判类**：同样是浏览器操作，Operator 是单决策体 Agent（动作面深），AutoGen 群聊是多决策体 Multi-Agent（协同面广）——**判类看决策体数量，不看长相**。
6. **史观倒置**：把「Tool Calling 一定比 ReAct 新」当规律——**ReAct 论文 2022 早于 Function Calling API 2023**，能力梯是解锁顺位不是出版年谱；读 09-04 时别被这个坑绊倒。
