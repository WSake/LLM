## 0. 为什么第 5 课讲「原生」？

01-04 篇把 VLM 的零件与装配拆完了：01 篇三路线（A 桥/B 开放/C 原生）、02 篇编码器三件事、03 篇桥四件事、04 篇八家装配定线。走到第 5 课，剩下最后一台机器没打开看过里面：

> **A/B 的装配我们看得懂（冻结 LLM 加桥=A；大 ViT+投影+LLM 全参=B），可 C 玄学在哪儿？——「原生」到底原什么？**

答案就一个词：**统一 token**。C 的「原生」不是参数多，是**数据从预训练第一口就不是"纯文本 + 后接视觉"**——图、音、文从来就住在同一个序列里。这篇把这一口锅拆开：

- **token 账**：同一段多模态输入，A 桥接只有图+文本两个通道，C 原生是一个序列全吃掉——**816 vs 316，差 500 个音频 token**，这就是「原生音频」的物证。
- **建法账**：C 原生从「统一混合语料预训练」起步，A/B 从「纯文本预训练」起步再造视觉——**第一口在哪，决定了路线**。
- **成本账**：从零预训练 ×100（01 篇 C1 只引）。贵到只有大厂玩得起 → **原生仍闭源主导**；Llama4 是开源 2025 追上的早期原生例外。
- **归位账**：8 模型里 C 只有 3 家（GPT-4o/GPT-5、Gemini、Llama4），但知识地图 §10.10 趋势①说这是**未来方向**——为什么？

## 1. 原生 = 三件事（先把地图钉上）

| 原生的三件事 | 问句 | 答案（本篇要练成一句话） |
|---|---|---|
| 统一 token（账 A） | 一台原生 VLM 的输入长什么样？ | 图/音/文进同一个序列（图 256 + 音频 500 + 文本 60 = 816 token），无桥、无两套序列、无视觉专属嵌入层 |

## 3. 账 A · 统一 token 账：一口锅吃了图/音/文

**一句话：原生 C 的输入 = 一个序列，图（patch token）音（帧 token）文（字 token）全在这个序列里，共享同一套词表空间与位置编码——没有独立的桥、没有视觉专属嵌入层、没有两套序列。**

运行结果：
```
A1 一张 224 图(patch14)=256 视觉 token（02 篇锚点只引） · 10 秒音频=500 音频 token（20ms 帧窗） · 40 字文本=60 文本 token
A1 混合输入在 C 原生=同一个序列共 816 token（无两套序列） · A 桥接只有图+文本两通道=316 token，音频不进序列（无原生音频）
A2 M-RoPE 把 60 旋转维三等分→文本 t=20 / 图 h=20 / 图 w=20 · 视频 16 帧→4096（16×256），帧与帧用帧轴 t 串行
A3 无桥签名判别：GPT-4o 装配→原生 C ✓ · Llama4 装配→原生 C ✓（早期原生例外）· Qwen-VL→非原生 ✓ · 早期 LLaVA→非原生 ✓
```

**A1 token 计数**——**能数 token，才能看出"原生到底原什么"**。一张 224 图 patch=14 → 16×16=256 视觉 token（02 篇锚点只引）；10 秒音频按 20ms 帧窗 = 500 音频 token；40 字文本 ≈ 60 token。C 原生把三者放进**同一个序列** = 816 token；A 桥接只有图+文本两个通道 = 316 token，**音频根本不进序列**——这就是「原生音频」最硬的物证：**A/B 系模型（2023 前）没有原生音频通道，GPT-4o 2024 的实时语音是设备侧串起来的（07 站再展开 §10.6 里程碑）。**

**A2 M-RoPE 三维位置**——同一套位置机制管三种模态：把 60 维旋转三等分 (t,h,w)=20/20/20，文本占 t 轴、图像占 (h,w) 两轴、视频/音频的帧再加一层帧轴用 t 串行（02 篇锚点只引）。**不是"每模态自己的位置编码拼起来"，而是一个 (t,h,w) 三维坐标里三种模态共享同一张表。**

**A3 无桥签名判别**——给装配描述判「是否原生 C」：判定规则=`无独立桥 AND 共享 token 空间 AND 一体预训练`。GPT-4o（原生统一 token/无桥/共享词表/一体预训练）→ 原生 ✓；Llama4（早期原生 MMFFM/无桥/多模态 MoE/一体预训练）→ 原生 ✓——**这就是 04 篇把 Llama4 归 C 的机制解释**；Qwen-VL（投影器桥 4.19M）→ 非原生 ✓；早期 LLaVA（独立桥+只训桥）→ 非原生 ✓（03 篇投影器账只引）。

## 4. 账 B · 从预训练建：原生 = 第一口就混合

**一句话：路线的分水岭不在参数量，在"第一口饭"——C 原生从『统一混合语料预训练』起步，A/B 从『纯文本预训练』起步再爬视觉；从零预训练 ×100（01 篇 C1 只引）是原生仍然闭源主导的账本原因。**

运行结果：
```
B1 原生四阶段：统一混合语料预训练 → 多模态视觉指令SFT → 对齐RL(RLHF/DPO) → 安全对齐（第一步=统一混合语料预训练=判别点）
B2 语料判别：原生 C 预训练语料=图文对+音视频交错+文本上下文（✓）… 纯文本网页+书籍（✗ 是 A/B 的起步语料）
B3 成本档三档：C 从零预训练 ×100 · B LLM 全参微调 ×10 · A 只训桥 ×1（01 篇 C1 只引）
```

**B1 四阶段**——原生 C 的建法四阶段：①统一混合语料预训练（图+音+文交错上下文）②多模态视觉指令 SFT（LLaVA-Instruct 类数据的原生版）③对齐 RL（RLHF/DPO）④安全对齐。**判别点在第 1 阶段：C 的第一步就是混合语料，A/B 的第一步是纯文本**——04 篇的"同一只 LLaVA 两代"（早期 A→1.5 B）在这里变成尺子：**看第一步语料含不含图像/音频，就能反推与生俱来 vs 后接**。

**B2 语料混合判别**——「燃料」决定路线：原生 C 要图文对+音视频交错+文本上下文，纯文本语料（网页+书籍）是 A/B 的起步料。**数据即燃料（10.0 篇原话）在路线层成立：要造原生 C，先要有多模态语料矿。**

**B3 成本档**——01 篇 C1 锚点（只引不重测）：A×1（只训桥≈0.03B）· B×10（LLM 全参微调）· C×100（从零预训练）。**原生 C 贵在从头训——为什么原生仍闭源主导（GPT-4o/Gemini 闭源 2 家）、开源 2025 才追上（Llama4 定向资源）：成本门。**

## 5. 账 C · 场景消费：什么场景用得上原生

**一句话：实时语音双向对话、1M+ 长视频、实时听懂屏幕+语音 = 原生招牌（不是 B 的活）；合同/文档、端侧 INT4 = B 就够——原生是因『单模型内的跨模态实时性』买单，不是因为"最新最强"。**

运行结果：
```
C1 5 场景判定：实时双向语音对话→是原生才够（GPT-4o 端到端·§10.6 里程碑只引）· 1M+ 小时级长视频→是原生才够（Gemini 招牌）· 合同/文档阅读理解→否（Qwen2.5-VL/Claude 后接入就够 B/A）· 端侧手机 INT4→否（MiniCPM-V 端侧 B=04 篇锚点）· Agent 实时看懂屏幕+语音→是原生才够（原生加分）
C2 需求反推：实时语音+打断+情绪→C · 小时级长视频→C · 中文文档+UI 开源→B（Qwen-VL）· 端侧离线→B 端侧
C3 原生三贵：贵在数据（多模态语料采集/清洗）· 贵在算力（从零预训练 ×100）· 贵在对齐（统一 token 空间训稳难）
```

**C1 场景判定**——判据=`实时音频 / 视频（长时） / 实时屏+语音` 才锁原生：GPT-4o 实时语音是**端到端**（2024 系统卡·情绪/打断，不是 ASR 级联，07 站展开 §10.6）；Gemini 1M+ 长视频靠原生 token 的上下文堆叠；实时看懂屏幕+语音是 Agent 的多模态未来吃原生融合（04 篇 Qwen2.5-VL 是 B 的过渡，09 站 §10.8 再展开只引）。**合同/文档、端侧 INT4 是 A/B 的老家**——别一看到"多模态"就抬原生。

**C2 需求反推**——给需求特征（不含模型名）反推路线：实时+打断+情绪 → C（GPT-4o）；小时级长视频 → C（Gemini）；中文文档+UI 开源 → B（Qwen-VL）；端侧离线 → B 端侧（MiniCPM-V）。**和 04 篇账 C 同款动作：场景是给需求选模型，先看要不要"单模型内跨模态实时"。**

**C3 原生三贵**——为什么原生仍是少数派：数据贵（多模态语料采集/清洗成本高）、算力贵（从零预训练 ×100 档）、对齐贵（统一 token 空间训稳难）。**20 字：原生贵得真实——数据+算力+对齐三座山，所以大厂标配、中小退拼装（§10.10 趋势①）。**

## 6. 账 D · 掌握度：直说会不会

**一句话：原生毕业 = 一句话（从预训练起统一建模）+ 一张表（C 只有 3 家）+ 三无签名（无桥/无专属嵌入/无冻结）+ 知道为什么仍是闭源主导。**

## 8. 常见坑（理解原生多模态的 6 个）

1. **把「多模态」当「原生」**——Qwen2.5-VL 能看文档、能操作 UI，但它是 B（投影器桥 4.19M + LLM 全参微调），不是原生 C。**看装配（有无独立桥、第一口语料混不混）不看能力。**
2. **以为原生 = 一定更好**——C×100 成本档（01 篇 C1 只引）决定了"原生"值不值一张选型票。**文档/端侧 A/B 就能吃，抬原生是浪费预算；原生买的是"单模型内跨模态实时"。**
3. **把 Llama4 当成"又一家 B"**——Llama4 是早期原生（无独立桥、多模态 MoE、任意尺寸原生支持），它是 C 路线少见的开源一例，别把它和 Qwen/InternVL 的 B 混在一起。
4. **以为原生 = 没有 token 化**——原生同样有 token：图 patch 进 256 token、音频 20ms 帧进 500 token，只是它们住在同一个序列、共享同一套位置。**"统一 token"不是"没 token"，是"大家都 token 且在同一个序列"。**
5. **用「榜单分数」替「路线判断」**——GPT-4o 榜单高≠选它一定对（闭源+API）；选型做的是需求→路线映射（实时音频→C、文档→B），不是跟着最高分跑（04 篇账 C 同口径）。
6. **以为原生 = 实时语音**——实时语音/视频是原生的招牌之一，但原生的大类是"一个序列吃多模态 + 长上下文"（Gemini 1M 视频、统一 token 空间）；且实时语音也能用级联（ASR→LLM→TTS）做，生产主力仍是级联（§10.6 原话，07 站展开）。
