## 0. 为什么第 4 课讲「定线」？

01/02/03 三篇把组件拆完了：01 篇钉死三条路线（改编码器/对齐/解码器哪一层），02 篇把「眼睛」拆成三件事（选哪只/怎么对焦/怎么认位），03 篇把「桥」拆成四件事（底座/选桥/厚度/练法）。现在的问题顺理成章：

> **零件都认识了——把三件套装起来，才知道每一家 VLM 到底是台什么机器。**

为什么到了第 4 课才讲"定线"？因为路线判定不能靠背名字。**LLaVA 与 LLaVA-1.5 是同一只模型的两代，却从 A 跨进 B（交界点=「LLM 的权重动不动」）**；**Qwen-VL 和 InternVL 同属 01 篇 D1 的 B，但 Qwen2.5-VL 会操作 UI（脚伸进 09 章 GUI），InternVL3 已经挤到准原生 C 的门口**。名字会骗人，装配不会：

| 模型 | 编码器 | 桥 | LLM | 后训练 | 路线 |
|---|---|---|---|---|---|
| LLaVA | CLIP ViT-L/14 冻结 | 线性投影 4.19M（03 篇锚点） | 早期冻结→1.5 全参 | SFT 两阶段 | A → B |
| Qwen-VL | 大 ViT+M-RoPE+动态分辨率（02 篇） | 投影器 | LLM 全参微调/RL | SFT+RL | B |
| InternVL | InternViT 大编码器 | pixel shuffle 准原生 token | LLM 全参 | SFT+推理 RL | B → 准原生 |
| GPT-4o / GPT-5 | 原生统一 token | 无独立桥 | 原生预训练全模型 | SFT+RL | C |
| Gemini 系 | 原生统一 token | 无独立桥 | 原生预训练全模型 | SFT+RL | C |
| Claude 系 | 视觉编码器+后接入 | 后接入视觉通道 | 文本 LLM 保留 | 文档/截图适配 | A（后接入） |
| Llama4 | 早期原生 MMFFM | 无独立桥 | 多模态 MoE 全模型 | 全模型自回归 | C（早期原生） |
| MiniCPM-V / Phi-Vision | 端侧小 ViT+投影 | LLaVA 式投影 | 端侧小 LLM 全参 | SFT+INT4 量化 | B（端侧） |

这张表是知识地图 §10.4 原表 + 01 篇 D1 锚点的「装配翻译」。本篇的四本账把每一列怎么读、怎么从装配推出路线、什么场景用得上，全部落成确定性判断。

## 1. 定线 = 四件事（先把地图钉上）

教学法约定在第一问的答案是「改动的是哪一层 → 由装配决定」，第二问"什么场景用得上"藏在每家的特点里：

| 定线的四件事 | 问句 | 答案（本篇要练成一句话） |
|---|---|---|
| 装配（账 A） | 一台 VLM 由什么组成？ | 编码器（选哪只）+ 桥（多厚）+ LLM（动不动）+ 后训练（练什么）——四件套缺一不可 |
| 定线（账 B） | 从装配怎么看出是哪条路线？ | 看「谁冻结谁全参」：冻结 LLM 只训桥=A · LLM 全参微调/RL=B · 统一 token 从零预训练=C |
| 场景（账 C） | 什么场景用哪家？ | 开源复现 LLaVA · 中文文档 UI Qwen-VL · 榜单推理 InternVL · 实时语音 GPT-4o · 长视频 Gemini · 文档截图 Claude · 任意尺寸 Llama4 · 端侧 MiniCPM-V |
| 掌握（账 D） | 一张对照表能不能随手翻？ | 八家七列（模型/路线/编码器/桥/LLM/后训练/场景）全表可查 + 决策树六分支 |

一句话版：**定线 = 读装配、不看名字；场景 = 读特点、不看榜单。十家模型背不全没关系，四件套 + 三路线两个字能推出来。**

## 3. 账 A · 装配台：一台 VLM = 编码器 + 桥 + LLM + 后训练

**一句话：只看名字记不住，看四个槽位就能归类——编码器（选哪只眼睛，02 篇账 A 管）、桥（多厚多贵，03 篇账 C 管）、LLM（动不动=冻结还是全参，01 篇定线的分水岭）、后训练（SFT/DPO/RL 练什么，03 篇账 D 管）。**

运行结果：
```
A1 四件套齐备 8/8：每家的编码器/桥/LLM/后训练都有名字（LLaVA=CLIPViT-L冻结+线性4.19M+早期冻结→1.5全参+SFT两阶段 · Qwen-VL=大ViT+M-RoPE+投影器+全参+SFT+RL · GPT-4o=原生token+无桥+原生全模型+SFT+RL · MiniCPM-V=端侧小ViT+LLaVA式投影+端侧全参+SFT+INT4）
A2 改动层标注 8/8：A 桥接主改对齐层（Claude 后接入）· B 开放参数=对齐+解码器（Qwen/InternVL/MiniCPM）· C 原生=改解码器全网络（GPT-4o/Gemini/Llama4）
A3 开源主线=开放参数：开源 5 家走 B 的 4 家 · 走 C（早期原生）的 1 家（Llama4 例外）· 开源公式=ViT/原生编码器+LLM 全参 5/5 齐备
```

**A1 装配台**——8 个模型各放四件套（探针台账逐项校验非空与合法）。Qwen-VL 的编码器槽就是 02 篇的「大 ViT+M-RoPE+动态分辨率」，LLaVA 的桥槽值是 03 篇的「线性投影 4.19M」——**槽位是空名，槽里的零件都来自前两篇的实测锚点**。

**A2 改动层标注**——回到 01 篇 A2 矩阵的同一句话：这条路线改动的是哪一层？A 桥接=桥在动（编码器冻结、LLM 冻结）；B 开放参数=对齐层 + LLM 解码器的权重都在动（02 篇的 Qwen 大 ViT 微调、03 篇的 LLM 全参都归在 B 的「全参与」里）；C 原生=没有独立的桥，改动藏在解码器全网络里。**Claude 系按 §10.4「后接入视觉」定 A 主改对齐层**（这条是作者归位——它满足 A 的签名「冻结 LLM + 加视觉通道」，但它是最成功的商业闭源桥接）。

**A3 开源公式**——§10.4 关键点原话「今天的开源 VLM = ViT（冻结或微调）+ 投影 + LLM 全参微调/RL」：开源 5 家（去掉三个闭源）里 **4 家走 B**（LLaVA/Qwen-VL/InternVL/MiniCPM-V），只有 Llama4 例外（早期原生 C）。**结论：开源段 80% 的答案都在 B 这一格，想自己搭 VLM 就从 B 的装配开始抄。**

## 4. 账 B · 定线坐标：装配 → 三路线（名字不重要，装配对暗号）

**一句话：定线不看名字看装配——四件套里谁冻结、谁全参、谁无桥，路线写在装配上；给一段「ViT 微调+投影+LLM 全参」的描述，不问模型名也应该脱口而出=B。**

## 8. 常见坑（理解 VLM 定线的 6 个）

1. **背名单记路线**——Qwen-VL 是 B、Gemini 是 C……背得再熟遇到新模型照样懵。正确姿势是背「签名」：A=冻结 LLM 只训桥、B=全参、C=统一 token 预训练——新模型读它的技术报告装配即可当场定线。
2. **以为 A 路线过时了**——Claude 系就是 A（后接入=桥接）的最成功商业闭源；A 没死，只是换成了「闭源 + 加场景」的形态。判断对不对要看企业要不要重训文本权重，不是看年份。
3. **把端侧当成新路线**——MiniCPM-V 是 B 的端侧档（LLaVA 式投影 + 端侧小 LLM 全参），路线没变，变的是参数规模与量化（INT4）；端侧是「资源受限的 B」，不是第四条路线。
4. **用「榜单分数」替「场景匹配」**——InternVL 榜单常青树 ≠ 你该用 InternVL；选型问「我的任务是什么语言、什么形态（文本/图片/视频）、什么预算」，不是问「谁分数最高」。
5. **把「原生」当唯一正确**——原生 C 融合最彻底但成本 ×100；今天 80% 的开源业务用 B（ViT+投影+全参）就够了。三条路线是三个答案不是一个最优解（01 篇总览原话）。
6. **把「多模态 MoE」当新范式定线**——Llama4 的多模态 MoE 是「C 路线内部的稀疏化」，不是第四条路线；MoE 是 02-18 的架构旋钮，管"算力花在哪"，不管"改哪一层"。
