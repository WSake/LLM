## 0. 为什么第 7 课讲「音频」？

05 篇把 C 原生的「统一 token」拆完了——图/音/文进同一个序列（**音频 500 token** 就是在那张表里带过的）。但你细看会发现：**05 篇只告诉你"音频也进了序列"，没回答"那到底用不用它"**——生产里 99% 的语音助手走的是**级联三模型**，不是把音频喂进 LLM：

> **同样一句"明天上海天气"，端到端把它当 500 token 音频喂进一个多模态 LLM；级联把它当 120 token 文本喂进普通 LLM + 两个小模型（ASR 听话 + TTS 说话）。为什么生产反而选后者？**

因为**级联便宜稳定、端到端贵但真**——§10.6 原话就是这个判断。本篇把这条判断算成三本账（token 账 / 延迟账 / 成本账），外加第 4 本账回答"那 2024 为什么出 GPT-4o 实时语音"——因为"真人感"场景（情绪、打断、半句接管）是级联给不了的，那是端到端独有。

## 3. 账 A · 音频 token 账：进不进 LLM 序列

**一句话：音频 30 秒≈500 token（05 锚点）；原生一序列 = 图256+音频500+文本60 = 816，A 桥 = 256+60 = 316（音频不进序列）；级联 LLM 只吃 ASR 文本 120 token，端到端吃音频 500——级联便宜 4.2× 的算术在这。**

运行结果：
```
A1 30s 语音 ≈ 500 token（05 锚点只引）· 流速 ≈16.67 tok/秒 · 60s ≈1000 · 1h ≈60000
A2 原生一序列 = 图256 + 音频500 + 文本60 = 816 · A 桥 = 256+60 = 316 · 差 500 = 音频 token
A3 级联 LLM 侧输入 = ASR 文本 ≈120 token（30s→60 中文字×2 tok/字）· 端到端 = 音频 500 · 500/120 ≈4.17×
A4 3 分钟 ≈3000 token · 30 分钟 ≈30000 token（音频比视频 token 便宜一个量级）
```

**A1 音频流速**——30 秒语音音频≈500 token 是 05 篇锚点（只引不重测），推出 **≈16.67 token/秒**：60 秒 1000、1 小时 60000。对照视频（06 篇）1 小时抽帧 3600 帧 = 921,600 token：**同样一小时，音频 60k vs 视频 0.92M≈15× 便宜**——音频是"连续低信息量"信号，视频是"抽帧高信息量"信号。

**A2 进不进序列**——05 篇的对照（只引不重测）：原生一序列 = 图256+音频500+文本60 = **816**；A 桥 = 256+60 = **316**（音频直接不进序列）。差正好 500 = 音频 token。**这就是"音频进 LLM 序列"的第一道选择题：你要原生（吃音频）还是要桥（不吃）。**

**A3 级联的隐藏优惠**——就算原生能进序列，**级联根本不让音频进 LLM**：ASR 先把音频转成文本（30s 音频≈60 个中文字×2 tok/字 = 120 token），LLM 只处理这 120。端到端要把 500 token 音频喂进去——**500/120 ≈ 4.17×，级联的 LLM 侧输入少 4 倍多**。这就是§10.6"级联廉价稳定"的第一层算术。

**A4 线性换算**——3 分钟 3000、30 分钟 30000。语音长音频仍可控（1h 才 60k），这也是语音 Agent 比视频 Agent 便宜好做的原因之一。

## 4. 账 B · 级联账：ASR→LLM→TTS 怎么配

**一句话：级联 = ASR 听话（Whisper 开源霸主）+ LLM 想事 + TTS 说话（CosyVoice/Qwen-TTS）；首响延迟 450ms（100+200+150）vs 端到端 200ms（慢 2.25×）、成本 $0.006/分钟 vs $0.018/分钟（端到端 3×）；工程优势是每跳可独立换代/重试/降级。**

运行结果：
```
B1 组件归位：ASR(Whisper 音频→文本)·TTS(CosyVoice/Qwen-TTS 文本→音频)·级联三环节齐备
B2 级联首响 = ASR 100ms + LLM 200ms + TTS 150ms = 450ms · 端到端 ≈200ms · 慢 ≈2.25×
B3 级联成本 ≈$0.006/分钟 ≤ 端到端 $0.018/分钟（端到端 3.0×·真人感换价格）
B4 环节故障谱：ASR 挂→听不到 · TTS 挂→说不动 · LLM 挂→兜底话术直走 TTS（可降级）· 每跳可独立重试
```

**B1 组件归位**——§10.6 组件三件套各就各位（只引不重测）：**ASR**（Whisper 是开源霸主，干"音频→文本"）、**TTS**（CosyVoice / Qwen-TTS，干"文本→音频"）、**语音模型**（Qwen-Audio、Gemini 原生音频，才是"音频直接进序列"的派系）。级联把前两个模型 + 普通 LLM 串起来，**语音模型那一路是端到端的活儿，级联不碰**。

**B2 延迟**——教学档：ASR 100ms + LLM 200ms + TTS 150ms = **450ms** 首响；端到端单模型一跳 = **200ms**。**450/200 = 2.25×**：级联慢在"串行三跳"，端到端快在"一跳"。这是给"真人感延迟"的粗量级填空（真实值以各家测速为准）。

**B3 成本**——教学档：级联 $0.006/分钟 vs 端到端 $0.018/分钟（**3×**）。结合账 A4.2×（token 更省），**"级联廉价"是双重算术：token 少（A3）+ 单价低（B3）**。

**B4 可靠性**——级联每跳是**独立成环**的小模型：ASR 挂→听不到、TTS 挂→说不动、LLM 挂→可以"没听清，请再说一遍"的兜底话术直走 TTS（**降级**）。换 ASR（Whisper→更强的 ASR）不用碰 LLM 和 TTS。**这不是端到端天然有的粒度——端到端一个黑盒，哪坏了都难定位。**

## 5. 账 C · 实时账：2024 里程碑怎么来的

**一句话：2024 之前语音助手是"回合制"（半双工·点按发话·等一轮）；GPT-4o 实时语音对话（2024·端到端·情绪·打断）把实时变成现实——单模型 1 跳 200ms + 语义打断（半句接管）；2025 Realtime API 把它变成语音 Agent 的标准接口方向。**

运行结果：
```
C1 里程碑① GPT-4o 实时语音对话（2024·端到端·情绪/打断）· ② Realtime API（2025·标准接口方向）· 2024 前=回合制
C2 实时语音=全双工（两边同时说·Realtime 并发流）· 老式助手=半双工（对讲机式）· 打断=端到端才顺
C3 级联打断粒度≈句（等 ASR 出整句）· 端到端=语义打断（半句被接管）· 打断延迟∝链路长度
C4 唤醒词/VAD 与架构无关（级联'Hi Siri'&端到端'你好'都要先检测进声）· 打断=边界更细的 VAD
```

**C1 里程碑**——§10.6 要素事实：**GPT-4o 实时语音对话（2024）**是里程碑，三关键词=端到端 / 情绪 / 打断；**2025 年 Realtime API** 成为语音 Agent 的标准接口方向。对照：**2024 之前是回合制**（半双工·点按发话·等一轮）——Siri/老 IVR 的体验就在这。

**C2 全双工**——"对话感"的物理含义：**全双工**（两边同时说、Realtime 并发音频流）vs **半双工**（对讲机式：同时只能一方）。老式语音助手半双工+回合制，所以会"您说完了吗?"的尴尬停顿；实时语音全双工，两边可以边听边说。

**C3 打断粒度**——"被打断"是端到端独有能力：级联要等 ASR 出**整句**才能回应（打断粒度≈句）；端到端看**语义**（半句就能识别"停，我说完了"→ 接管）。**打断延迟 ∝ 链路长度**：三跳 vs 一跳。这是端到端"真人感"最直观的来源。

**C4 VAD 与架构无关**——注意别搞混：**唤醒词/VAD（语音活动检测）两者都要**（级联"Hi Siri"、端到端"你好"都得先检测进声）。区别在**打断粒度**：端到端用更细的 VAD 边界+语义实现半句接管，级联只能按整句走完再回。

## 8. 常见坑（理解音频与语音的 6 个）

1. **以为"语音 Agent=把音频直接喂 LLM"**——生产主力是级联（ASR→LLM→TTS），音频不进序列（LLM 只吃 120 tok 文本）；端到端是"真人感"专用。方向反了、预算第一个爆。
2. **把 ASR 和"语音模型"混为一谈**——ASR（Whisper）只做音频→文本；Qwen-Audio/Gemini 原生音频才是"音频直接进序列"的模型。级联不用语音模型，端到端才用。
3. **以为"实时=模型快"**——2024 前模型不慢，是"半双工+回合制"把实时掐死了；实时来自全双工（并发流）＋单跳延迟（端到端 200ms vs 级联 450ms）＋语义打断。
4. **觉得 VAD/唤醒词是端到端才有的**——两者都要（级联"Hi Siri"、端到端"你好"）；区别只在打断粒度（句 vs 半句），不在"要不要检测进声"。
5. **把"打断"当"抢话+忽略"**——打断是语义能力（半句就识别意图接管），不是把音量盖过去；级联的三跳延迟决定了它只能按整句回。
6. **用"哪家贵"决定架构**——级联 token 少（4.2×）+单价低（3×）+可降级（B4）=生产默认；端到端贵但真人感。音频本事是"预算×延迟×话术复杂度"三维解（§10.6 只给判断不给死答案）。
