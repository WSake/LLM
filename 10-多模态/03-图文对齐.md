## 0. 为什么第 3 课讲「桥」？

01 篇把三条路线钉死了。回看那张 3×3 改动层矩阵（01 账 A2），01 篇展开了编码器那一列，02 篇把「眼睛」拆成三件事（选哪只/怎么对焦/怎么认位）讲完一整章。剩下一列——**对齐**——就是你面前这一格：

| 路线 | 对齐（桥） |
|---|---|
| A 桥接 | 训练（投影器 / Q-Former / 交叉注意力）· 编码器冻结 · LLM 冻结 |
| B 开放参数 | 训练（投影器参数全参与）· 编码器微调或冻结 · LLM 全参微调 |
| C 原生 | 无独立桥（统一 token 空间，对齐并进整个网络） |

这一格藏着多模态 90% 的历史与现实：**眼睛把图变成 token（02 篇：一张图 = 577 token），但 LLM 听不懂 token，只听词嵌入（7B 的词嵌入空间是 4096 维）——中间差着一座桥。** 01 篇用账 C 证明「A 只训 ≈0.03B 的桥就能接上 LLM」，02 篇把眼睛吐的 token 数算到 577/分块。现在的问题顺理成章：

> **这座桥到底是怎么来的？——桥学什么（CLIP 是怎么把图文对齐了的）、桥怎么选（演化族谱）、桥有多薄（参数账）、桥怎么练（训练阶梯）。**

本篇把「对齐格」展开成四件事，一一对应一个确定性探针账：

1. **底座** → CLIP 对比学习——图文配对互为正样本，学出对齐语义空间；这是「桥能翻译」的前提（图能搜文、文能搜图）；
2. **选桥** → 对齐方式演化——交叉注意力（Q-Former 抽 query 压缩）→ 纯投影器（线性/MLP）→ 原生（没桥），每档一个会过账的机制；
3. **厚度** → 投影器参数账——桥有多薄（线性 4.19M = 0.06%、MLP 20.97M = 0.30%）；
4. **练法** → 对齐训练阶梯——视觉指令微调 → 多模态 DPO → 多模态 RLVR，奖励来源越来越真。

> 关键区别（为什么不是 01 章路线判定的重写）：01 篇的桥是矩阵里的一格「训练/不训练」；本篇把**桥本身**拆成底座、族谱、厚度、练法四件事，并且每件事都落到「多少参数、多少 token、多少倍、多少判」的确定性数字上。

## 1. 桥 = 四件事（先把地图钉上）

四件事用四个问句表达，教学法约定在本篇的第一问答案是「改动的是哪一层 → 对齐层」，第二问"什么场景用得上"就藏在这四个问句里：

| 桥的四件事 | 问句 | 答案（本篇要练成一句话） |
|---|---|---|
| 底座（CLIP） | 桥凭什么能翻译？ | 图 → 文、文 → 图两向检索都能用，靠的是对比学出的共享语义空间 |
| 选桥（演化族谱） | 数据/算力不同用哪座桥？ | 少数据用线性投影 → 中等数据 MLP → token 压缩用 Q-Former → 最强用原生 |
| 厚度（投影器账） | 桥贵不贵？ | 线性 4.19M=0.06%、MLP 20.97M=0.30%——语义在对齐底座里，不在桥里 |
| 练法（训练阶梯） | 桥怎么练真？ | 指令微调给「标准答案」→ DPO 给「偏好」→ RLVR 给「可验证真值」 |

一句话版：**桥不是让 LLM 学会看图，是把图翻成 LLM 已经会的语言——底座（CLIP）负责「对齐」，桥只负责「翻译 + 压缩」；翻译的部件越薄越好，真正的表现力在上游的编码器与下游的 LLM。**

理解这座桥不能靠背参数。探针 `text_image_align_demo.py` 用纯 stdlib 把四件事测出来：

| 账 | 问 | 怎么答（确定性仿真） |
|---|---|---|
| A | 桥怎么选？ | 对齐方式演化族谱 6 家（年份单调）+ A2 矩阵「对齐格」三态归位 + 5 场景选方案 |
| B | CLIP 学出了什么？ | 确定性「对齐语义空间」12 类图文对：图文互检 12/12+24/24 + 同义改写判别对照 6/6 vs 0/6 + InfoNCE 对比损失 ≈2240× |
| C | 桥有多薄？ | 投影器参数账 4.19M/20.97M（0.06%/0.30%）+ Q-Former 压缩 577→32=18.0× + 6 场景选桥 |
| D | 桥怎么练真？ | 训练阶梯三档（SFT→DPO→RLVR）+ 5 才算范式 + RLVR 真值闭环 2/3→3/3 + 架构→方案 6/6 + 决策树 6/6 |

全程无网络、无随机、无第三方：计数/判层/选型/检索/验证全是**确定性函数**（语义向量用 sha1 截断构造）。三条独立进程逐字节恒一（md5 `a56f1f00…`），任何一步出错立即 assert 暴露。

## 3. 账 A · 对齐方式演化：选桥（桥接谱系与三态归位）

**一句话：桥不是弯的，它是条演化主轴——CLIP 先学出对齐底座（2021）→ 交叉注意力拿条件（Flamingo 2022）→ Q-Former 抽 query 压缩（BLIP-2 2023）→ 线性投影简单有效（LLaVA 2023）→ MLP+解冻全参（LLaVA-1.5 2024）→ 原生没桥（2025）；选桥 = 先看数据多不多，再看要不要压缩。最开始时是检索，不开 LLM 就不要桥。**

运行结果：
```
A1 族谱年份单调 6/6（2021→2025 一条演化主轴）· 机制 6/6 合法（contrastive/cross_attn/projector/none）
A2 对齐格归位 3/3：A 桥接=只训对齐层（编码器冻结·LLM 冻结·仅对齐层训练）
              B 开放参数=对齐训练+全参与 · C 原生=无独立桥（对齐并进整个网络）
A3 场景→对齐方案 5/5：已有大模型只加看图算力紧→线性投影器冻结 LLM（A 桥）
              中等数据想更强协作→MLP 投影开放 LLM（B） · 文档长 token 想压缩→Q-Former query
              按图搜文/按文搜图→CLIP 语义空间不接 LLM · 从零预训练→原生统一 token（C）
```

**A1 演化族谱六家**（知识地图 §10.3「对齐方式演化」原话整理，加上 CLIP 作为对比底座）：

| 对齐方式 | 年份 | 一句话 | 机制 |
|---|---|---|---|
| CLIP | 2021 | 对比学习·图文配对互为正样本·学到对齐语义空间（底座） | contrastive |
| Flamingo | 2022 | 交叉注意力把视觉条件拿进冻结 LLM | cross_attn |
| Q-Former | 2023 | 可训练 query 提取视觉 token·编码器+LLM 双冻结 | cross_attn |
| LLaVA | 2023 | 线性投影把 patch 特征投进词嵌入空间·简单有效 | projector |
| LLaVA-1.5 | 2024 | 两层 MLP 投影·解冻 LLM 全参微调 | projector |
| 原生路线 | 2025 | 统一 token 空间·不再需要独立桥 | none |

**A2 回挂 01 的矩阵**——同一个「对齐格」，三条路线三种处置：A 桥接只训对齐层（编码器冻结、LLM 冻结，只有桥在动）；B 开放参数桥的每个参数都参与联合微调；C 原生根本不需要独立的桥（对齐并进整个网络的预训练里）。**A3 场景选方案 5/5** 是这套判据的单选题：只给成熟大 LLM 加看图、算力紧 → 线性投影 + 冻结（A，01 账 C2 的 ≈0.03B）；中等数据 → MLP + 开放（B）；文档/图表长 token 想压缩 → Q-Former 抽 query；**按图搜文/按文搜图不开 LLM → CLIP 语义空间直用，不要桥**；从零预训练 → 原生（C）。

## 4. 账 B · CLIP 对比/检索账：桥凭什么能翻译（对齐语义空间）

**一句话：CLIP 用「图文配对互为正样本」的对比学习把图与文塞进同一个语义空间——图能搜文、文能搜图，而且同义改写（小猫→猫）在这个空间里照样命中（6/6），词面精确匹配却全 miss（0/6）：对齐，越过了词面。**

运行结果：
```
B1 文本→图 top-1：真标签 12/12（对齐空间图文互为最近邻）· 图→文本 24/24（双向往返都用得上）
B2 判别性对照：同义改写召回 对齐语义空间 6/6 vs 词面精确 match 0/6——对齐越过了词面
B3 InfoNCE 账：对齐空间损失 0.0007 < 0.002（正样本对几乎独吞概率质量）
         未对齐损失 1.5249 > 1.0 · 未对齐/对齐 ≈ 2240 倍 >1000（对比学习把正样本从负样本池里拉出来）
B3 量纲诊断：对齐度=对角与非对角之差（未对齐差 0.10 vs 对齐差 0.70）
B4 CLIP 两用 2/2：检索（双向往返）+ 图像编码器预训练的事实底座（§10.3 要素事实）
```

**B1 空间长什么样**——探针用 sha1 构造一个确定性的 12 类「语义空间」：每类共享一个语义分量 s(C)，图像 = 0.85×s(C)+0.15×实例扰动，文本 = 0.90×s(C)+0.10×查询扰动。在这个空间里，12 张真标签的图全部互为文本最近邻（12/12），24 张图的类别又全部被文本查回（24/24）——**CLIP 的「双向往返」都成立**。

**B2 为什么说"越过了词面"**——同一批 6 组同义改写（小猫→猫、狗狗→狗、小轿车→汽车、雪峰→雪山、钢琴曲→钢琴、单车→自行车）：走**对齐语义空间**检索 6/6 全中（「小猫」的语义分量≈「猫」，所以最近邻还是猫图）；走**词面精确匹配**（字面 equal）0/6 全 miss。这一对照就是 §10.3「学到对齐语义空间」的教学证据：**对齐 = 相似语义在空间里比邻而居，哪怕字面完全不同。**

**B3 InfoNCE 对比损失**——CLIP 的损失函数（教学简化）：一张图和它的配对文本是正样本对 (i,i)，其余 15 个文本是负样本，`L = -1/B Σ log(exp(s_ii/τ) / Σ_j exp(s_ij/τ))`，τ=0.07。对齐空间（对角 0.80 vs 非对角 0.10）→ `0.0007`——正样本对几乎独吞了概率质量；未对齐空间（对角 0.40 vs 非对角 0.30）→ `1.5249`——正样本淹没在噪声里。**两档差 2240 倍**，这就是「对比学习把正样本从负样本池里拉出来」的数学形状。量纲诊断提醒：真正的信号是**对角与非对角的差**（0.70 vs 0.10），不是对角回数值。

**B4 底座的两副面孔**——CLIP 今天有两个身份：直接的**图文检索器**（双向往返），和无数 VLM 的**图像编码器预训练底座**（02 篇的族谱里 CLIP ViT 一家就占了两席）。所以桥的翻译能力不是桥自己会的——**是底座在预训练里对齐好的**，桥只是把已对齐的特征「插头插进」LLM。

## 5. 账 C · 投影器账：桥有多薄（参数账与压缩账）

**一句话：桥是「只换维度、不重新学语义」的翻译层——线性投影 1024×4096 = 4.19M 参，只占 LLM-7B 的 0.06%；MLP 厚 5 倍也只有 0.30%。而 Q-Former 那类桥顺手把 token 压了 18.0×（KV 省 94.5 个百分点）——桥薄、桥还能压缩。**

运行结果：
```
C1 线性投影参数 = 1024×4096 = 4.19 M · MLP = 4.19+16.78 = 20.97 M（MLP 比线性厚 5 倍）
C1 线性桥只占 LLM-7B 的 0.06% · MLP 桥只占 0.30%（<0.3%）——桥很薄
C2 token 口径：一张图 = 576 patch + 1 CLS = 577 token（02 账）
C2 Q-Former 压缩 = 577/32 = 18.0 倍（长上下文省钱）· KV 省 94.5 个百分点
    （回引 01 账 Q-Former 256→32 省 KV 87.5pp 同式；本账按 02 的 patch 规模 577 算）
C3 场景→选桥 6/6：数据少→线性薄桥 · 中等数据→MLP · token 贵长文档→Q-Former 交叉注意力
              图文检索不开 LLM→不用桥 · 全量→原生统一 token · 特征已 CLIP 对齐过→薄桥插维度
```

**C1 桥有多薄**——ViT-L/14 的 patch 特征是 1024 维，LLM-7B 的词嵌入是 4096 维。线性投影 = 1024×4096 = **4.19M**；再加一层 LD×LD 就成 MLP = **20.97M**（厚 5 倍，表达更强但吃更多数据）。两张桥都大不到哪去：占 7B 的 **0.06% / 0.30%**。**这就是 01 账 C2「A 只训 ≈0.03B」的来处——桥很薄，因为语义不在桥里，在对齐底座里。**

**C2 桥还能压缩**——02 篇的账：一张图 = 576 patch + 1 CLS = 577 token。Q-Former 用 32 个 query 把视觉 token 提炼成 32 个 → **压缩 577/32 = 18.0×**，KV cache 同步省下 **94.5 个百分点**（`(577-32)/577`）。这正是「文档/图表长 token 想压缩 → Q-Former」的原因；01 篇用 256/32 口径算过同一笔账（87.5pp），本账按 02 篇的 577 口径复算同一式，两处量级一致。

**C3 选桥判据 6/6**——数据少先跑通用薄桥；中等数据要更好对齐用 MLP；token 贵/长文档图用 Q-Former；**图文检索不开 LLM 就不要桥**；全量预算要最强用原生；**编码器已经是 CLIP 对齐过的，桥只插维度（薄桥即可）**——这条是今天绝大多数开源 VLM 的实际路径（§10.4 的 Qwen/LLaVA 都是编码器对齐好 + 投影桥 + LLM 全参）。

## 6. 账 D · 对齐训练阶梯账：桥怎么练真（SFT→DPO→RLVR）

**一句话：对齐训练的奖励来源一路变真——视觉指令微调给「老师标准答案」（SFT）→ 多模态 DPO 给「人类偏好」（哪个好）→ 多模态 RLVR 给「可验证真值」（计数/坐标/几何，程序能核对）。RLVR 的卖点就是：奖励是规则验证器给的，不是模型自欺打的。**

运行结果：
```
D1 训练阶梯三档 3/3：SFT→DPO→RL 递进，数据形态从监督到偏好到可验证奖励
D2 数据样例→训练范式 5/5：唯一答案→SFT · 「标注者说后者好」→DPO · 「可程序核对真值」→RLVR
              「互为正样本」→CLIP 对比预训练 · 「统一 token 从零」→原生预训练
D3 RLVR 账：策略 '数人物' 2==2 · '几何角度' 180==180（规则验证器可核对）
D3 诚实注入：策略在坐标题上答错 1/3（可验证奖励=真值函数·不是自欺的价值模型）
D3 RLVR 闭环：验证器信号把策略 2/3 → 3/3（可验证奖励驱动修正=RLVR 卖点）
D4 架构→对齐方案 6/6：Flamingo 交叉注意力(A冻LLM) · BLIP-2 Q-Former(A双冻结) · LLaVA 线性投影(A→B 桥)
              LLaVA-1.5 MLP(B) · Qwen2.5-VL 大ViT+投影(B) · GPT-4o 原生(C)
D4 决策树 6/6：不开 LLM 纯检索→零对齐训练 · 特征已对齐→薄桥 · 预算不足→缓图
              小数据幻觉重→先工程后微调 · 有图文问答数据→B · 全量→开放参数或原生
```

**D1 阶梯三档**（知识地图 §10.3 原话展开）：视觉指令微调（LLaVA-Instruct 类，2023，给唯一答案 + 参考答案）→ 多模态 DPO（2024，给好坏回复对，学「哪个更好」）→ 多模态 RLVR（R1-V 等 2025，给「可验证问题」：数人物、坐标解析、几何角度）。**奖励来源从「人给的答案」走到「程序可核对的真值」**——越来越「真」，也越来越难造假。

**D2 算范式 5/5**——看到数据样例判它是哪档训练：`图里有几个人？A：3 个人`（唯一答案）→ SFT；`两个回复版本，标注者说后者好` → DPO；`终点经纬度可用程序核对真值` → RLVR；`百万级图文配对·互为正样本` → CLIP 对比预训练；`从零统一 token` → 原生预训练。**一句话：给答案=SFT、给偏好=DPO、给可验证题目=RLVR、给配对=对比预训练。**

**D3 为什么 RLVR「真」**——探针里放了一个诚实的教学闭环：确定性「策略」能答对 2/3（数人物=2、几何角度=180），在坐标题上被注入 1 个错（把真值 31.8,117.2 答成 30.1,116.0）。规则验证器（`rule_verifier`：一条查表真值函数，没有模型分数、没有自欺）抓住这一处 → 修正循环把 2/3 补到 **3/3**。**可验证奖励 = 真值函数；它不能一挥而就给你聪明的模型，但每一笔奖励都是程序能核对的硬账**——这正是 R1-V 路线「用视觉可验证题训推理」与「价值模型自欺打分」的分水岭。

**D4 归位与决策树**——把 01 篇 D1 的架构定线落到对齐层：Flamingo = 交叉注意力对齐层（A·冻 LLM）；BLIP-2 = Q-Former 桥（A·双冻结）；LLaVA = 线性投影 + 两阶段 SFT（A→B 桥）；LLaVA-1.5 = MLP + LLM 全参（B）；Qwen2.5-VL = 大 ViT + 投影 + M-RoPE（B，回到 02 篇）；GPT-4o = 原生统一 token（C）。决策树再提醒一遍**"什么时候不值得做对齐训练"**：纯检索不开 LLM → 零对齐训练；特征已对齐 → 薄桥省预算；预算过不了 A 桥 → 缓图；小数据幻觉重 → 先上检索/工程别急着多模态微调。

## 7. 这篇怎么用（一页带走 + 掌握度检验）

**一页带走：桥 = 底座（CLIP·对齐语义）→ 选桥（族谱）→ 厚度（投影器）→ 练法（阶梯）。**

```
底座：CLIP 对比学习·图文配对互为正样本 → 图搜文/文搜图；同义改写 6/6 vs 词面 0/6（越过了词面）
选桥：少数据→线性投影（A 桥·0.06%）· 中等→MLP 开放（B）· token 贵→Q-Former 压缩 18.0×（KV 省 94.5pp）
     检索不开 LLM→不用桥 · 从零→原生
厚度：线性 4.19M · MLP 20.97M（厚 5 倍）= 7B 的 0.06%/0.30%——语义在底座，不在桥
练法：给标准答案→SFT（LLaVA-Instruct）· 给偏好→DPO · 给可验证题目→RLVR（真值函数 2/3→3/3）
```

**掌握度检验（不看代码，答得出才是真会）：**

1. 一张图的视觉 token 怎么进 LLM？（答：编码器吐 token（577/张）→ 桥（投影器/Q-Former）把 token 投进 4096 维词嵌入空间；桥在读 LLM 的语言，不是在学看图）
2. 为什么说 CLIP「越过了词面」？（答：对齐语义空间里同义改写（小猫→猫）检索 6/6 全中，词面精确匹配 0/6——相似语义比邻而居，字面不相干）
3. 对比损失怎么看出「对齐了」？（答：InfoNCE 账，τ=0.07；对齐空间 0.0007 vs 未对齐 1.5249 ≈ 2240×——正样本对几乎独吞概率质量）
4. 桥有多薄？（答：线性 1024×4096=4.19M=0.06%，MLP 20.97M=0.30%；桥薄因为语义在 CLIP 底座里，桥只负责翻译）
5. Q-Former 的价值是什么？（答：压缩——577→32 token = 18.0×，KV 省 94.5 个百分点；长文档图省钱）
6. 对齐训练的三档各是什么激励？（答：SFT 给标准答案 → DPO 给偏好对 → RLVR 给可验证真值（规则验证器），奖励来源越来越真）
7. 为什么 RLVR 的奖励「不骗人」？（答：可验证奖励=真值函数（计数/坐标/几何，程序可核对），不是价值模型打分——探针里策略故意错 1/3，验证器抓住后 2/3→3/3）
8. 什么场景根本不需要桥？（答：图文检索不开 LLM——CLIP 语义空间直接当检索器，接 LLM 才需要桥）

## 8. 常见坑（理解对齐层的 7 个）

1. **以为「对齐 = 多模态训练」**——80% 的对齐发生在 CLIP 对比预训练（底座），桥只是把已对齐的特征翻译进 LLM；想靠桥救回没对齐的编码器是缘木求鱼。
2. **以为桥越厚越好**——线性 0.06%、MLP 0.30%、Q-Former 还要再挑 query 数；桥厚 5 倍吃数据多 5 倍，语义不在桥里。数据少先用薄桥。
3. **让检索进 LLM**——按图搜文/按文搜图是 CLIP 空间的事，向量库就能干；把整图塞进 LLM 检索既贵又慢（回引 02 看图 vs OCR ≈74×）。
4. **把 InfoNCE 当「对齐度」**——真实的信号是**对角与非对角之差**（0.80-0.10 vs 0.40-0.30），不是对角回数值；只看对角回数会在 τ 上自我安慰。
5. **DPO 当 SFT 用**——SFT 给「唯一答案」，DPO 给「好坏对」；数据里没有成对偏好，跑 DPO 是没米下锅。
6. **把 RLVR 当万能钥匙**——可验证奖励只吃「程序能核对真值」的题（计数/坐标/几何）；开放问答没有规则验证器，硬套就是幻觉放大器。
7. **只背「LLaVA=投影器、Qwen=动态分辨率」**——要会说清每家在 01 账 A 三态的对齐格上是哪一态（A 桥/B 全参与/C 无桥），这才算掌握了架构差异的落点。
