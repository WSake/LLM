## 0. 为什么把"认路"当第一课

多数大模型教程把读者的起点假设成"一无所知"或"什么都会"，而真实情况是**每个人都会一点、缺的却不一样**。上来就啃公式，数学好的人嫌慢、数学弱的人劝退；上来就写代码，有经验的人受益、纯新手崩溃。

本仓库的做法是：**先花一小时做一次"能力自测"，把缺什么、先补什么、从哪篇开始读，变成一张你自己的路线图。** 这比任何"推荐学习顺序"都更贴合你——因为顺序本来就是给"知道自己是谁"的人用的。

同时，这节课也告诉你**这套仓库的翻书方法**：它不是一本从第一页翻到最后一页的书，而是一台"三件套"机器（地图 + 正文 + 可跑代码），你会用了它，后面的每一章都事半功倍。

## 1. 本仓库怎么用：三层结构 ↔ 你的学习闭环

### 1.1 三件套：地图、正文、可跑实验

```text
┌─────────────┐   ┌─────────────┐   ┌─────────────┐
│  ① 知识地图   │   │  ② 章节正文   │   │③ 可跑实验/notebook│
│（是什么）     │ → │（怎么理解)  │ → │（亲手验证）   │
└─────────────┘   └─────────────┘   └─────────────┘
  00-知识地图/       NN-目录/*.md        code/notebooks/
  90+ 知识点定位      一篇=一个知识点       跑完看数字
```

1. **知识地图**（`00-知识地图/大模型知识地图_完整版.md`）回答"什么是 XXX、它为什么存在、我该学到什么程度"——是目录与索引的总纲。
2. **章节正文**（`01-基础/` 等目录）回答"XXX 到底怎么运转"——每篇一个知识点，按固定 9 段模板写，最要紧的两点：**它能解决什么问题**、**它和数据/前后章怎么衔接**。
3. **可跑实验**（`code/notebooks/` 与 `code/scripts/`）回答"眼见为实"——你亲手跑一遍，看到数字，知识才算长在你身上。

### 1.2 闭环五步（每学一个知识点都走一遍）

```text
①地图定位 → ②读正文 → ③跑notebook → ④看指标/写结论 → ⑤回索引打勾 ✅/⬜
              （10-30分钟）  （10-30分钟）   （5 分钟）
```

第⑤步的"打勾"就是 `00-知识地图/对照索引.md`——它是你的**进度卡**，也是仓库的**贡献认领清单**：看到 ⬜ 而你刚好会，欢迎写完提 PR。

> 为什么强制"看完就跑跑"？因为大模型的知识只分两种：**跑过证明的**和**听说过没证实的**。本仓库所有正文里的数字，都来自仓库里能一键复现的脚本——你可以（也应该）自己复现一遍。

## 2. 01-基础 这门课：七间房与推荐顺序

`01-基础` 对应地图 §1 的 **6 个知识点**（§17.1.1–§17.1.6）：Python 工程、数学、机器学习、深度学习、Transformer 前置、GPU——其中机器学习拆成"范式评估"与"sklearn 实战"两篇。六条知识点有严格依赖链：**Python 先于一切，数学→机器学习→深度学习→NLP→GPU**。加本文入口，共 **8 篇成品**（1 篇入口 + 7 篇内容课）。下面把 7 篇内容课按此链排成"七间房"，顺序即文件名序号：

|---|---|---|---|
| 0 | **本课**（学习路线与自我评估） | 认路 + 自测 | 知道自己先补哪、从哪读起 |
| 1 | `01-Python入门与工程能力.md` | 环境(uv·conda·venv)/Python 语法/命令行·Git/numpy·pandas/dataclass | 环境能装、代码能跑、数据能读、管线能写 |
| 2 | `02-机器学习中的数学.md` | 线性代数/微积分/概率统计/信息论/数值优化（梯度下降家族） | 公式不再劝退，能读懂论文公式并亲手用 numpy 验证 |
| 3 | `03-机器学习-范式与评估.md` | 监督/无监督/强化三大范式 + 评估口径（交叉验证·分类/回归/无监督指标） | 看见任何模型先问"我的评估口径怎么看" |

## 3. 起点自测：五个维度，十道问句

诚实作答，每行选 **A / B / C**，然后对着"该做什么"给自己画路线。

### 维度一：写代码（Python）

1. `a = [x**2 for x in range(10)]`，我说这行会执行 10 次循环并得到平方列表，你**能自己写出等价的两行 for 循环**，且说出两者差异吗？
   - A. 能，还知道列表推导更快更简洁 → 直接进房 4（sklearn 实战）
   - B. 看得懂却不能独立写 → 进房 1，从第 2 节读
   - C. 完全陌生 → 先花 1–2 周补 Python 入门，再回来
2. 你能用 `numpy` 把两个矩阵乘起来，并说清"矩阵乘法不是逐元素乘"吗？
   - A. 能 → 房 1（Python）与房 2（数学）都只需扫读
   - B. 不能 → 进房 1 的第 4 节（numpy/pandas 起步）与房 2 的线性代数
   - C. 没听过 numpy → 房 1 是你的第一站

### 维度二：数学（线代 / 概率）

3. 有人拿矩阵 `W`（形状 3×5）乘向量 `x`（5×1），结果是什么形状？"转置"是干嘛的？
   - A. 全答对 → 房 2 只需扫读
   - B. 形状答对、转置说不清 → 房 2 线性代数部分重读
   - C. 答不上 → 房 2 线性代数一遍过
4. 抛一枚不均匀硬币，"正面概率 p"是什么意思？`P(A|B)` 读作什么？
   - A. 都能解释 → 房 2 概率部分扫读
   - B. 知道 p 是概率、条件概率没概念 → 房 2 第 3 节过一遍
   - C. 都陌生 → 房 2 概率统计部分认真读

### 维度三：机器学习概念

5. 你分得清"训练集 / 验证集 / 测试集"吗？能说出为什么不能拿测试集调参吗？
   - A. 能，还知道交叉验证 → **评估篇（房 3）只需扫读**，直接进 `02-核心原理` 或 `06-应用开发`
   - B. 大概懂、说不出交叉验证 → **房 3 认真读**（这是全仓最重要的方法论之一）
   - C. 不知道 → 房 3 是你的必由之路
6. "准确率 95%"你听到的第一反应，是"不错"还是"看类别分布再下结论"？
   - A. 第二个 → 你已经具备评估素养
   - B. 第一个 → 房 3 的"准确率陷阱"一节会改变你

### 维度四：深度学习

7. 你能解释"反向传播 = 链式法则的工程实现"这句话吗？
   - A. 能 → 房 5 扫读，重点看正则化与损失函数
   - B. 听过、讲不圆 → 房 5 从 0 节读起
   - C. 没概念 → 房 5 是全目录里你最该多花时间的
8. "训练精度 100% 但测试精度 70%"意味着什么？你会怎么下手？
   - A. 过拟合，需要正则化/降复杂度/加数据 → 房 5 跳过第 5 节也行
   - B. 说不出 → 房 5 第 5 节必读
   - C. 完全懵 → 房 5 从第一节慢慢来

### 维度五：NLP 与语言模型

9. 你能从"Token 分词 → 词向量 → 注意力 → Transformer"说清一条演进线吗？
   - A. 能 → 房 6 扫读，直接进 `02-核心原理`
   - B. 知道 Transformer、说不清词向量 → 房 6 第 2–5 节
   - C. 陌生 → 房 6 完整读一遍
10. 你理解"语言模型在学'续写'"这句话吗？
    - A. 理解，还知道它为什么能学到知识 → 房 6 扫读
    - B. 听过、不太信 → 房 6 第 4 节（语言模型）必读
    - C. 没概念 → 房 6 是你的过渡课

### 3.1 自测结果怎么用

把 10 题的答案汇进一张表：

```text
维度       你答了几个 A/达标      接下来
写代码     ≥1 个 C → 先补 Python；全 A → 房 1 只需扫读到第 4 节
数学       ≥1 个 C → 房 2 认真读；全 A → 扫读
ML 概念    B 或 C → 房 3 必读（评估篇）
深度学习   B 或 C → 房 5 多花时间
NLP        B 或 C → 房 6 必读
```

铁律两条，比任何单篇都重要：

1. **薄弱项优先，不求全 A 再前进。** 补到"能读、能跑、能自答"即可动身；系统性的深度留给 02–13 在实战中补。
2. **每读一篇，一定跑通它的 notebook 或脚本，再在心里复述"这篇教了我什么、和上一篇怎么接"。** 复述不出来就是还没消化。

## 4. 学完本目录后：通往两条路线

`01-基础` 之后是大模型知识体系的分岔口（详细路线在 `16-学习路线与里程碑`，此处给出目录级路径）：

```text
【路线 A · 算法/研究员】想懂"模型是怎么训练出来的"
  01-基础 → 02-核心原理 → 03-模型家族 → 04-训练体系 → 11-评测

【路线 B · 应用/工程】想懂"模型怎么被用成产品"
  01-基础(可轻量) → 06-应用开发 → 07-应用框架 → 08-RAG → 09-Agent → 11-评测

【两条路线的交汇带（谁也别跳）】05-推理与部署 · 11-评测 · 12-安全
```

- 选 A：把房 5（神经网络）、房 3（评估）尤其读扎实，它们是 `02-核心原理` 的四梁八柱。
- 选 B：可以只取房 3（评估）+ 房 1（Python 够用版）+ 房 4（sklearn 实战），然后在 `06-应用开发` 的路上边做边补数学。

> 不确定选哪条？先顺着本目录读一遍，再花一个周末把 `02-核心原理` 的第一篇（Transformer）与 `06-应用开发` 的第一篇（Model API）各看一半——哪边让你"更想动手做点什么"，就去哪边。

## 5. 学习纪律：让"学会"成为可验证的事实

1. **每篇一实验**："看完了"不等于"会了"。合上文档，隔 30 分钟不借助资料跑一遍 notebook 的关键输出，跑得出来才算会。
2. **每周一小结**：用一张纸写"这周我掌握的知识点：地图章节号 + 一句话"，卡壳的位置就是下周要补的地方。
3. **每级一项目**：路线 A/B 各分四档（初/中/高/专家），**每档结束必须交付一个能跑通的项目**。项目选题在 `16-学习路线与里程碑` 的里程碑清单里，比如"手写神经网络学 XOR"就来自房 5。
4. **疑点入册**：遇到不懂的标记到 `对照索引.md` 对应行，下个周末回头清一遍——这是"完整学习"与"刷完"的关键区别。

## 6. 常见坑

| 坑 | 原因 | 对策 |
|---|---|---|
| 从最难的章节开始 | 被"XX 全解"标题吸引 | 先自测，从自己的薄弱维度开始，别跟体系顺序硬刚 |
| 只读不跑，两周后忘光 | "看过"没有沉淀 | 每篇必须跑一个实验，跑不过就重读 |
| 数学劝退就跳过 | 以为"以后用不上" | 公式在 02/04/05 会反复出现；现在的半小时是后来的几小时 |
| 拿测试集反复调参 | 混淆验证/测试 | 评估篇（房 3）会把这个概念钉死——先读它再动手 |
| 收藏一堆资源不行动 | 把"规划"当"学习" | 用 10 分钟自测 + 每晚 30 分钟，跑起来再谈收藏 |
