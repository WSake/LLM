## 0. 为什么要学数学：机器学习的三块基石

机器学习本质上是这样一件事：

> **给计算机一大堆数据，让它自己找出其中的规律，然后用这个规律去预测没见过的新数据。**

整个过程每一步都和数学挂钩：

| 机器学习里做的事 | 背后用的数学 | 一句话直觉 |
| --- | --- | --- |
| 数据长什么样、怎么表示 | **线性代数** | 数据是"表格"，矩阵运算是"搬动表格" |
| 模型怎么判断自己好坏、怎么变好 | **微积分** | 用"坡度"决定往哪边调整参数 |
| 模型面对的不确定性、预测的概率 | **概率与统计** | 世界不是确定的，我们用概率说话 |
| "预测得准不准"如何定量 | **信息论** | 用"比特"衡量信息和惊讶程度 |
| 真正的训练过程 | **数值优化** | 一步步走下坡，找到损失最小的点 |

这三块不是孤立的，它们像**一套齿轮**一样咬合：

```text
数据 ──线性代数──> 矩阵 X（每行一个样本）
                      │
                      ▼
               模型：y = XW + b（又是线性代数）
                      │
                      ▼
             损失函数 L = 预测与真实差多少（概率/信息论）
                      │
                      ▼
            梯度 ∂L/∂W（微积分：链式法则）
                      │
                      ▼
          W ← W - η·∂L/∂W（数值优化：梯度下降）
```

### 0.1 与大模型（LLM）的关联总览

你会在后面所有章节里反复看到这些名字，这里先混个脸熟：

- **嵌入（Embedding）**：把"词"变成向量 → 线性代数。
- **注意力（Attention）**：词与词之间的"相似度打分"，本质是**点积** → 线性代数 + 概率。
- **下一个词预测**：模型输出每个候选词的概率 → 概率与统计。
- **交叉熵损失**：训练时模型的"分数" → 信息论。
- **反向传播 / 梯度下降**：几十亿参数如何被逐个调整 → 微积分 + 优化。
- **采样（Sampling）与温度（Temperature）**：怎么从概率分布里选词 → 概率与统计。

> 💡 学习方法建议：先**读完一章**，再**亲手运行代码**，最后**合上书给自己讲一遍**。数学不是"看会的"，是"用会的"。

## 1. 线性代数：描述数据的形状与变换

机器学习里几乎所有的数据都被存成**矩阵**，几乎所有计算核心都是**矩阵乘法**。GPU（显卡）为什么能加速 AI？因为 GPU 本质上就是一台"**大规模并行做矩阵乘法的机器**"。

### 1.1 起源故事：从解方程到"向量空间"

线性代数不是某个数学家一拍脑袋发明的，它源于一个非常古老的问题：**解线性方程组**。

- **公元前 200 年（中国）**：西汉的《九章算术》里记载了"方程术"，就是今天**高斯消元法**的雏形——用加减消元逐步求解多个未知数，这是世界上最早的系统化线性方程组解法之一。
- **17 世纪（日本 / 德国）**：日本数学家**关孝和**（1683）与德国数学家**莱布尼茨**几乎同时提出**行列式**，用来判断方程组是否有唯一解。
- **19 世纪（英国 / 爱尔兰）**：数学家 **阿瑟·凯莱（Arthur Cayley）** 在 1858 年正式把"矩阵"当作可参与运算的数学对象；**威廉·哈密顿** 提出"线性算子"思想。之后"向量、矩阵、线性变换"被统称为**线性代数**。
- **20 世纪（现代）**：计算机出现后，线性代数成为数值计算的地基；深度学习让"大规模矩阵乘法"成为全世界消耗算力最大的运算，也把 GPU 推上了王座。

> 🧠 一句话记住：**线性代数 = 用"数表"描述世界，用"运算"变换世界。**

---

### 1.2 标量、向量、矩阵、张量：数据的四种"容器"

想象你要记录水果店的库存：

- **标量（Scalar）**：一个数。比如"今天苹果 20 个"，记作 $x=20$。
- **向量（Vector）**：一列数。比如"苹果 20、梨 15、香蕉 30"：

$$
\mathbf{x} = \begin{bmatrix} 20 \\ 15 \\ 30 \end{bmatrix}
$$

  向量可以看作**空间中的一个箭头**：在"苹果轴"上走 20 格，"梨轴"上走 15 格，"香蕉轴"上走 30 格。

- **矩阵（Matrix）**：一个"数表"。比如记录 3 天的库存：

$$
A = \begin{bmatrix} 20 & 15 & 30 \\ 18 & 20 & 25 \\ 22 & 12 & 28 \end{bmatrix}
$$

- **张量（Tensor）**：维度 ≥ 3 的"数据盒子"。一张 RGB 彩色图是（高，宽，3 通道）的三维张量；一批图片就是四维张量。深度学习中"张量"≈"任意维数组"。

```python
import numpy as np

scalar = 20                          # 标量
vector = np.array([20, 15, 30])      # 向量（1 维）
matrix = np.array([[20, 15, 30],
                   [18, 20, 25],
                   [22, 12, 28]])    # 矩阵（2 维）
tensor = np.zeros((3, 4, 4, 3))      # 3 张 4x4 的 RGB 图（4 维）

print("向量形状:", vector.shape)       # (3,)
print("矩阵形状:", matrix.shape)       # (3, 3)
```

> 🖼️ 直观理解：**点（标量）→ 箭头（向量）→ 表格（矩阵）→ 数据盒子（张量）**。

### 1.3 向量的运算：加、减、数乘、点积

#### 加法、减法与数乘（几何直觉）

两个向量相加 = **把两个箭头首尾相接**；相减 = 从一个箭头指向另一个；数乘 = **拉长/缩短箭头**（负数是掉头）。

```python
a = np.array([1, 2])
b = np.array([3, -1])

a_plus_b = a + b      # [4, 1]：先走 a 再走 b
doubled  = 2 * a      # [2, 4]：箭头拉长一倍
```

#### 点积（Dot Product）：机器学习里最重要的运算之一

两个同长度向量的点积定义为：

$$
\mathbf{a} \cdot \mathbf{b} = a_1 b_1 + a_2 b_2 + \cdots + a_n b_n = \sum_{i=1}^{n} a_i b_i
$$

它还有完全等价的几何形式：

$$
\mathbf{a} \cdot \mathbf{b} = \lVert \mathbf{a} \rVert \, \lVert \mathbf{b} \rVert \, \cos\theta
$$

其中 $\theta$ 是两个向量的夹角，$\lVert \mathbf{a} \rVert = \sqrt{a_1^2 + \cdots + a_n^2}$ 是向量长度（**范数**）。

这个公式揭示了点积的本质：

> **点积 = "一个向量在另一个向量方向上的投影长度" × "另一个向量的长度"。**

三个结论请记牢（后面注意力机制全靠它们）：

- 方向相同（$\theta=0$）：点积最大 → 两个向量"最像"。
- 方向垂直（$\theta=90°$）：点积 = **0** → 两个向量"无关"，叫**正交**。
- 方向相反（$\theta=180°$）：点积为负数 → 两个向量"最不像"。

所以 **点积天然就是一种"相似度打分"**。大模型的注意力机制，就是先算词向量两两的点积来打分。

把长度的影响去掉、只看方向，就得到**余弦相似度**（范围 $[-1, 1]$）：

$$
\cos\theta = \frac{\mathbf{a} \cdot \mathbf{b}}{\lVert \mathbf{a} \rVert \, \lVert \mathbf{b} \rVert}
$$

```python
a = np.array([1, 2, 3])
b = np.array([2, 1, 0])

dot = np.dot(a, b)                        # 点积 = 1*2 + 2*1 + 3*0 = 4
norm_a = np.linalg.norm(a)                # 长度（欧几里得范数）
cos_sim = dot / (norm_a * np.linalg.norm(b))

print("点积:", dot)                        # 4
print("余弦相似度:", round(cos_sim, 4))     # 越接近 1 越像
```

> 🌰 生动例子：向量可以当作"口味档案"。"苹果口味向量"（甜度 9，酸度 2，脆度 7）和"梨口味向量"（甜度 8，酸度 1，脆度 5）点积很大，说明**这俩口味很像**——推荐系统正是靠这种"档案相似度"给你推荐东西。

### 1.4 线性组合、张成空间、基

把若干个向量**各自缩放后再相加**，得到的新向量称为它们的**线性组合**：

$$
\mathbf{v} = c_1 \mathbf{v}_1 + c_2 \mathbf{v}_2 + \cdots + c_k \mathbf{v}_k
$$

例如 $\mathbf{v}_1=(1,0)$、$\mathbf{v}_2=(0,1)$ 的组合 $3\mathbf{v}_1 + 4\mathbf{v}_2 = (3,4)$。

- **张成（Span）**：用这些向量能组合出的**所有**向量的集合。$(1,0)$ 和 $(0,1)$ 张成整个平面。
- **线性无关（Linearly Independent）**：任何一个向量都不能由其他向量组合出来。$(1,0)$、$(0,1)$ 线性无关；$(1,2)$、$(2,4)$ 线性相关（后者是前者的 2 倍）。
- **基（Basis）**：一组"恰好能张成整个空间、又线性无关"的向量。最常见的基是标准基 $\mathbf{e}_1=(1,0)$、$\mathbf{e}_2=(0,1)$。

> 🧭 类比：**基 = 坐标系里的一对箭头**。任何点 $(x,y)$ 都能写成"沿第一个箭头走 $x$ 步、沿第二个箭头走 $y$ 步"。换一套箭头（换基），同一个点的坐标就变了——机器学习的"特征变换"经常就是在换坐标系。

> 🌰 生动例子：零花钱 = "每天固定 10 元" + "每个满分奖 50 元"。这两个"规矩"就是一组基；一周零花钱 = $7 \times 10 + \text{满分次数} \times 50$，就是一个线性组合。

### 1.5 矩阵：表格，更是一台"变形机器"

#### 矩阵是什么

矩阵有两种看待方式，都要会用：

1. **数据表格**：行是样本、列是特征（成绩表、股价表）。
2. **线性变换（Linear Transformation）**：一个矩阵就是一整套"把空间里的箭头搬一搬"的规则。**这种视角是深度学习的核心**，因为神经网络的一层就是 $y = Wx$——用矩阵 W 把输入向量 x 变成输出向量 y。

#### 矩阵乘法：为什么是"行 × 列"？

设 $A$ 是 $m \times n$ 矩阵，$B$ 是 $n \times p$ 矩阵，乘积 $C = AB$ 是 $m \times p$ 矩阵，其中：

$$
C_{ij} = \sum_{k=1}^{n} A_{ik} B_{kj}
$$

即：**$C$ 的第 $i$ 行第 $j$ 列 = $A$ 第 $i$ 行与 $B$ 第 $j$ 列的点积**。

用例子走一遍（$n=2$）：

$$
A = \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix},\quad
B = \begin{bmatrix} 5 & 6 \\ 7 & 8 \end{bmatrix}
$$

$$
AB = \begin{bmatrix} 1\times5+2\times7 & 1\times6+2\times8 \\ 3\times5+4\times7 & 3\times6+4\times8 \end{bmatrix}
   = \begin{bmatrix} 19 & 22 \\ 43 & 50 \end{bmatrix}
$$

四个关键性质（务必记牢）：

- **不满足交换律**：一般 $AB \neq BA$。"先转 90° 再平移" 和 "先平移再转 90°" 结果不同。
- **满足结合律**：$A(BC) = (AB)C$。
- 行列维度必须匹配：$A_{m\times n} B_{n\times p}$ 中间维度 $n$ 必须相同，结果的形状是 $m\times p$。
- 行数 = 矩阵乘法总运算量：$mnp$ 次乘加。**GPU 快，就是因为能把海量这样的乘加并行做掉**。

```python
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

C = A @ B          # @ 就是矩阵乘法
print(C)           # [[19 22]
                   #  [43 50]]

print(A @ B == B @ A)   # 一般不等
```

> 🌰 生动例子：一张价目表（商品 × 单价）乘以一份"采购清单"（商品 × 数量），得到"总价"。行是商品、列是价格/数量，矩阵乘法就是把两套信息"撮合"在一起——**第一个矩阵的行信息 × 第二个矩阵的列信息**。

#### 两种最有用的特殊矩阵

- **单位矩阵 $I$**：对角线上全是 1、其余是 0，作用相当于"乘法里的 1"：$AI = IA = A$。
- **转置 $A^T$**：把行列互换。$A^T_{ij} = A_{ji}$。用途：把"列向量约定"互相转换，比如把行向量 $\mathbf{x}$ 转成列向量来参与矩阵运算。

$$
I = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix},\qquad
A = \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix},\quad
A^T = \begin{bmatrix} 1 & 3 \\ 2 & 4 \end{bmatrix}
$$

### 1.6 线性变换：用矩阵"搬动"整个空间

一个 $2\times2$ 矩阵如何变换一个平面？只需要看两件事：**原来的两个基向量 $\mathbf{e}_1=(1,0)$、$\mathbf{e}_2=(0,1)$ 分别被搬到了哪里**。矩阵的两列，恰好就是这两个基向量被搬动后的新位置。

$$
A = \begin{bmatrix} a & c \\ b & d \end{bmatrix}
\quad\Longleftrightarrow\quad
\mathbf{e}_1 \to \begin{bmatrix} a \\ b \end{bmatrix},\quad
\mathbf{e}_2 \to \begin{bmatrix} c \\ d \end{bmatrix}
$$

常见的 2D 变换：

| 变换 | 矩阵 | 效果 |
| --- | --- | --- |
| 水平缩放 | $\begin{bmatrix} 3 & 0 \\ 0 & 1 \end{bmatrix}$ | 横向拉长 3 倍 |
| 旋转 90° | $\begin{bmatrix} 0 & -1 \\ 1 & 0 \end{bmatrix}$ | 整个平面转 90° |
| 剪切 | $\begin{bmatrix} 1 & 1 \\ 0 & 1 \end{bmatrix}$ | 把正方形压成斜的平行四边形 |
| 投影到 x 轴 | $\begin{bmatrix} 1 & 0 \\ 0 & 0 \end{bmatrix}$ | 所有点被"压平"到一条直线 |

> 🧭 类比：投影矩阵把 3D 世界拍成 2D 照片——**信息被压缩、维度降低了**。这正是"降维"思想（后面 PCA、SVD）的几何来源。

```python
shear = np.array([[1, 1], [0, 1]])
square = np.array([[0, 1, 1, 0], [0, 0, 1, 1]])   # 正方形四个顶点
moved = shear @ square                             # 变成平行四边形
print(moved)
```

> 神经网络为什么"想"用很多层？因为**单层矩阵只能做线性变换（直线还是直线）**，而多层 + 非线性激活函数（如 ReLU）才能把平面"揉皱"，拟合任意复杂的形状——这就是"深度"的几何意义。

### 1.7 行列式：变换的"缩放系数"

行列式（Determinant）衡量一个线性变换**把面积（或体积）放大/缩小了多少倍**：

$$
\det(A) = \begin{vmatrix} a & b \\ c & d \end{vmatrix} = ad - bc
$$

例子：矩阵 $\begin{bmatrix} 3 & 0 \\ 0 & 2 \end{bmatrix}$ 把正方形从 1×1 变成 3×2，面积放大 6 倍，恰好 $\det = 3\times2 - 0 = 6$。

两个关键结论：

- $\det(A) = 0$：变换把平面**压成一条线或一个点**（信息丢失，矩阵不可逆）。
- $\det(A) < 0$：变换**翻转了空间的方向**（镜像）。

3×3 行列式（对角线法则）：

$$
\det\begin{bmatrix} a & b & c \\ d & e & f \\ g & h & i \end{bmatrix}
= aei + bfg + cdh - ceg - bdi - afh
$$

```python
A = np.array([[3, 0], [0, 2]])
print(np.linalg.det(A))      # 6.0：面积放大 6 倍
```

> 🌰 生动例子：把行列式想成"复印机的缩放倍率"。倍率 6 表示面积放大 6 倍；倍率 0 表示**复印出来是一条线**（东西被压扁了，回不去原来的样子）。

### 1.8 逆矩阵与线性方程组

#### 从方程组到矩阵方程

$$
\begin{cases} 2x + y = 5 \\ x - y = 1 \end{cases}
\quad\Longleftrightarrow\quad
\underbrace{\begin{bmatrix} 2 & 1 \\ 1 & -1 \end{bmatrix}}_{A}
\underbrace{\begin{bmatrix} x \\ y \end{bmatrix}}_{\mathbf{x}}
=
\underbrace{\begin{bmatrix} 5 \\ 1 \end{bmatrix}}_{\mathbf{b}}
$$

解方程组 = 找到 $\mathbf{x}$ 使得 $A\mathbf{x} = \mathbf{b}$。

#### 逆矩阵：撤销变换

如果存在 $A^{-1}$ 使得 $A^{-1}A = AA^{-1} = I$，那么：

$$
\mathbf{x} = A^{-1}\mathbf{b}
$$

$2\times2$ 的逆矩阵公式：

$$
A^{-1} = \frac{1}{ad-bc} \begin{bmatrix} d & -b \\ -c & a \end{bmatrix}
$$

**注意分母就是 $\det(A)$**：行列式为 0 时没有逆（变换把空间压扁了，无法撤销）→ 这类矩阵称为**奇异矩阵**，方程组要么无解要么有无穷多解。

#### 高斯消元法：计算机真正用的方法

实际计算不会用逆矩阵公式（太慢），而是用《九章算术》就有雏形的**高斯消元**：把增广矩阵 $[A \mid \mathbf{b}]$ 通过"行加减、行交换、行乘常数"化成上三角，再回代求解。

$$
\begin{bmatrix} 2 & 1 & \mid & 5 \\ 1 & -1 & \mid & 1 \end{bmatrix}
\to \begin{bmatrix} 2 & 1 & \mid & 5 \\ 0 & -\frac{3}{2} & \mid & -\frac{3}{2} \end{bmatrix}
\implies y=1,\ x=2
$$

```python
A = np.array([[2, 1], [1, -1]])
b = np.array([5, 1])

x = np.linalg.solve(A, b)      # 高斯消元（LAPACK 实现）
print(x)                        # [2. 1.]

A_inv = np.linalg.inv(A)
print(A_inv @ b)                # 同样得到 [2. 1.]（可逆时）
```

> 🌰 生动例子：把 $A$ 想成"咖啡萃取机"（豆子 → 咖啡），逆矩阵就是"时光机"（咖啡 → 豆子）。萃取机把空间压扁了（行列式 = 0，比如两种豆子磨出来味道一样），你就无法从结果反推过程。

### 1.9 特征值与特征向量：变换的"主轴"

#### 定义

对于一个方阵 $A$，如果存在非零向量 $\mathbf{v}$ 和数 $\lambda$，使得：

$$
A\mathbf{v} = \lambda \mathbf{v}
$$

那么 $\mathbf{v}$ 叫 **特征向量**，$\lambda$ 叫 **特征值**。意思是：**被 $A$ 变换后，这个向量方向不变，只是被拉长/缩短了 $\lambda$ 倍**。

> 🧭 生动例子：地球自转时，**两极的轴心方向不变**——那就是旋转的特征方向。对任何变换，总有一些"主轴"方向在变换后仍然稳稳当当。

#### 怎么求（2×2 例子）

$$
A = \begin{bmatrix} 2 & 1 \\ 1 & 2 \end{bmatrix},\qquad
\det(A - \lambda I) = 0
$$

$$
\begin{vmatrix} 2-\lambda & 1 \\ 1 & 2-\lambda \end{vmatrix}
= (2-\lambda)^2 - 1 = 0 \implies \lambda = 1 \text{ 或 } 3
$$

对应特征向量：$\lambda=3 \to \mathbf{v}=(1,1)$；$\lambda=1 \to \mathbf{v}=(1,-1)$。验证：$A(1,1) = (3,3) = 3(1,1)$。✅

#### 特征分解（Eigendecomposition）

把 $n$ 个特征向量拼成矩阵 $V$、特征值写成对角阵 $\Lambda$：

$$
A = V \Lambda V^{-1}
$$

> 直觉：**任何线性变换 = "旋转到主轴系 → 沿各主轴各自缩放 → 旋转回去"**。这个视角把对矩阵的理解从"元素"提升到"方向 + 倍率"。

#### 应用：主成分分析（PCA）

**PCA 是特征分解最著名的机器学习应用之一**。核心思想：把高维数据投影到"数据变化最大"的几个方向上，实现降维、去噪、可视化。

- 数据先中心化（减去均值）。
- 计算协方差矩阵 $\Sigma = \frac{1}{n}X^TX$。
- 求 $\Sigma$ 的特征值排序，取前 $k$ 个最大特征值对应的特征向量作为"主方向"。
- 特征值越大 → 这个方向上数据波动越大 → 信息越多。

```python
# 二维数据降为一维（PCA 最简版）
rng = np.random.default_rng(0)
X = rng.normal(size=(100, 2))
X = X @ np.array([[3, 0], [0, 0.5]])   # 制造一个"长条状"数据
X = X - X.mean(axis=0)                  # 中心化

cov = X.T @ X / X.shape[0]
eigvals, eigvecs = np.linalg.eigh(cov)  # 特征值升序
top1 = eigvecs[:, -1]                   # 最大特征值对应的方向
proj = X @ top1                         # 投影到一维

print("最大特征值方向:", top1)           # 应该接近 (1, 0)
print("投影后方差:", proj.var())
```

> 📌 关联预告：**PCA 和后面讲的 SVD 是"亲戚"**；LLM 里的词向量（Word2Vec 等）也常用 SVD/PCA 做可视化和降维；"注意力"里的投影矩阵 $W_Q, W_K, W_V$ 则是学习出来的"任意变换"。

### 1.10 奇异值分解（SVD）："特征分解"的万能版

任何矩阵（不要求方阵）都能分解：

$$
A_{m \times n} = U_{m \times m} \, \Sigma_{m \times n} \, V^T_{n \times n}
$$

- $U$、$V$ 是正交矩阵（各列互相垂直、长度为 1）。
- $\Sigma$ 是对角阵，对角线上的 $\sigma_1 \ge \sigma_2 \ge \cdots$ 称为**奇异值**，衡量每个"主轴方向"的重要性。

> 直观意义：$SVD = $ "旋转 → 沿各主方向缩放（$\sigma_i$）→ 再旋转"。奇异值越大，该方向越重要。

两层应用：

**1. 低秩近似（压缩）**：只保留前 $k$ 个最大的奇异值，用 $A \approx U_k \Sigma_k V_k^T$ 近似原矩阵。图像压缩、推荐系统（矩阵补全）都靠它。

**2. 与 PCA 的关系**：对中心化数据，$X = U\Sigma V^T$，则 $X^TX = V\Sigma^2 V^T$——**$V$ 的列就是 PCA 的主方向，$\sigma_i^2$ 就是协方差矩阵的特征值**。

```python
A = np.array([[1, 0, 0], [0, 0.3, 0]])   # 一个"几乎压扁"的矩阵
U, S, Vt = np.linalg.svd(A)

print("奇异值:", S)        # [1.  0.3]：第二个方向重要性差很多
A_approx = U[:, :1] * S[0] @ Vt[:1, :]    # 只保留第一个奇异值
print("近似误差:", np.abs(A - A_approx).max())
```

### 1.11 线性代数 × LLM：把概念全串起来

一个 GPT 风格模型在推理时，每个 token（词）都是一个**向量**，整句话就是**一个矩阵**。关键步骤对应的代数：

| LLM 里的部件 | 数学本质 | 用到的本章概念 |
| --- | --- | --- |
| 输入嵌入 | 查表：token ID → 向量 | 向量、矩阵 |
| 位置编码 | 给每个位置加一个特征向量 | 向量加法 |
| 注意力打分 | $QK^T$：词与词两两点积 | 点积、相似度 |

| 参数总量 | 所有 $W$ 的元素个数 | 矩阵形状、乘加次数 |

## 2. 微积分：教模型如何变好

线性代数告诉我们**数据长什么样**；微积分则负责回答机器学习里最核心的问题：

> **"参数往哪个方向调，结果才会变好？"**

### 2.1 起源故事：牛顿与莱布尼茨的"世纪之争"

- **古希腊（芝诺悖论）**：追乌龟的悖论让人们意识到，"瞬间的速度"是一个棘手的概念——**极限**的思想萌芽于此。
- **17 世纪（英国 / 德国）**：**牛顿**用"流数术"研究行星运动和物理变化，**莱布尼茨**独立发明了微分与积分记号（$\frac{dy}{dx}$、$\int$），两人为此争论了几十年。
- **19 世纪（法国 / 德国）**：**柯西**与**魏尔斯特拉斯**用严格的 $\epsilon$-$\delta$ 语言给"极限"补上了逻辑地基，微积分才成为严谨的数学。
- **20 世纪（现代）**：微积分成为优化的基础。深度学习中的**反向传播算法（1986）**本质上是"链式法则 + 自动微分"的工程实现。

> 🧠 一句话记住：**微积分 = 研究"变化"和"积累"的学问。机器学习只关心其中一半：怎样找到让损失函数最小的那个点。**

---

### 2.2 极限：从"平均速度"到"瞬时速度"

开车 1 小时走了 60 公里，平均速度 60 km/h。但"此刻的速度表显示多少"？答案是：让时间间隔 $\Delta t$ 无限缩小：

$$
v(t) = \lim_{\Delta t \to 0} \frac{s(t+\Delta t) - s(t)}{\Delta t}
$$

符号 $\lim$ 读作"极限"：**当间隔小到不能再小的时候，比值会趋近于哪个数**。

> 🌰 生动例子：想测一辆车"冲过终点一瞬间"的速度，不能靠"平均",只能让测量窗口越来越短。**极限就是"测量窗口无限短"的那一瞬间的速度。**

### 2.3 导数：函数在某一点的"斜率"

#### 定义

$$
f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}
$$

几何意义：曲线 $y=f(x)$ 在点 $x$ 处的**切线斜率**。物理意义：**变化率**。

> 🧭 爬山类比：导数 = 脚下山坡的坡度。正数意味着往上走，负数意味着往下走，0 意味着平路（可能在山顶或山脚——**极值点**）。

#### 常用导数表（机器学习 90% 的时间只要这几个）

| 函数 $f(x)$ | 导数 $f'(x)$ | 备注 |
| --- | --- | --- |
| $x^n$ | $n x^{n-1}$ | 幂函数 |
| $e^x$ | $e^x$ | 指数函数（导数还是它自己！） |
| $\ln x$ | $\dfrac{1}{x}$ | 对数函数 |
| $a^x$ | $a^x \ln a$ | 一般指数 |
| $\sin x$ | $\cos x$ | 三角函数 |
| $\cos x$ | $-\sin x$ | 三角函数 |
| $C$（常数） | $0$ | 常数 |
| $f(x)+g(x)$ | $f'(x)+g'(x)$ | 加法法则 |
| $f(x)\cdot g(x)$ | $f'(x)g(x) + f(x)g'(x)$ | 乘法法则 |

#### 数值求导：计算机验证

```python
def numerical_derivative(f, x, h=1e-6):
    return (f(x + h) - f(x - h)) / (2 * h)   # 中心差分，误差更小

f = lambda x: x ** 2
print("d(x^2)/dx at x=3:", numerical_derivative(f, 3))   # ≈ 6.0
print("理论值: 2*3 =", 2 * 3)

g = lambda x: np.exp(x)
print("d(e^x)/dx at x=1:", numerical_derivative(g, 1))   # ≈ e ≈ 2.718，e^x 的导数还是 e^x
```

> 💡 为什么机器学习里"指数函数"到处都是？因为 $e^x$ 的导数是它自己，**在求梯度时能大量简化算式**；softmax、指数分布、高斯分布全都有 $e$ 的身影。

### 2.4 偏导数与梯度：多变量的下坡方向

损失函数不只有一个输入，而是有成百上千个参数：$L(w_1, w_2, \dots, w_n)$。

#### 偏导数

**偏导数** $\dfrac{\partial L}{\partial w_i}$ 表示：固定其他参数不动，只让 $w_i$ 动一点点，$L$ 变化多少。就像问："只调整第 1 个旋钮，效果变多少？"

#### 梯度（Gradient）

把所有偏导数排成一个向量：

$$
\nabla L = \begin{bmatrix} \dfrac{\partial L}{\partial w_1} \\ \dfrac{\partial L}{\partial w_2} \\ \vdots \\ \dfrac{\partial L}{\partial w_n} \end{bmatrix}
$$

梯度的两个黄金性质：

1. **$\nabla L$ 指向 $L$ 上升最快的方向**（登山时最陡的路）。
2. **$-\nabla L$ 指向下降最快的方向**（下山最省力的路）。

> 🧭 生动例子：你在山坡上一团雾里，看不到远处，只有脚下的坡度。**梯度下降 = 每次只朝"当前脚下最陡的下坡方向"迈一小步**，走很多步就能到山谷（损失最小）。

```python
def numerical_gradient(f, params, h=1e-6):
    grad = np.zeros_like(params, dtype=float)
    for i in range(len(params)):
        p_plus = params.copy();  p_plus[i] += h
        p_minus = params.copy(); p_minus[i] -= h
        grad[i] = (f(p_plus) - f(p_minus)) / (2 * h)
    return grad

L = lambda w: (w[0] - 3) ** 2 + (w[1] + 1) ** 2   # 碗状函数，最低点在 (3, -1)
print("梯度 at (0, 0):", numerical_gradient(L, np.array([0.0, 0.0])))
# ≈ [-6, 2]：往 (3, -1) 方向走，x 增加、y 减少
```

### 2.5 链式法则：复合函数的"接力赛"

$$
\frac{dz}{dx} = \frac{dz}{dy} \cdot \frac{dy}{dx}
$$

如果 $y = g(x)$，$z = f(y)$，那么 $z$ 对 $x$ 的变化率 = 两段变化率的乘积。

> 🏭 生动例子：工厂流水线——"面粉 → 面团 → 面包"。**面粉涨价 10%（$\frac{dy}{dx}$），面包店乘 2 倍定价（$\frac{dz}{dy}$），面包价格就涨 20%（$\frac{dz}{dx}$）**。每一段的敏感度相乘，就是整条链子的敏感度。

神经网络就是一个"超长流水线"：输入 $x \to$ 线性层 $\to$ 激活函数 $\to$ 线性层 $\to \cdots \to$ 损失 $L$。**反向传播 = 从损失出发，把每一段链式法则的乘积逐层传回去**，算出每个参数该往哪调。

### 2.6 积分：变化率的"逆运算"（了解一下）

积分解决"**累积**"问题：知道每时每刻的速度，问 1 小时走了多远？

$$
\int_a^b f(x)\, dx = \lim_{n\to\infty}\sum_{i=1}^{n} f(x_i) \Delta x
$$

直觉：把 $[a,b]$ 切成无数细条，每条高 $f(x_i)$、宽 $\Delta x$，**面积加总**。

**牛顿-莱布尼茨公式**（微积分基本定理）把微分和积分连起来：

$$
\int_a^b f(x)\, dx = F(b) - F(a), \qquad F'(x) = f(x)
$$

> 与 ML 的关联：概率分布"曲线下的面积"就是概率——连续型随机变量的概率计算本质是积分；期望（平均值）也是积分。后面概率章节会用到。

### 2.7 最优化：怎么找到"损失最小"的参数

#### 损失函数（Loss Function）

用一个数衡量"模型错得多离谱"。最常见的有：

- **均方误差 MSE**（回归任务）：$L = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$
- **交叉熵 Cross-Entropy**（分类 / LLM 的下一个词预测）：$L = -\frac{1}{n}\sum_{i=1}^{n}\sum_{k} y_{ik}\log \hat{y}_{ik}$

#### 梯度下降（Gradient Descent）算法

从任意起点出发，重复两步：

$$
\mathbf{w} \leftarrow \mathbf{w} - \eta \, \nabla L(\mathbf{w})
$$

- $\eta$（学习率）是**步长**：太大一步跨过山谷，太小走得太慢。
- 直到梯度接近 0（到达谷底）或设定好的迭代次数用完。

```python
def gradient_descent(grad_fn, w0, lr=0.1, steps=50):
    w = np.array(w0, dtype=float)
    history = []
    for _ in range(steps):
        w = w - lr * grad_fn(w)
        history.append(w.copy())
    return w, history

grad_L = lambda w: np.array([2 * (w[0] - 3), 2 * (w[1] + 1)])   # 解析梯度
w_star, _ = gradient_descent(grad_L, [0.0, 0.0])
print("收敛到:", w_star)        # 接近 [3, -1]，即损失最低点
```

#### 凸 vs 非凸：为什么深度学习训练"没有保证"

- **凸函数**（如 $w^2$）：只有一个碗底，梯度下降**保证**到达全局最低点。
- **非凸函数**：有多个"假山谷"（局部极小值）和"马鞍"（鞍点）。深度学习的损失面极度非凸，训练只能说"尽量找到够好的谷底"。

> 🌰 生动例子：凸函数像一个碗，闭着眼扔球也会滚到碗底；深度网络像一片山地，球容易卡在**假山谷**里——这就是为什么需要随机初始化、学习率调度和各种优化技巧。

### 2.8 反向传播：链式法则的"工程实现"

以最简单的一层网络 + 均方误差为例：

$$
y = wx + b, \qquad L = \frac{1}{2}(y - y_{true})^2
$$

求 $\frac{\partial L}{\partial w}$：用链式法则一路拆：

$$
\frac{\partial L}{\partial w} = \frac{\partial L}{\partial y} \cdot \frac{\partial y}{\partial w}
= (y - y_{true}) \cdot x
$$

同理 $\frac{\partial L}{\partial b} = y - y_{true}$。就这么简单——**误差 $(y - y_{true})$ 沿着计算图"倒着"乘回去**。

```python
# 手工实现一个"微型 autograd"：前向传播 + 反向传播
def forward(x, w, b):
    y = w * x + b              # 前向
    L = 0.5 * (y - 4) ** 2    # 假想真实值 4
    return y, L

def backward(x, w, b):
    y, _ = forward(x, w, b)
    dL_dy = (y - 4)           # 链式法则第一段
    dy_dw = x                 # 第二段
    dy_db = 1
    return dL_dy * dy_dw, dL_dy * dy_db

x, w, b = 2.0, 0.5, 0.0
for _ in range(100):
    dw, db = backward(x, w, b)
    w -= 0.1 * dw
    b -= 0.1 * db
print("训练后 y =",  w * x + b)   # 输出接近 4
```

> 🏭 再回到流水线类比：前向传播是"面粉 → 面包"，反向传播是"面包价格波动 → 反推哪道工序最敏感"，从而知道**该改哪个环节**。

### 2.9 微积分 × LLM：几十亿参数是怎么训练的

- GPT 的训练目标：最大化"真实下一个词"的概率，等价于**最小化交叉熵损失**。
- 每迭代一步：前向传播算出所有词的预测概率 → 算损失 → **反向传播把梯度传遍每一层** → 用梯度下降（及其进化版 Adam）更新全部参数。
- 一次更新要算**数十亿个参数的梯度**，靠的是：自动微分 + GPU 并行 + 精巧的分布式设计。
- 学习率太大/太小、梯度消失/爆炸，都与微积分的性质直接相关（例如 ReLU 缓解梯度消失，就是因为它梯度恒为 1）。

> 💡 如果你只能记住一件事：**神经网络就是"用链式法则反向传播梯度，再用梯度下降调整参数来降低损失"**。

## 3. 概率与统计：处理不确定性

机器学习面向的核心现实是：**世界充满不确定性，数据是随机采样的**。"这个人明天会买这个商品吗？""下一个词最可能是什么？"——我们用概率回答。

### 3.1 起源故事：从赌注到科学

- **1654 年（法国）**：赌徒德·梅雷向数学家**帕斯卡**请教"赌局中断后赌金怎么分"，帕斯卡与**费马**通信解决该问题——**概率论诞生**。流传说法：这件事源于一个赌注问题，因此概率论常被称为"从赌桌上学来的数学"。
- **1763 年（英国）**：**托马斯·贝叶斯**去世后发表的论文提出了"由结果反推原因"的方法，即**贝叶斯定理**。
- **18-19 世纪（法国）**：**拉普拉斯**把概率论系统化，写出《分析概率论》；**高斯**在误差分析中提出**正态分布**（钟形曲线）。
- **20 世纪**：频率派与贝叶斯派的方法论之争延续至今；统计学习、强化学习、现代 LLM 全部建立在这套语言之上。

> 🧠 一句话记住：**概率 = 用数字表达"不确定"，统计 = 从数据里反推"概率"。**

---

### 3.2 概率基础：样本空间、事件、概率公理

- **样本空间 $\Omega$**：所有可能结果的集合。掷骰子：$\{1,2,3,4,5,6\}$。
- **事件**：某些结果的集合。如"掷出偶数" = $\{2,4,6\}$。
- **概率 $P$**：给每个事件一个 $[0,1]$ 的数，并满足三条公理：
  - $P(\Omega) = 1$（总概率是 1）
  - $0 \le P(A) \le 1$
  - 互斥事件相加：$P(A \cup B) = P(A) + P(B)$（A、B 不同时发生）

> 🌰 生动例子：抛一枚公平硬币，"正面"概率 $\frac{1}{2}$。抛 10 次，想知道"恰好 5 次正面"的概率，就需要组合数学（二项分布），这既是赌场里的问题，也是**语言模型按概率生成文本**的数学基础。

#### 联合概率与边缘概率

- $P(A, B)$（联合概率）：A 和 B 同时发生。
- $P(A) = \sum_b P(A, B=b)$（边缘概率）：把所有 B 的情况加总，"挤出"A 的概率。

> 📌 关联：LLM 输出"今天 / 天气"的联合分布 $P(\text{今天},\text{天气})$，而生成文本时我们逐词地按条件概率"边缘化"推进。

---

### 3.3 条件概率与贝叶斯定理：由果溯因

**条件概率** $P(A \mid B)$ = "已知 B 发生的前提下，A 发生的概率"：

$$
P(A \mid B) = \frac{P(A, B)}{P(B)}
$$

由此可推出大名鼎鼎的**贝叶斯定理**：

$$
P(A \mid B) = \frac{P(B \mid A) \, P(A)}{P(B)}
$$

它把"知道了结果 B 之后，原因 A 的概率"和"原因 A 下出现结果 B 的概率"联系起来。

#### 🌰 生动例子 1：疾病检测

某种罕见病患病率 $P(病) = 0.1\%$；检测法在患病时 99% 检出（真阳性率），健康时 5% 误报（假阳性率）。你检测阳性，真有病的概率是多少？

$$
P(病 \mid 阳性) = \frac{0.99 \times 0.001}{0.99 \times 0.001 + 0.05 \times 0.999} \approx 1.94\%
$$

**只约 2%！** 反直觉但千真万确——因为健康人基数太大，5% 的误报会产生大量"假阳性"。这正是"先验概率"的力量，也是贝叶斯推理能纠正直觉的地方。

```python
p_disease = 0.001
p_pos_given_disease = 0.99
p_pos_given_healthy = 0.05

p_pos = p_pos_given_disease * p_disease + p_pos_given_healthy * (1 - p_disease)
p_disease_given_pos = p_pos_given_disease * p_disease / p_pos
print(f"阳性者真有病的概率: {p_disease_given_pos:.2%}")   # ≈ 1.94%
```

#### 🌰 生动例子 2：垃圾邮件过滤（朴素贝叶斯）

邮件里有"免费"这个词，是垃圾邮件的概率是多少？先统计训练数据：

- 垃圾邮件中 30% 含"免费"：$P(免费 \mid 垃圾) = 0.3$
- 正常邮件中 2% 含"免费"：$P(免费 \mid 正常) = 0.02$
- 垃圾邮件占比 $P(垃圾) = 0.2$

$$
P(垃圾 \mid 免费) = \frac{0.3 \times 0.2}{0.3 \times 0.2 + 0.02 \times 0.8} \approx 79\%
$$

> 🧠 贝叶斯公式的骨架：**后验 $\propto$ 似然 $\times$ 先验**。机器学习里"训练 = 用数据把先验更新成后验"。

### 3.4 随机变量与常见分布

**随机变量**：把随机试验的结果映射成数字。分两类：

- **离散型**：掷骰子的点数、句子里"下一个词是哪个"。
- **连续型**：身高、温度、embedding 向量里的实数值。

描述一个分布的核心工具：离散用**概率质量函数** $P(X=x)$；连续用**概率密度函数** $f(x)$（曲线下的面积 = 概率，注意单点的概率为 0）。

#### 常见分布（机器学习最常用到的 5 个）

| 分布 | 用途 | 直觉例子 |
| --- | --- | --- |
| **伯努利**（0/1） | 单次"成功/失败" | 掷一次硬币是否正面 |
| **二项**（n 次独立） | 复读机式试验成功次数 | 抛 100 次硬币正面的次数 |
| **多项**（k 个类别） | 每次从 k 个类别选一个 | **LLM 在词表里选下一个词！** |
| **正态**（钟形曲线） | 误差、自然测量值 | 同年龄身高的分布 |
| **指数** | 等待时间 | 下一趟地铁还要等多长时间 |

#### 正态分布：统计学的心脏

$$
f(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)
$$

**68-95-99.7 法则**：均值 $\mu$ 附近 $\pm 1\sigma$ 内约 68% 的数据，$\pm 2\sigma$ 内约 95%，$\pm 3\sigma$ 内约 99.7%——体检报告"标准差"就是 $\sigma$。

```python
import numpy as np

rng = np.random.default_rng(42)
coins = rng.binomial(n=100, p=0.5, size=10000)       # 10000 次"抛 100 个硬币"
print("正面次数的均值:", coins.mean())                 # ≈ 50
print("正面次数的标准差:", coins.std())                # ≈ 5（= sqrt(100*0.5*0.5)）

heights = rng.normal(loc=170, scale=6, size=10000)   # 身高 ~ N(170, 6^2)
within_1sd = np.mean(np.abs(heights - 170) <= 6)
print("±1σ 内的比例:", round(within_1sd, 3))           # ≈ 0.68
```

#### 中心极限定理（Central Limit Theorem）

> **一堆独立随机变量的平均值，无论原来是什么分布，只要样本足够多，就近似服从正态分布。**

这就是"为什么到处都是钟形曲线"：测量误差、学生成绩、抽样均值……统统被"平均"成了正态。**统计推断的地基就是它。**

#### 🌰 LLM 关联：多项分布与 softmax

词表 $\mathcal{V}$ 有 5 万个词，模型对每个词给出一个分数（logits），用 **softmax** 变成概率：

$$
P(\text{词}_k) = \frac{e^{z_k}}{\sum_{j=1}^{|\mathcal{V}|} e^{z_j}}
$$

生成时从这个**多项分布**里按概率采样——这就是"模型在掷一个有 5 万个面的骰子"。

```python
def softmax(z):
    z = z - z.max()                    # 数值稳定：减去最大值防止溢出
    e = np.exp(z)
    return e / e.sum()

logits = np.array([2.0, 1.0, 0.1])
probs = softmax(logits)
print("softmax 后概率:", probs)         # 和为 1，最大 logit 对应最大概率
```

### 3.5 期望与方差：数据的"中心"和"离散程度"

**期望（Expectation）** = 加权平均：

$$
E[X] = \sum_x x\,P(X=x) \quad(\text{离散}),\qquad
E[X] = \int x\,f(x)\,dx \quad(\text{连续})
$$

**方差（Variance）** = 离中心平均偏了多少：

$$
\mathrm{Var}(X) = E[(X - E[X])^2]
$$

标准差 $\sigma = \sqrt{\mathrm{Var}(X)}$（和原始数据同单位，更直观）。

> 🌰 生动例子：两个班平均分都是 80。A 班人人都 79-81 分，B 班一半人 60、一半人 100。**期望相同，方差天差地别**——"平均分"会骗人，方差才告诉你数据到底散不散。

```python
class_a = np.array([80, 79, 81, 80, 80])
class_b = np.array([60, 100, 60, 100, 80])
print("A: 均值", class_a.mean(), "方差", round(class_a.var(), 2))
print("B: 均值", class_b.mean(), "方差", round(class_b.var(), 2))
```

> 📌 关联：LLM 训练时，跨样本求平均损失 = 估计"期望损失"；而我们关心模型会不会因随机初始化/随机数据而产生巨大方差（**不稳定**）。正则化、模型集成都是在压低方差。

---

### 3.6 协方差与相关性：两个变量一起怎么变

**协方差**衡量两个变量是否"同涨同跌"：

$$
\mathrm{Cov}(X, Y) = E[(X - E[X])(Y - E[Y])]
$$

**相关系数**把协方差归一化到 $[-1, 1]$：

$$
r = \frac{\mathrm{Cov}(X, Y)}{\sigma_X \sigma_Y}
$$

- $r$ 接近 1：正相关（身高越高，体重越大）。
- $r$ 接近 -1：负相关（车速越快，到达时间越短）。
- $r$ 接近 0：线性无关（不代表独立，可能有非线性关系）。

> 🌰 生动例子：**冰淇淋销量和溺水人数高度正相关**——但不是冰淇淋"导致"溺水，是共同原因"天热"。**相关 ≠ 因果**，这是数据科学最重要的戒律之一。

```python
height = np.array([160, 165, 170, 175, 180, 185])
weight = np.array([50, 55, 60, 63, 75, 80])
print("相关系数:", np.corrcoef(height, weight)[0, 1])   # 接近 1
```

> 📌 关联：协方差矩阵是 **PCA** 的输入（前文 1.9）；特征高度相关会导致模型冗余、不稳定。数据预处理中的标准化就是在控制方差/协方差的影响。

---

### 3.7 统计推断：从"样本"推断"总体"

现实里我们拿不到全体数据（总体），只能拿到一部分（样本），并用统计推断总体。

#### 大数定律与中心极限定理

- **大数定律**：样本量越大，样本均值越接近总体均值（抛 1000 次硬币，"正面比例"几乎就是 0.5）。
- **中心极限定理**：样本均值的分布近似正态，于是我们能给出误差界限。

#### 置信区间（Confidence Interval）

民意调查"支持率 52%，误差 ±3%，置信水平 95%"的含义是：**如果重复做很多次同样调查，约 95% 的区间会盖住真实支持率**。（注意：不是说"真实值 95% 概率在区间里"——这个微妙区别是统计学经典的易错点。）

```python
sample = rng.normal(loc=52, scale=10, size=400)      # 模拟 400 人调查
se = sample.std(ddof=1) / np.sqrt(len(sample))       # 标准误
ci = (sample.mean() - 1.96*se, sample.mean() + 1.96*se)
print("95% 置信区间:", np.round(ci, 2))
```

#### 假设检验与 p 值

流程：提出零假设（如"硬币是公平的"）→ 计算如果零假设为真，出现"这么极端数据"的概率（**p 值**）→ 若 p 很小（通常 < 0.05），认为零假设可疑，拒绝它。

> 🌰 生动例子：掷 100 次硬币，正面 95 次。若硬币公平，出现这么极端的结果概率极小（p < 0.001）。于是我们说"这不是运气，硬币大有问题"。**p 值缩水的对象是"假设"，不是"结论的正确性"。**

> 📌 关联：评估两个模型谁更好（A/B 测试）、对比训练前后表现，都要用这套"差异是不是偶然"的语言。

### 3.8 最大似然估计（MLE）：选让数据"最可能"的参数

给了一堆数据，假设它们来自某个带参数 $\theta$ 的分布，**MLE 选能让"看到这些数据"的概率最大的 $\theta$**：

$$
\hat{\theta}_{MLE} = \arg\max_{\theta} \prod_{i=1}^{n} P(x_i \mid \theta)
$$

（乘积转成对数求和更方便：$\log$ 把乘法变加法，且单调性不变。）

#### 🌰 例子：估计硬币正面概率

抛硬币 10 次，6 次正面。正面概率 $p$ 的似然是 $L(p) = p^6(1-p)^4$。求导令其为 0，得到 $\hat{p} = 0.6$。**MLE 的估计就是"出现的数据频率"**——这个结果非常符合直觉。

```python
from scipy.optimize import minimize_scalar

n_log_lik = lambda p: -(6 * np.log(p) + 4 * np.log(1 - p))   # 负对数似然
res = minimize_scalar(n_log_lik, bounds=(0.01, 0.99), method="bounded")
print("MLE 估计 p =", round(res.x, 3))                        # ≈ 0.6
```

> 📌 关联：**LLM 预训练的目标就是 MLE**——把"给定前文，最大化真实下一个词的概率"写作数学，正是极大似然。而"负对数似然"等价于交叉熵损失（下一节信息论会解释为什么）。

---

### 3.9 贝叶斯推断：把先验知识加进来

$$
P(\theta \mid \text{数据}) \propto \underbrace{P(\text{数据} \mid \theta)}_{\text{似然}} \times \underbrace{P(\theta)}_{\text{先验}}
$$

- MLE 只考虑似然；**贝叶斯**还允许你注入先验（领域知识、常识）。
- 数据少时先验主导，数据多时数据（似然）逐渐碾压先验——**后验随证据更新**。

> 🌰 生动例子：新邮件的"免费"出现频率和垃圾邮件比例一样（似然相同），但你之前的经验（先验）认为"科技订阅邮件也常带'免费'"——于是先验把判断往"正常"拉一点。**先验 = 你预装的经验。**

### 3.10 概率与统计 × LLM：一张图看懂语言模型

语言模型做的事就是估计条件概率：

$$
P(w_1, w_2, \dots, w_T) = \prod_{t=1}^{T} P(w_t \mid w_1, \dots, w_{t-1})
$$

生成过程 = **一遍遍从多项分布里采样下一个词**。几个工程细节背后的概率：

| LLM 概念 | 概率含义 |
| --- | --- |
| softmax | 把分数变成合法的概率分布 |
| 温度 temperature | 放大/缩小分布的"陡峭程度"：温度低 → 概率集中 → 更确定/保守 |
| top-k / top-p 采样 | 只从概率最高的若干词里采样，滤掉"垃圾概率" |
| 困惑度 Perplexity | 模型对下一个词的平均不确信程度（越低越好），$= e^{\text{交叉熵}}$ |
| 训练数据采样 | 数据本身来自真实世界分布，模型就是分布估计器 |
| 过拟合 | 模型记住了训练分布，却对真实分布泛化差 |

```python
probs = softmax(np.array([1.0, 0.8, 0.5]))

def sample_with_temperature(logits, temp=1.0):
    p = softmax(logits / temp)         # 温度越高分布越平
    return np.random.choice(len(p), p=p)

for temp in [0.1, 1.0, 5.0]:
    dist = softmax(np.array([0.0, 2.5, 1.0]) / temp)
    print(f"温度 {temp}: 概率分布 = {np.round(dist, 3)}")
```

> 💡 总结：**概率统计告诉我们模型"该怎么相信什么"，现代 LLM 本质是一个大规模、参数化的条件概率估计器**。

## 4. 信息论：度量"信息"本身

概率能回答"某个结果多可能"，信息论回答一个更本质的问题：**"一条消息带来了多少信息？"** 答案是：**越不可能发生的事，发生后带来的信息（惊讶度）越大**。LLM 训练的损失函数（交叉熵）就是从这里来的。

### 4.1 起源故事：香农与"比特"

- **1948 年（美国）**：贝尔实验室工程师 **克劳德·香农** 发表划时代论文《通信的数学理论》，一手创立信息论。他把"信息量"定义为**比特（bit）**，奠定了数字通信、压缩、加密和今天一切基于熵的机器学习方法。
- 灵感来自工程实践：如何用最短的编码传送电报、怎样在噪声信道里不出错——这些问题的答案最后凝练成了"熵"。

> 🧠 一句话记住：**信息量看的是"意外程度"，而不是内容长短。**

---

### 4.2 信息量与熵

#### 信息量（Self-Information）

$$
I(x) = -\log_2 P(x)
$$

- 天气播报"明天太阳从东边升起"：概率 ≈ 1，信息量 ≈ 0 ——没人会惊讶。
- 天气播报"明天下雪"（在热带）：概率极小，信息量很大 ——大新闻！

> 用 $\log_2$ 时单位是比特；机器学习里常用 $\log_e$（自然对数），单位是 nats。两者只是差个常数，**函数的形状一样**。

#### 熵（Entropy）：分布的平均信息量

$$
H(X) = -\sum_x P(x) \log P(x)
$$

熵度量一个分布的"混乱程度/平均惊讶程度"：

- 公平硬币 $P=(0.5, 0.5)$：$H = 1$ 比特（完全不可预测）。
- 灌铅硬币 $P=(0.99, 0.01)$：$H \approx 0.08$（几乎总能猜中，信息很少）。
- **均匀分布熵最大**，单点分布熵为 0。

```python
def entropy(p):
    p = np.asarray(p, dtype=float)
    return -np.sum(p * np.log2(p))

print("公平硬币熵:", entropy([0.5, 0.5]))        # 1.0
print("灌铅硬币熵:", round(entropy([0.99, 0.01]), 3))
```

---

### 4.3 交叉熵与 KL 散度：衡量两个分布差多远

真实分布 $p$，模型分布 $q$：

$$
H(p, q) = -\sum_x p(x) \log q(x)
$$

可以拆成两部分：

$$
H(p, q) = H(p) + D_{KL}(p \| q)
$$

其中 **KL 散度**度量"用 q 描述 p 时多花的比特数"：

$$
D_{KL}(p \| q) = \sum_x p(x) \log \frac{p(x)}{q(x)} \ge 0
$$

性质：

- $D_{KL}(p \| q) = 0$ 当且仅当 $p = q$（分布完全一样）。
- **不对称**：$D_{KL}(p \| q) \neq D_{KL}(q \| p)$。惩罚"模型自信地错"很狠（$q(x)$ 很小时 $\log \frac{p}{q}$ 爆炸）。

> 📌 为什么训练用"交叉熵"而不是"KL"？因为真实分布 $H(p)$ 是常数，优化 $H(p,q)$ 与优化 $D_{KL}$ 完全等价，但前者写起来更简单。

```python
p = np.array([0.7, 0.2, 0.1])     # 真实分布
q = np.array([0.6, 0.3, 0.1])     # 模型分布

cross_entropy = -np.sum(p * np.log(q))
kl = np.sum(p * np.log(p / q))
print("交叉熵:", round(cross_entropy, 4))
print("KL:", round(kl, 4))
print("交叉熵 ≈ 熵 + KL:", round(entropy(p) + kl, 4))
```

> 🌰 生动例子：真实天气明天 70% 下雨（p），隔壁气象台说 10% 下雨（q）。它每天少报信息，你按它出门天天淋雨——KL 散度就是"它的预报比真相多浪费多少信息"。

---

### 4.4 信息论 × LLM：交叉熵损失的真面目

LLM 的每一步训练都建立在交叉熵上：

1. 对第 $t$ 个位置，模型给出预测分布 $q_t$；真实答案是 one-hot 的 $p_t$（如"正确词是 第 3 个词"）。
2. 损失 = 每个位置的交叉熵取平均：

$$
L = -\frac{1}{T} \sum_{t=1}^{T} \log q_t(w_t^*)
$$

  其中 $w_t^*$ 是真实词。**因为 one-hot 的原因，交叉熵只剩"真实词位置的负对数概率"**——最大化"真实词概率"（上一章的 MLE）和最小化这个损失，是同一件事。

3. 训练结束时，**困惑度（Perplexity）**：

$$
\mathrm{PPL} = e^{L}
$$

   困惑度可以理解为"模型每次平均在多少个词之间犹豫"。PPL = 10，相当于它每选一个词，心里大约在 10 个候选里纠结。

```python
def ppl_from_log_probs(log_probs):
    return np.exp(-np.mean(log_probs))

# 两组 log 概率：第一组模型很自信且正确，第二组很犹豫
good = ppl_from_log_probs(np.array([-0.1, -0.2]))
bad  = ppl_from_log_probs(np.array([-3.0, -2.5]))
print("自信模型困惑度:", round(good, 2))   # 小 → 好
print("犹豫模型困惑度:", round(bad, 2))    # 大 → 差
```

> 💡 扩展：**知识蒸馏**（大模型教小模型）用 KL 散度对齐师生分布；**RLHF** 里的 KL 惩罚防止模型为了奖励大幅偏离原分布。信息论的"距离尺子"贯穿了整个 LLM 训练链路。

## 5. 数值优化：梯度下降家族

有了梯度（微积分）和损失（概率/信息论），剩下的问题是工程问题：**如何让几十亿参数的训练又快又稳**。

### 5.1 问题设定

我们要解的是一个（通常非凸的）最小化问题：

$$
\min_{\theta} \; \frac{1}{n} \sum_{i=1}^{n} L(f_\theta(x_i), y_i)
$$

### 5.2 梯度下降的几个"版本"

| 方法 | 每次用多少数据 | 特点 |
| --- | --- | --- |
| 批量梯度下降（BGD） | 全部样本 | 稳但太慢，内存也放不下大模型 |
| 随机梯度下降（SGD） | 1 个样本 | 快但噪声大，步伐抖 |
| 小批量 SGD（Mini-batch） | 一批（如 32/64/128） | **实际训练都用它**：兼顾效率与稳定 |

为什么小批量有优势？每个小批量的损失是整个数据集损失的**无偏估计**，噪声反而有助于跳出局部极小值；GPU 也能高效并行一批数据。

### 5.3 学习率：迈步子的艺术

- **太大**：在山谷两边"振荡"，甚至发散。
- **太小**：像乌龟爬，训练几万年。
- **自适应/调度**：先大步探索，后小步收敛。

> 🌰 生动例子：学习率像"下山时迈的步子"。步子太大直接冲过谷底又上对面山，步子太小太阳下山都到不了营地。聪明的登山者会**一开始迈大步、快到底时收小步**——这就是学习率衰减/预热调度。

### 5.4 进阶优化器：动量与 Adam（直觉版）

**Momentum（动量）**：像滚下山的小球，带上"惯性"：

$$
v \leftarrow \beta v + (1-\beta)\nabla L, \qquad \theta \leftarrow \theta - \eta v
$$

能冲过小的局部极小值、在谷底附近不来回震荡。

**Adam**（深度学习默认选择）：动量 + 每个参数自适应学习率：

$$
m \leftarrow \beta_1 m + (1-\beta_1)\nabla L \qquad (\text{一阶矩估计})
$$

$$
v \leftarrow \beta_2 v + (1-\beta_2)(\nabla L)^2 \qquad (\text{二阶矩估计})
$$

$$
\theta \leftarrow \theta - \eta \frac{\hat{m}}{\sqrt{\hat{v}} + \epsilon}
$$

直觉：**梯度大但稳定 → 大步；梯度小或来回跳 → 小步**；每个参数有自己的节奏。

> 🧠 一句话：**SGD 是"老实走路"，Momentum 是"带惯性的球"，Adam 是"每个参数有自己智慧的球"。** 现代 LLM 预训练（如 GPT、Llama）常用 AdamW（Adam + 解耦权重衰减）。

### 5.5 完整代码：三种方法解线性回归（从零实现）

造一批带噪声的线性数据 $y = 3x + 2 + \text{噪声}$，用三种方式学习 $w, b$：

```python
rng = np.random.default_rng(7)
n = 200
x = rng.uniform(-2, 2, n)
y_true = 3.0 * x + 2.0
y = y_true + rng.normal(0, 0.5, n)

def mse(w, b):
    pred = w * x + b
    return np.mean((pred - y) ** 2)

def gradients(w, b):
    pred = w * x + b
    dw = 2 * np.mean((pred - y) * x)
    db = 2 * np.mean(pred - y)
    return dw, db

# 1) 批量梯度下降
w, b, lr = 0.0, 0.0, 0.1
for _ in range(300):
    dw, db = gradients(w, b)
    w -= lr * dw;  b -= lr * db
print("BGD  结果: w=%.3f b=%.3f" % (w, b))

# 2) 小批量 SGD（batch=32）
w, b = 0.0, 0.0
for epoch in range(100):
    idx = rng.permutation(n)
    for i in range(0, n, 32):
        batch = idx[i:i+32]
        xb, yb = x[batch], y[batch]
        pred = w * xb + b
        dw = 2 * np.mean((pred - yb) * xb)
        db = 2 * np.mean(pred - yb)
        w -= 0.1 * dw;  b -= 0.1 * db
print("SGD  结果: w=%.3f b=%.3f" % (w, b))

# 3) 解析解（正规方程）：w,b = argmin ||Xw - y||²
# 记 X 的形状为 (n, 2)，第一列全 1 对应 b
X_design = np.stack([np.ones(n), x], axis=1)
solution = np.linalg.pinv(X_design) @ y    # (XᵀX)⁻¹Xᵀy 的稳妥算法
print("解析解: w=%.3f b=%.3f" % (solution[1], solution[0]))
```

> 📌 三种方法殊途同归：都逼近真实 $w=3, b=2$。解析解告诉我们"数学上最优点是什么"；梯度类方法告诉我们"数据多到无法算解析解时（大模型）照样能逼近"。

#### 线性回归与最小二乘的线性代数视角

用矩阵写正规方程：最小化 $\lVert X\theta - y \rVert^2$ 的解是

$$
\theta = (X^T X)^{-1} X^T y
$$

直觉：把 $y$ 投影到 $X$ 的列空间上，投影点与 $y$ 的距离（残差）最小。**线性代数（投影）、微积分（求导为零）、概率（高斯噪声下的 MLE）在这里殊途同归**——这正是数学三大支柱交汇的完美示范。

## 6. 综合实战：把数学串起来

把前面所有概念放进两个"从零实现"的例子里：一个 softmax 回归（分类，含交叉熵），一个迷你两层神经网络（含手工反向传播）。**强烈建议你亲手跑一遍并修改参数**。

### 6.1 实战一：softmax 回归（与 LLM 输出层同构）

任务：用两个特征区分 3 类（用模拟数据）。

```python
import numpy as np

rng = np.random.default_rng(0)
# 造 3 类数据：每类100个点，中心分别在 (0,0)、(3,3)、(-2,4)
C, N, D = 3, 100, 2
X = np.vstack([
    rng.normal([0, 0], 0.5, (N, D)),
    rng.normal([3, 3], 0.5, (N, D)),
    rng.normal([-2, 4], 0.5, (N, D)),
])
y = np.repeat([0, 1, 2], N)

W = np.random.randn(D, C) * 0.1   # (特征维度, 类别数)
b = np.zeros(C)
lr, epochs = 0.5, 300

def softmax(Z):
    Z = Z - Z.max(axis=1, keepdims=True)  # 防止exp溢出，数值稳定技巧
    e = np.exp(Z)
    return e / e.sum(axis=1, keepdims=True)

def one_hot(y_idx, k):
    out = np.zeros((len(y_idx), k))
    out[np.arange(len(y_idx)), y_idx] = 1
    return out

n = X.shape[0]  # 总样本数 300
for it in range(epochs):
    logits = X @ W + b                  # (n, C)
    probs = softmax(logits)             # 每个样本属于3个类别的概率
    
    # 交叉熵损失
    loss = -np.mean(np.log(probs[np.arange(n), y]))
    
    # softmax+交叉熵 梯度
    grad_logits = (probs - one_hot(y, C)) / n
    W -= lr * (X.T @ grad_logits)
    b -= lr * grad_logits.sum(axis=0)
    
    if it % 50 == 0:
        print(f"iter {it:3d}  loss={loss:.4f}")

# 计算训练集准确率
pred_logits = X @ W + b
pred_y = pred_logits.argmax(axis=1)
acc = np.mean(pred_y == y)
print(f"训练集准确率: {acc:.1%}")
```

> 📌 看清了吗？整个训练循环只用到了：**softmax（指数 + 归一化）、交叉熵（对数）、矩阵乘法、矩阵转置、梯度下降**。这就是"神经网络训练"的全部骨架。**GPT 的输出层与这里的结构完全一致**，只是前面的"特征"换成了亿万参数的 Transformer 在算。

### 6.2 实战二：迷你两层神经网络（手工反向传播）

两层网络：输入 2 维 → 隐藏层 4 个神经元（ReLU）→ 输出 1 个值。任务：拟合 $y = x_1 \cdot x_2$（乘法，线性模型学不会，必须有非线性）。

```python
import numpy as np

rng = np.random.default_rng(1)
N = 500
X = rng.uniform(-1, 1, (N, 2))
y = (X[:, 0] * X[:, 1]).reshape(-1, 1)            # 目标：乘积

n_in, n_hidden, n_out = 2, 4, 1
W1 = rng.normal(0, 0.5, (n_in, n_hidden))         # 随机初始化
b1 = np.zeros((1, n_hidden))
W2 = rng.normal(0, 0.5, (n_hidden, n_out))
b2 = np.zeros((1, n_out))

lr = 0.1
for it in range(2000):
    # ---- 前向传播 ----
    z1 = X @ W1 + b1
    a1 = np.maximum(0, z1)          # ReLU 激活
    z2 = a1 @ W2 + b2
    loss = np.mean((z2 - y) ** 2)   # MSE

    # ---- 反向传播（链式法则）----
    dz2 = 2 * (z2 - y) / N
    dW2 = a1.T @ dz2
    db2 = dz2.sum(axis=0, keepdims=True)

    da1 = dz2 @ W2.T
    dz1 = da1 * (z1 > 0)            # ReLU 导数：正值走 1，否则 0
    dW1 = X.T @ dz1
    db1 = dz1.sum(axis=0, keepdims=True)

    # ---- 梯度下降更新 ----
    W2 -= lr * dW2;  b2 -= lr * db2
    W1 -= lr * dW1;  b1 -= lr * db1

    if it % 400 == 0:
        print(f"iter {it:4d}  loss={loss:.5f}")

print("最终损失:", round(loss, 5))
print("示例预测:", np.round(z2[:3].ravel(), 3), "真实:", y[:3].ravel())
```

> 📌 手工反向传播的唯一"魔法"就是 2.8 节的链式法则：`dz2 → dW2 → da1 → dz1 → dW1` 一层层把梯度传回去。**现代框架（PyTorch / JAX）做的只是用"自动微分"自动生成这个过程**，算法思想完全一样。

### 6.3 穿上 GPT 的"外衣"：全链路图景

把这篇笔记从头到尾串成一个故事：

1. **数据进来**：文本被切成 token，每个 token 查嵌入表变成向量（线性代数：表 = 矩阵）。
2. **Transformer 层**：注意力用 Q·K 点积打分（点积 = 相似度）→ softmax 变成权重（概率）→ 对 V 加权求和（线性组合）；前馈层做两次矩阵变换（矩阵乘法）+ ReLU 非线性。
3. **输出**：最后一层给出每个词的分数（logits），softmax 转成概率分布（多项分布）。
4. **训练**：交叉熵损失（信息论）度量"模型有多不像真实数据"。
5. **优化**：反向传播（链式法则）求每个参数的梯度 → Adam/AdamW（数值优化）更新参数。
6. **推理**：温度采样（概率）从分布里挑下一个词，一个词一个词地"继续写"。

> 🎯 你看，**没有任何一步超出了这篇笔记讲过的数学**。所谓"大模型"，就是把这几步在小到几十、大到几千层的高度上反复做、拼命做、并行做。
