## 0. 攻击本质：合法查询如何变成偷窃

### 0.1 是什么

前七站都在防「输入」——改对话、改语料。这一站的对象是**模型本身**：对手不开打不入侵，就坐在那里**正常付费、正常拿回复**，把整台模型「照抄」一份回家。

**模型抽取**（model extraction）＝攻击者通过**大量合理查询**，记录输入-输出对，再训练一个**自己的**模型去拟合这些行为——最终得到一个功能近似、但属于自己的副本。

| | 注入/越狱（前站） | 模型抽取（本讲） |
|---|---|---|
| 攻击面 | 输入内容 | **输出行为**（答案本身） |
| 攻击手段 | 诱导提示词 | **大量合法查询 + 有系统性的采样** |
| 偷的是什么 | 会话控制权 | **行为副本 + 训练数据残余 + 边界知识** |
| 是否非法请求 | 是（恶意输入） | **每一单笔都合法**——问题在总量与系统性 |

关键认知：**单笔查询永远合法**。抽取无法靠「请求合法与否」拦截，只能靠**模式识别 + 成本压制**。

### 0.2 三步蒸馏法：把黑盒变影子

抽取不是乱问，是**三步浓缩**（探针账 A 特征就是这三步的可测信号）：

```
① 系统性采样 → ② 记录输入输出 → ③ 训练影子模型
   ┌─────────────┐     ┌──────────────┐     ┌──────────────┐
   │ 覆盖任务分布  │     │ QA 对入库     │     │ 用 (x,y) 拟合 │
   │ 固定模板批量发 │     │ 清洗错答      │     │ 轻量架构复刻   │
   └─────────────┘     └──────────────┘     └──────────────┘
     ↕ 特征可测
   QPS 高 · 前缀同 · 主题集中 · 时刻均匀
```

**特征信号**（探针五元组）：
- **QPS**：人一秒 1 条封顶，脚本可以一秒打 12 条（探针 `x-77`）。
- **前缀多样性**：人每次问法不同，脚本同一模板循环（探针 `pref_ratio=0.033`）。
- **主题集中度**：抽取目标明确时集中钻某类任务（`topic_share=0.6`）；真人查询主题天然分散。
- **时间均匀性**：脚本节奏均匀如节拍器，人上午忙下午歇（探针 `evenness` 1.0 vs 0.0）。

### 0.3 顺带偷走的：不止行为，还有记忆

影子模型复刻行为时，会把**模型记住的训练数据残余**也一起带出来：

- **记忆泄漏**：模型过拟合（memorization）的教材、私信、个人记录，会在采样中显形（联动 12-04 数据泄漏）。
- **成员推断**：抽出「这串文本/这个人」在训练集里的痕迹。
- **边界知识**：模型的隐藏能力边界、拒绝逻辑、提示词措辞——都被镜像。

> 行为能被镜像，记忆也能。抽取是对「答案」的暗杀，直接判了「知识面」的死刑。

## 1. 防御四件：把「抄作业」的成本拉到不可承受

既然单笔合法，防御只能**让系统性抄写变贵、变慢、变不准确**。四件各有分工：

### 1.1 限流（成本闸）

**是什么**：按账号/密钥/IP 限额 QPS 与日配额，超限硬拒 429（联动 13-08 网关限流）。

**为什么**：抽取的第一物理约束是**吞吐**。探针账 D：无防御抄 100 万条只要 **1.0 天**，限流到 4 qps 后要 **2.9 天**——成本翻倍还是小事，**时间窗拉长 = 被检测的窗口变长**。

**怎么做**：API 网关配额 + 突发桶（13-08 令牌桶 rate=60 bucket=120 授例）。账 D 中 `无防御 1.0 天 → 限流 2.893 天`。

**边界与坑**：限流只解决「多久能抄完」，不解决「能不能抄」。对手可以多开号、平滑拉长——它抬升成本，但**单独不能挡**。更隐蔽的是：抽取脚本 12 qps 会被 4 qps 限流拒 161 条（账 C 实测），**对手只需要放慢到 4 以下**——所以限流必须与指纹配合。

### 1.2 指纹检测（模式闸）

**是什么**：对**查询行为**而非单笔内容跑模式识别——QPS、前缀多样性、主题集中度、时间均匀性合成**嫌疑分**（探针账 A），达标即标记。

**为什么**：限流有漏洞，**模式没有刻意伪装前是诚实的**。真人查询和机械采样在统计上分离良好（正常窗 score 0.042 vs 抽取窗 0.89，探针账 B）。

**怎么做**：在网关记录查询元数据 → 滑窗计算特征 → 超阈进人工复核 / 自动降权。账 B 判别双臂：`u-01` 放行，`x-77` 标嫌疑。

**边界与坑**：**带对抗意识的对手会伪装**——随机化时间、多主题轮换、降价敏感算法检索。指纹是**概率性拦截**，不是确定性；它的价值在**抬高伪装成本**（对手要为每个查询编一个「像真人」的伪装）。

### 1.3 服务条款（法律闸）

**是什么**：ToS 明文禁止批量蒸馏/镜像/竞争复制，封禁与追责条款写进合同。

**为什么**：这层不挡技术，挡**追责路径**。TPD（temp-data processing）过后凭技术难取证，但**明文条款 + 会话日志 = 法律抓手**。探针账 C：`x-77` 自称 `use=batch`，直接触发 ToS 违规判定——会话当日停用。

**怎么做**：ToS 写进注册流程 + 封禁分级（警告 → 停用 → 追索）。联动 12-09 合规的「责任边际」。

**边界与坑**：ToS 拦住了守规矩的人，**拦不住恶意者**（他们不读条款）；且它的威力依赖「取证」——所以它必须与限流/指纹**先发生**，ToS 才有关门对象。

### 1.4 输出扰动（质量闸）

**是什么**：对嫌疑会话/高价值边界输出**加扰动噪声**（拉普拉斯噪声、混合差分隐私 DP），让抄到的东西失真。

**为什么**：抽取的最终价值在**拟合精度**。扰动直接攻击这一点：账 C `b=0.5 → top-1 命中率 0.62`，账 D `限流+扰动 → 4.133 天`——**每一点精度损失，都要对手用更多查询补偿**。

**怎么做**：对 top-k logits 加拉普拉斯噪声（教学值：b=0.1→0.93、b=0.5→0.62），或对输出做有界改写（廉价熵替换）。

**边界与坑**：扰动**把受害者也伤了**——所有正常用户共享同一吞吐/质量下降（DP 的「花钱买隐私」本质）。所以扰动只对**已标记嫌疑**的会话开（账 D 的判别性：正常窗 b=0.0 命中率 1.00）。

## 2. 2025 争论：蒸馏他人模型 = 行业常态还是偷窃？

### 2.1 事实背景（要素事实 · 离线不可验）

2024-2025 模型生态出现大量「**用自己的数据 + 蒸馏他人行为**」的模型：

- **DeepSeek 案**（要素事实）：2025 年关于 DeepSeek 蒸馏 OpenAI 输出的公开争论——OpenAI 称在对手输出中检测到其专属 `Chain-of-Thought` 措辞；DeepSeek 侧否认/淡化。法律与伦理上**至今无定论**。
- OpenAI 2024 年更新了 ToS 明确禁「蒸馏竞争模型」；xAI 等 **2025 裁决数据判例**（要素事实：法官裁定 AI 训练属「合理使用」，2025-02 纽约南区）——**训练层面的合理使用原则，正在被逐案改写**。

> 诚实边界：以上为离线要素事实，事件名/年份真实但细节（措辞、判幅）未经本会话在线核验，只作论点铺垫，不作事实断言。

### 2.2 边界：抽取与合理使用的分界在哪

| 判据 | 合理使用（研究/兼容） | 抽取（竞争/套利） |
|---|---|---|
| 目的 | 研究、评测、兼容、教学 | **复制竞争模型行为生产同类产品** |
| 规模/系统性 | 有限采样、抽样评测 | **系统性全覆盖采样（探测特征）** |
| 后续用途 | 引用的评测报告/论文 | **上线影子模型走商业** |
| 对原模型 | 无害甚至建设性 | **直接拿走对方市场价值** |

**判据不是「有没有抄」而是「抄完拿去干嘛」。** 这一维度的判定：**指纹做因果，ToS 做追责，监管做兜底**（12-09 联动）。

## 3. 决策总纲

```
高价值边界 + 高嫌疑模式 ──► 扰动 + 停用（ToS）
高价值边界 + 低嫌疑 ────► 正常放行（不伤用户体验）
低价值边界 + 高嫌疑 ────► 限流 + 监控
低价值边界 + 低嫌疑 ────► 无动作
```

四件不是单选：只装限流 = 对手放慢就能穿；只装指纹 = 无追责路径；只装 ToS = 拦不住恶意者；只装扰动 = 误伤正常用户。

## 诚实边界

- **指纹为统计启发**：特征五元组参数为教学值，真实对抗抽取（伪装节奏、多主题）会压低可分性——fingerprint 是概率闸不是确定性闸。
- **2025 争论为要素事实**：DeepSeek 案与 2025 合理使用判例未经本会话在线核验，细节（措辞、判幅）不可作为法务依据。
- **扰动参数为教学值**：`b` 取值只展示单调关系，未在真实模型上标定；真实 DP 参数需按合法性与精度损失做联合调优。
- **防御四件不能根除抽取**：只能把成功率压低、把成本拉长、把法律路径接上——「只能缓解」在此与 12-02/12-07 同源。
