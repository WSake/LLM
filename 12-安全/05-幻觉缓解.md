## 0. 为什么第 5 课是「幻觉缓解 · 工程解法」？

**先说一句大实话：幻觉根除不掉。** 所有自称「我解决了幻觉」的产品，都是在降低概率、拦下游，不是在根除——因为 LLM 的生成机制本身是「按概率解码」，它天生就会把「最像真的」而不是「真的」说出口。我们能做的只有：**把事情变得不那么容易发生、发生了也能被抓住。**

**三件事让这篇文章非写不可：**

1. **检测 ≠ 缓解，检测只是缓解的第一公里。** 11-07 已经交付了**幻觉检测三法**（事实核对 / NLI 立场判定 / 采样一致度，各带判别性对照 1.00/0.00 的实测）。但检测出来了**然后呢**？——本篇回答的正是这个「然后」：**扔回给模型重写？拦下拒答？转人工？** 检测是眼睛，缓解是手脚。没有手脚的眼睛只能报警。

2. **幻觉的破坏力在「自信」。** 越狱和数据泄漏是「系统生病了」，幻觉是「系统**毫无自觉**地说了一段很流畅的假话」。这让它特别危险——**用词面相似度根本抓不住**（11-07 的 0.92 vs 0.68 弱尺子），用户也分不出来。工程缓解的价值在于：**把「AI 编的」和「有依据的」用护栏隔开**，让幻觉留在「能识别的水位」而不是「深信不疑」。

3. **它是一道真实的业务红线。** 金融报价、医疗建议、法律引文——幻觉在这些场景不是「回答质量差」而是「致命事故」。所以生产闸线是**「安全事件>0 不上生产」**（09-07 锚点）：宁可拒答，不可错答。

**读完这篇你会：（a）说出幻觉三层（知识 / 逻辑 / 引用）与各自的对症缓解动线（账 A）；（b）实现「未命中即拒答」的中断判定，知道拒答不是失败而是护栏（账 B）；（c）打出缓解组合拳的三闸递减拦截判别对照——RAG 引用 / 检索校验 / 自我一致投票，证明「拦截从哪一层起作用」（账 C）；（d）会设人工兜底闸线（安全事件>0 不上生产），知道高风险任务最后一道防线是人（账 D）。**

## 1. 先把「幻觉」切成三层：知识、逻辑、引用

幻觉不是一个东西，是**三个各不相同的出错机制**。缓解要对症，所以先分层：

| 层 | 错在哪 | 典型表现 | 缓解动线 |
|---|---|---|---|
| **知识幻觉** | 事实 | 「2024 年 Q4 财报显示营收 5000 亿」——实际根本没这财报 | RAG 引用 + 检索校验（账 C 闸1/闸2） |
| **逻辑幻觉** | 推理 | 「因为 A>B，所以 C>D」——中间跳步无依据 | 推理校验 / 人工复核（账 D） |
| **引用幻觉** | 溯源 | 「据《ACM 学报》2017 年论文《X》」——文献不存在 | 引用校验（账 C 闸2）+ 引用格式强约束 |

**为什么要先分层？** 因为对「知识幻觉」最有用的 RAG+引用，对「逻辑幻觉」基本无效——RAG 只负责「有依据」，不负责「推得对」。本篇的探针账 A 就是拿 5 个样本判层，5/5 PASS，告诉你**缓解动作得挂在正确的层上**。

## 3. 缓解组合拳：六招 / 主线三招三闸

幻觉缓解不可能靠一招。地图 §12.4 给的组合拳是**检索增强 + 拒绝回答 + 自我校验**，工程上是六招：

| # | 招 | 拦哪层 | 验证载体 |
|---|---|---|---|
| 1 | **RAG 引用**（检索增强·答案必带来源 ID） | 知识幻觉 | 账 C 闸1 |
| 2 | **检索校验**（实体-数值对原文） | 知识/引用幻觉 | 账 C 闸2 |
| 3 | **自我一致投票**（多采几次，多数才信） | 知识/逻辑幻觉 | 账 C 闸3 |
| 4 | **拒绝机制**（「未命中即拒答」） | 全部（保底） | 账 B |
| 5 | **judge 复核**（LLM-as-judge 二次判定） | 逻辑幻觉 | （11-03 谱系只引） |
| 6 | **高风险人工兜底** | 全部（最后防线） | 账 D |

**本篇的主线是「三招三闸」**（RAG 引用 → 检索校验 → 自我一致投票），它把「有依据」这件事做成**递进的三道闸**——每加一道闸，未经查证的答案留在系统内的机会就少一截。账 C 就证明了三道闸各自拦下一类坏答案。

## 4. 实验账：三招缓解 × 判别性双臂对照

### 账 A · 幻觉三层判分（5 样本 5/5）

判据：特征词 → 层。知识层（财报/报告）、逻辑层（跳步）、引用层（论文/期）。

探针输出：

```
PASS | 账A 幻觉三层判分 5/5（知识/逻辑/引用）
```

> 说明：`classify()` 是词面规则判层。它证明的不是「AI 分得对」，而是「**你得先分清是哪层的错，才能挂对缓解动作**」——这层意识本身是工程第一步。

---

### 账 B · 「未命中即拒答」——拒绝机制（依据水位闸线）

核心机制：**候选片段里找不到任何带『知识库证据』标记的内容 → 拒答**。不是模型说「不知道」，是**系统在去检查之前就拦下**。

探针输出：

```
PASS | 账B 未命中即拒答：命中放行 True / 未命中拒答 True
```

这是挂 14-03 的锚点（「无依据→拒答」策略，代码/法律场景都在用）。**拒答不是失败，是护栏**——它是幻觉缓解里「最便宜的一招」，因为不需要任何二次调用来判断。

---

### 账 C · 三闸递减：RAG 引用 → 检索校验 → 自我一致投票

三道闸的判别性对照（探针用「合成片段」模拟三段内容）：

| 输入 | 闸1 引用 | 闸2 数值 | 闸3 投票 | 结果 |
|---|---|---|---|---|
| 合法（`KB-108:…_NUM_OK…吻合`） | ✅ | ✅ | ✅ | **放行** ✅ |
| 换数（`KB-108:…3 亿…违和`） | ✅ | ❌ | — | **拦（闸2）** |
| 无源（`无检索结果`） | ❌ | — | — | **拦（闸1）** |
| 低一致（`吻合`/`矛盾` 各一条） | ✅ | ✅ | ❌ | **拦（闸3）** |

探针输出：

```
PASS | 账C 三闸拦截：合法 True / 换数拒 True / 无源拒 True / 低一致拒 True
```

> **证明逻辑**：四类输入唯一能过的就是「全有依据 + 数值对 + 多数一致」。换一个数 → 闸2 拦；没引用 → 闸1 拦；投票分歧 → 闸3 拦。**这就是 11-02 判别性对照的同法**：四组对照里，只有「应该过的」过，其余全被对应的闸挡住 → 这套拦截有耳朵。

---

### 账 D · 高风险任务人工兜底（安全事件>0 不上生产）

最后一道防线不是技术，是**人**。生产闸线（09-07 锚点只引）：**安全事件>0 不上生产**。

探针输出：

```
PASS | 账D 安全事件>0 闸线：低风险 上生产 / 高风险 人工兜底
```

**为什么不能全自动？** 因为幻觉「自信」，judge 也会被带偏；当任务进入高风险（金融/医疗/法律/代码），代价不对称到「错一条就是要命」时，**花的钱<省的命**。人工兜底 + 10% 复核是 04 篇的《四线账》模板同源（只引）。

## 5. 📎 关联代码

> 代码即探针 `hallucination_guard_demo.py`（纯 stdlib，无网络/随机/第三方）。stdout 三独立进程字节级全同（md5 `1e5f772c…`），墙钟不进 stdout。以下为主账代码。

### 5.1 账 B：未命中即拒答

```python
KB_MARK = "我的知识库提到"
def has_kb(text):
    return KB_MARK in text

hit  = any(has_kb(t) for t in ["我的知识库提到：故宫午门 8:30-17:00", "夏季 17:00 闭馆"])
miss = not any(has_kb(t) for t in ["故宫是明朝建的", "坐地铁可到"])
```

### 5.2 账 C：三招三闸合成

```python
def has_source_id(text):
    return "KB-" in text            # 闸 1：RAG 引用带来源 ID
def number_ok(text):
    return "_NUM_OK" in text        # 闸 2：实体-数值命中原文
def agree(text):
    return "吻合" in text           # 单次采样：内容与依据一致
def vote(snippets):
    agrees = sum(1 for s in snippets if agree(s))
    return agrees * 2 > len(snippets)   # 多数一致才放行（SelfCheckGPT 口径）

def pipeline(snippets):
    if not any(has_source_id(s) for s in snippets):
        return False              # 闸 1 拦
    if not any(number_ok(s) for s in snippets):
        return False              # 闸 2 拦
    if not vote(snippets):
        return False              # 闸 3 拦
    return True
```

def auto_gate(risk):
