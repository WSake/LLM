## 0. 为什么看纵向：横向比完缺一张"族谱"

11 章把十四个家族并排进同一张八要素表，得到的结论是"2026 年大家长得很像"——RoPE + SwiGLU 全谱系通用、Attention 一格六种写法互相对抗、8 个特征家家都占六七条。但这个"像"只回答了一半的问题：

> 谁先像谁？LoRA/SwiGLU/多阶段训练这些词，第一个出现是谁？谁把它们变成"不抄就会被淘汰"的事实标准？

知识地图 §3.12 给了一段极浓缩的话，正好是答案的骨架：

> - **范式层**：GPT 发明范式（预训练/In-context/RLHF/推理/Agent 接口），Claude 定义对齐与 Agent 标准（Constitutional AI、MCP），Google 定义多模态与超长上下文。
> - **架构层**：Llama 稳定了开源骨架；DeepSeek 贡献 MLA 与极致 MoE；Mistral 普及 MoE；各家在滑窗/稀疏/混合注意力上互相借鉴。
> - **训练层**：InstructGPT 的 RLHF → DPO 简化 → GRPO 适配推理 → RLVR 给燃料 → 蒸馏扩散；"谁先开源谁定义下一轮"成为 2024 年后规律。
> - **2026 年收敛态**：前沿模型八要素高度趋同……**大厂拼的已不是单点创新，而是数据、算力、系统与生态。**

本篇把这段话展开成能跑的东西。核心问题只有一个：**"继承"和"创新"到底各承担什么角色？** 用本篇的量化回答：

1. **继承保住能力下限**。四代配方（GPT 古典 → +RoPE → +GQA → 现代 Llama 系）在同一个任务上全都解锁 ICL（fresh 达到 0.983-1.000，随机基线仅 ≈0.077）——后代没丢祖先"现场读映射"的能力。谱系上离根最远的家族也一样：**共享的那部分（共同基底 RoPE + SwiGLU）谁也不会拆掉，因为拆掉=变不会。**
2. **创新买的是成本与速度，不是"会不会"**。同一预算下，+GQA 把 KV 每 token 从 192B 压到 96B，+SwiGLU+RMSNorm 把参数从 57,072 压到 51,936 且回到 fresh 1.000——**模型家族的技术演进，是用"谁先谁后"的时差换"谁更省更快"的现实收益。**

> 一句话（为什么有本篇）：**横向比完了"像不像"，还得竖着看"谁先从谁那里长出、长出了什么不同"。继承是能力下限（共同基底谁也不敢拆），创新是成本/速度/时差（差分项=选型依据）——两个维度合起来，才叫"家族谱系"。**

## 2. 怎么构造：五段可重算的跑

- **A 谱系图（图算法本机真算）**：把 14 个家族建成有向图节点，边 = "直接继承谁家的路线"（谱系假设见代码注释，源=知识地图 §3.12 + 各篇家族章，**非本机实测**）。算法：从根 01-GPT 出发做拓扑计算——每家**代数**（最长父链边数）、每家**谱系路径**（沿第一个父回溯到根的链）、**hub**（被作为直接父代引用的次数，= 谁的路线被抄成骨架）、**LCA**（两家的最近共同祖先=分叉点）。断言：全节点可达根、图无环（DFS 三态）、最长代数=3、hub 第一=02-Llama。
- **B 范式溯源与普及率（本机真算 + 公开事实）**：把 11 章的 8 个收敛特征逐一条到"发明者/首源 → 谁让它成标准"（公开事实，非本机实测）；普及率 = 统计 14 家 CONV_PROFILE 每特征出现次数（本机真算，断言共同标准 ≥2 个）。训练范式链 RLHF(2022)→DPO(2023)→GRPO(2024)→RLVR(2024)→蒸馏(2024) = 每代"抽掉一个依赖"（年份公开事实，断言单调不减；去依赖=换代的机制解释）。
- **C 血缘量化（位串算术本机真算）**：继承度 = 与根 01-GPT 共享的特征位数（根=收敛态完整定义，离根越近继承越多）；相对父新增位 = 本家有而直接父没有的位，回退位 = 父有而本家丢的位；共同基底 = 14 家全 1 的位。**断言：最低继承度 = 05-Mistral 3/8（独门最多），共同基底 = RoPE + SwiGLU 恰好 2 位。**
- **D 四代引擎继承实验（本机真训练）**：复用 02-Llama 批的 `llama_demo.py` Engine 配方开关（pos/act/norm/NV），把"基因"按代换代——gen0 古典(GPT 系) abs+GELU+LayerNorm+MHA → gen1 +RoPE → gen2 +GQA → gen3 现代(Llama 系) rope+SwiGLU+RMSNorm+GQA。同一 add 任务（P=13、K=5、T=11、C=48、2-block），同预算同种子 1000 步×bs64，结尾 fresh@S=0。**断言：四代 fresh 全解锁（>0.5，继承保底）、gen3 ≥ gen0（创新不亏）、现代参数不增（SwiGLU 8C/3 比 GELU 4C 更省）、GQA 起 KV 减半（192→96B）。**
- **E 定义者台账 + 2026 收敛态断言（公开事实 + 本机断言）**：8 个范式"定义者→继承去向"两列（谁发明的、现在谁在用）；2026 收敛态检查 = 8 特征普及率（除 Agent 外都 ≥10/14=事实标准；Agent 9/14=收敛态里最年轻的维度、还在扩散）。

诚实边界一句话：**本篇最值钱的不是新算力，是把"继承与创新"从叙事变成能算的木偶——A 的图、C 的血缘、D 的真训练（复用既有引擎）都是本机可重算的；谱系假设、发明者年代、判分是既有结论/公开事实（非本机实测）如实标注。** 墙钟 run1 实测 294.5s（大头在 D 段四次训练），三遍运行 stdout 逐位一致。

> 一句话（构造选择）：**五段正好对应"纵向谱系"的五个读数——画谱系（A）、追范式（B）、量血缘（C）、验能力（D）、落台账（E）。脚本以图算法/位串/训练三段确定性为主，随机仅存在于 D 段训练（固定种子），全脚本三遍逐位一致。**

## 3. A 段 谱系图：十四家的 DAG，代数 / hub / LCA

脚本 [A] 段把 14 个家族建成一棵从 01-GPT 出发的谱系树（`lineage_demo.py` [A] 段，图算法=本机真算）：

[A] 家族谱系图（lineage DAG）——谁直接继承谁（谱系假设=非本机实测；图算法=本机真算）

    08-Gemini       1  01-GPT          01-GPT → 08-Gemini

四个读数：

1. **谱系有个"主干外旋"结构**。GPT 是唯一的根（decoder + 预训练 + next-token 范式），Llama 把它的范式接走做成可抄的骨架，然后在 Llama 这一支上分出 Qwen（拿到中文数据/词表）、DeepSeek（自研 MLA+MoE）、Mistral（SWA+MoE 普及）、Gemma（交替注意力）、InternLM（最强开源 VLM）——**6 个孩子，谱系最宽的一代**。
2. **hub = "谁被抄成骨架/路线"**。被直接继承最多的是 02-Llama（5 次）、其次是 04-DeepSeek（4 次）、再是 01-GPT（3 次）。这是本篇最硬的一个读数：**开源骨架 hub=Llama（架构层的"事实标准"），国产 MoE 路线 hub=DeepSeek（10a-10d 四家没人再发明 MoE 骨架，直接收编）**——Llama 定义了开源骨架构型，DeepSeek 定义了 MoE 路线形态。
3. **LCA 是"在哪分叉"的答案**。Qwen×DeepSeek 都从 Llama 分叉（骨架构型同源），Gemma×Gemini 却在 GPT 处分叉——Google 的闭源 Gemini 是范式定义者（原生多模态+超长上下文），开源 Gemma 是骨架继承者（走 Llama 骨架+交替注意力），一个公司两条血脉。DeepSeek×MiniMax 的 LCA=DeepSeek 说明 MiniMax 是 DeepSeek 路线的直接后裔；GLM 的 LCA=Qwen 说明它贴着中文主线走。

> 一句话（A 段）：**谱系图把"谁继承谁"变成可算的 DAG：主干外旋、hub=抄得最多的骨架（Llama）、路线 hub=最被收编的路线（DeepSeek），LCA 回答"两家的分歧点在哪一格"。断言：全可达根、无环、最长代=3、hub 第一=Llama。**

## 6. D 段 四代引擎继承实验：继承保底，创新更省

[D] 段把"继承 vs 创新"从读谱系变成一次真的训练（`lineage_demo.py` [D] 段，本机真训练；复用 02-Llama 批的 Engine 配方开关）：同一 add 任务（P=13、K=5、T=11、C=48、2-block）上，把配方基因逐代换代，同预算同种子各 1000 步×bs64：

```text
    代                 配方                             参数  KV B/层/tok fresh@S=0
    gen0 古典(GPT系)     abs+gelu+ln+MHA             57072      192B    1.000
    gen1 +RoPE        rope+gelu+ln+MHA            56544      192B    0.990
    gen2 +GQA         rope+gelu+ln+GQA            51936       96B    0.983
    gen3 现代(Llama系)   rope+swiglu+rms+GQA         51936       96B    1.000
    → 读数：四代全部解锁同一 ICL（P=13 随机基线 1/13≈0.077）——『继承』保住的是祖先的
      能力下限：换任何一阶配方基因，没丢"现场读映射"的能力；『创新』的收益不是学不会→
      学得会，而是『同预算同种子下一样解锁，但参数不增 / KV 减半』——这就是 §3.12 的
      继承与创新：骨架(能力)定底，差分(配方)定成本与解锁速度。
```

三个读数：

1. **继承保底 = 后代全部解锁**。四代的 fresh 是 1.000 / 0.990 / 0.983 / 1.000，随机基线只有 1/13≈0.077——**从 GPT 古典配方到现代 Llama 配方换了一整套基因，祖先"现场从示例读映射"的能力一丁点没丢**。这就是谱系图上"继承"的实证：共同任务谁都能学会，拆基因也不退步。
2. **创新收益 = 更省，不是更会（在这个任务上）**。改位置的收益体现在参数（—Wpos—，57072→56544）；改注意力的收益最猛：+GQA 把 **KV 每 token 从 192B 压到 96B 减半**、参数降到 51,936；改激活+归一的现代代（swiglu+rmsnorm）**参数不增且 fresh 回到 1.000**（gen2 是 0.983）。教学点：**家族技术演进的回报不在 toy 任务的"能不能学会"，而在真实场景省掉的算力/显存/墙钟——KV 减半在 128k 上下文就是一本 16→8 GiB 的账（复习 02-10/03-02）。**
3. **用实验把"祖先能力=公共底层"钉死**。四代都走同预算同种子（train 内部 `seed_init=7+C`、`seed_tr=1234`、`build_batch` 同一随机流），所以 fresh 的差异只能归因于配方基因本身——这是"可归因的谱系实验"，也是 §3.12"骨架(能力)定底、差分(配方)定成本"的机本演示。

> 一句话（D 段）：**四代同预算同种子各训 1000 步，fresh 全部解锁（继承保底：祖先能力没丢）；创新收益显示在成本维度——+GQA 把 KV 减半、现代代参数回落到最低且 fresh 回 1.000（创新更省）。"会不会"是继承的事，"省不省/快不快"是创新的事。**

## 8. 常见坑 + 衔接下一目录

**① 把谱系图当成"谁比谁强"的族谱。**
谱系是"谁继承谁的家路线"，不是"谁高谁低"——Gemini 与 Llama 平行不是 Google 碾压，是闭源范式定义者 vs 开源骨架继承者两条不同的变现路线。读图读"分叉与 hub"，不读排行。

**② 把"继承"当成"没本事"。**
继承=免费获得共同基底（RoPE/SwiGLU/多阶段），拆掉反而变不会——Qwen 继承 Llama 骨架不是模仿，是用省下的票去买中文词表经济（差分项）。D 段证明：同一任务上继承不掉能力，创新买的是成本。

**③ 只看普及率，不看发明者和扩散路径。**
14/14 的 RoPE 是"谁都不用再检查的默认"，但它的发明者（RoFormer 2021）和把它变成标准的 Llama 才是继承叙事的主角。普及率只能回答"传得开吗"，回答不了"谁传的"。

**④ 把代际实验的 fresh 当成"配方好不好"的榜单。**
同一个 toy 任务四代都能解锁，差异几乎都在参数/KV/墙钟（本批：KV 192→96B 减半、参数 57072→51936），真正把 KV 减半变成一本真实收益账要到 128k 上下文才现形（02-10/03-02 的 16→8 GiB）。toy 上"都会"是继承的证据，不是配方打平的结论。

**⑤ 想在谱系里硬找"唯一发明者"。**
原生多模态是 Gemini 定义的、长上下文是 Claude/Gemini 一起推的、Agent 接口先是 function call 后是 MCP——范式是接力不是独享，台账里的"定义者"是"最先产品化/最先标准化的那家"（公开事实，非本机实测），不是"第一个想到的人"。

**⑥ 忘了谱系假设是可变假设、判分是作者判分。**
A 段边、E 段发明者年代、C 段判分都是既有结论/公开事实（非本机实测）：改判分会改继承度数字但不改"共同基底=RoPE+SwiGLU、Agent 最年轻"的结构性结论。引用数字给口径时，区分"本机真算的图算法/位串/训练"与"外部假设"。
