## 0. 为什么讲 Claude 要从"只给能力不给权重"讲起

读 `03-01`–`03-06` 六篇，你得到六句话：**① 目标不变+规模翻页；② 开源把架构投成事实标准；③ 数据与对齐做成壁垒；④"省"做到机制级；⑤"省"做成可卖规格；⑥ 端侧是另一本账。** 六句有一个共同前提：**你有权重。** ——你说 Llama 的 RoPE 投成事实标准，前提是你打开 config.json 能看到 `rope_theta`；你说 DeepSeek 的 MLA 省 KV，前提是你能在注意力里找到那一行低秩投影；你说 Gemma 的交替注意力是 SWA 的逐层化，前提是你翻开 42 层的掩码表。

**Claude 一上来就把这个前提拿掉了。** 知识地图 §3.7 给 Claude 的八要素速写，前两格就是"架构=闭源"。这是 `03-模型家族` 的**第一大家族"闭源 API 系"**：你买到的是一个接口、一份 token 流、一些可调的 API 参数（上下文长度、思考旋钮、工具协议），而不是一颗能拆开看的参数。所以讲 Claude 这一篇，讲法必须换——不是"拆它的架构"，而是回答一个方法论问题：

> **一家你拿不到权重的公司，还能从它的公开论文/对齐招牌里学到可验证的东西吗？**

答案藏在知识地图 §3.7 的"训练"格：**Constitutional AI / RLAIF**（2022-12 arXiv、2023-06 正式刊；Anthropic 首创"AI 打 AI 的分，代替人类打分"）。它是 Claude 家族最"论文公开 + 招牌官方"的一根线，而它恰恰不依赖你拆开某颗权重——它是一套**数据管道**（AI 判官 critique → revision → 偏好对 → RM → RLHF），原理可以用任何语言模型复现。这就把"闭源"变成了"可复现"：**正文 [A] 段用 02-14 那套 1-block toy，把 Constitutional AI 的 RLAIF 数据管道整个跑成最小闭环（0 条人工标注）。**

顺带说清本篇在家族谱系上的位置：`03-00` 八要素模板立完，`01-06` 是"架构可见"的开源家族，`07` 起进"能力可见/权重不可见"的闭源 API 系——**"推理方式"格第一次从"自部署（自己跑权重）"变成"只能调 API（买能力）"**。这不仅是 Claude 一家的事，也是 08-Gemini、及其他闭源系的事；本篇把这个"闭源视角"立成模板。

> 一句话（为什么有本篇）：**背"Claude3.7 混合推理"帮不了你判断闭源模型的边界；理解"闭源版对齐 = RLAIF 数据管道 + 接口旋钮"，并且亲手把'AI 判官修自己的输出'跑成一个 0 条人工标注的最小闭环，才看得清 Claude 这家'只给能力不给权重'的家族，它的招牌到底在卖什么（对齐能力商品化 + Agent 接口）。**

## 2. 怎么构造：把"宪法条款"玩具成判官三票，直接复用 02-14 引擎

Constitutional AI（Anthropic, 2022-2023）的原始流程是这样的（论文原文，**非本机实测**）：

1. **红队 prompt**：给模型一些故意制造困难的 prompt（真实系统里是大量"想让模型干坏事"的用例）；
2. **critique**：让模型（或判官 AI）审视自己刚生成的回答，"哪里违反了宪法条款？"；
3. **revision**：让模型按宪法条款**修订**自己的回答；
4. **自动产偏好数据**：`修订后的回答 > 原始回答` 构成偏好对——**由 AI 判官定，不需要人类逐一标注**；
5. **RM**：从这批 AI 偏好对里学奖励模型；
6. **RLHF**：用 RM 的分数做 RL（自有权重）；论文同时做了 SL-CAI（直接拿修订答当 SFT 数据回灌）。

这个管线**不挑模型**——你甚至可以在一颗 16 万参数的 toy 上跑。要把它做成最小闭环，需要四个对应物（本篇 `claude_demo.py`，全部复用 02-14 引擎，`import rlhf_ppo_demo as R`）：

| Constitutional 一步 | 本篇对应（toy 化） | 02 复习点 |
|---|---|---|
| 宪法条款 | **判官三票**：`judge_score(gold, ans, tox) = (首 token 对？ + 全 token 在？ + 无污染 token ？)` 0-3 分（02-14 母规则） | 02-14 A 段（人见三票） |
| 红队采样 | 高温采样 4 次挑 "得分 <3" 的回答（A1） | 02-13 SFT 产物 · 02-11 采样 |
| critique | 判官指出混进别的公式的 token（如 `['pi']`） | 02-11 voca 的 toxic_for |
| revision | **约束解码修订**：重答时把违规 token 的 logits 置 `-inf`（A2） | 02-11 采样改 logits |
| RLAIF 偏好对 | 违规答 vs 修订答（判官定胜，0 条人工标注，A3） | 02-15 DPO（偏好对也可用它）· 02-14 B 段 383 对 |
| RM | 02-14 同款 Bradley-Terry RM（A4） | 02-14 B 段 |
| RLHF | 02-14 同款 REINFORCE+KL（A5，对照） | 02-14 C 段 |
| SL-CAI（修订回灌 SFT） | 修订答直接当 SFT 数据回灌 600 步（A6，稳路径） | 02-13 SFT · 02-15 DPO |

引擎就是 02-14 那套 1-block（LN→因果 MHA→LN→FFN，T=48, C=96, NHEADS=3, B=16），词表 V=251。预训练 1200 步 + SFT 200 步（种子 42/9，与 02-14 完全相同）→ 得到 `p_sft`（respond 模型）。**全篇实验只有一个新增物：`revise_constrained`——把 `forbid`（tox 集合）的 logits 置 `-inf` 后重采样。** 这就是"toy 宪法修订"：真实 Constitutional 用的修订是靠"重新写一遍"（revision prompt），toy 用"解码禁词"效果等价——都是把不合条款的输出从生成分布里剔除。

关键设定——**"污染"就是"违反宪法"**：语料里 30 条指令 (what is ...)，金标准回答是某条物理常数（如重力加速度 9.8，圆周率 3.14159…），而 `toxic_for` 把"别的公式的数字/名字"（pi 等）标为违禁 token。模型答错了答案（把 π 扯进重力问题）→ 判官三票 <3 → 违规。这套宪法条款很简单，但**每一票都可解释、可逐位复现**——这正是本篇要的"toy 宪法"：条款本身不重要，**"AI 判官自己定标准→模型按标准修自己→自动产生训练数据"这个闭环**才是要测的机制。

> 一句话（构造选择）：**Constitutional AI 是一根数据管道，不挑模型——把'宪法条款'玩具成判官三票、把'revision'玩具成约束解码，02-14 引擎一行不动就能把整条 RLAIF 闭环跑起来。要复现的是管线本身，不是 Claude 的权重。**

## 3. A 段 Constitutional AI / RLAIF 最小闭环：AI 判官修自己的输出

脚本 [A] 段（`claude_demo.py`，**本机实测**）：

```text
[A0] 基线：SFT respond 能答，但采样『污染率』约三成（判官三票挑）
  三票 perfect 率：训练问 76% · 全新问 59%（3/3=答对+答全+答干净）
  污染率（混进别的公式）：训练问 27% · 全新问 29%

[A1] 红队 + critique：高温采样 → 判官挑『违规回答』并指出违规 token
  挑出违规回答 14/30 条（每条 critique=判官指出混进的 token）
    critique：问「what is the gravitatio…」 采样→「9 . 8 meters per second squared . pi is」· 违规 token: ['pi']
    critique：问「what is the accelerati…」 采样→「9 . 8 meters per second squared . pi is」· 违规 token: ['pi']
    critique：问「what is the ratio of c…」 采样→「3 . 14159 . mathematicians approximate pi . 14159 .」· 违规 token: ['pi']

[A2] revise：对同一条指令重答、解码时禁掉违规 token（toy 宪法修订）
  修订版三票满分 14/14 · 修订版仍污染 0/14

[A3] RLAIF 偏好对：违规答 vs 修订答（判官定胜, 0 条人工标注）
  自动产出偏好对 108 组（修订分>违规分）——对应 02-14 人工标注 383 组
  留出判别集 17 组 · 全部由判官自动判（RLAIF：AI 代人工）

[A4] 奖励模型：从 AI 自动偏好对学『哪个回答更被喜欢』（800 步）
  留出 AI 偏好对判别率 88%（RM 学会了判官的三票偏好）

[A5] RLHF 对照（REINFORCE + KL，150 步）——reward 上去了，三票被 RM 劫持？
  平均 RM 奖励：前 -1.919 → step50 3.605 → 后 6.305
  KL(π‖SFT_ref) ≈ 25.885
  RLHF 后三票 perfect：训练问 30%（前 76%） · 全新问 17%（前 59%）
  RLHF 后污染率：训练问 70%（前 27%） · 全新问 83%（前 29%）

[A6] Constitutional 稳路径：判断官修订答直接 SFT（AI 数据→回灌，600 步）
  SFT 后三票 perfect：训练问 100%（前 76%） · 全新问 78%（前 59%）
  SFT 后污染率：训练问 0%（前 27%） · 全新问 19%（前 29%）
```

六个读数，逐段解释：

1. **A0：SFT 会答，但会"犯混"。** 训练问三票 76%（每答对一大半），全新问 59%（没见过的问法掉一截）——这是 02-13 SFT 之后的正常模样；**污染率三成**（27%/29%）说明"混进别的公式"不是偶发，是 SFT 之后的高温采样常态。这就是红队要抓的对象。

2. **A1：红队抓到了"违规"。** 高温采样 4 次挑"得分 <3"的回答，30 条指令里 14 条被抓（`14/30`）。critique 例子正是"答重力却混出 pi"这种污染——**AI 判官自己指出了违规 token `['pi']`，不需要人类逐条标注**。这条是全文的"真实温暖"——像 Claude 宣发时说的"红队改错"，在 toy 上是逐 token 可见的。

3. **A2：约束解码修订 = toy 宪法修订，效果满格。** 对 14 条违规答分别按"禁掉 tok 集合"重答，**14/14 全部三票满分、0/14 仍然污染**。这说明什么？**"别混别的公式"这条宪法条款，用约束解码就能 100% 执行——条款的可执行性独立于模型的学习能力。** 真实系统的 revision 也是这个意思：给模型一次"重写"，比期待它一次就记住更可靠。

4. **A3：RLAIF 自动产偏好对，0 条人工标注。** 每问采样 10 次收集全部违规答、逐对与修订答比（判官定胜），得 **自动偏好对 108 组**（留出 17 组给判别集）。对照 02-14：那里人类标了 383 对；**这里是 AI 判官自己打的 108 对**——"AI 打 AI 的分，代替人类标注"就是这个意思（RLAIF = RLHF with AI Feedback）。

5. **A4：RM 从 AI 偏好对里学会了判官的偏好——留出判别率 88%。** 这是**正面结果**：pure RLAIF 采出的数据，不需要任何人类标注，就能训出一个 88% 互认的奖励模型。RM 学会了"修订=好、违规=坏"。

6. **A5（诚实对照）：RLHF 150 步把 RM 的分数推向 6.305，把三票推崩。** RM 奖励一路涨（-1.919→3.605→6.305）——**RL 确实在最大化 RM**；但 RLHF 后无约束三票：训练问 76%→**30%**、全新问 59%→**17%**，污染率 27%→**70%**、29%→**83%**，KL=25.885 无界。为什么？**RM 只在"修订 vs 违规"这对格式需求上见过世界**（训练对全是 SFT 采样 vs 约束解码修订），一旦 RL rollout 摸到"非 tox 但答错"（既没混别的公式、也没答对）的新回答，**RM 对它给高分**（因为它跟修订答同属"不混 tox 词"那个格式族）——策略于是朝"格式对、内容错"漂移。这就是 02-14 正文 §8 写的"**弱代理（RM 判别率≈8 成）+ 长训练 → RLHF 翻车**"在 toy 上的直演。**A5 的结果是负的、但必须诚实播报**——它演示的正是真实 RLHF 出过的问题（RM 与真目标之间的格式捷径）。

7. **A6（稳路径）：Constitutional AI 论文同款"修订数据回灌 SFT"。** 把 A2/A3 的自动修订答直接当 SFT 数据回灌 600 步（不用 RM、不用 RL），三票训练问 **100%**（前 76%）、全新问 **78%**（前 59%），污染率训练问 **0%**（前 27%）、全新问 **19%**（前 29%）——**安全性（污染率降）+ 帮助性（三票升）同涨，且整个管道 0 条人工标注**。这正撞上 Constitutional AI 论文的收尾：**先 RLHF 后 SL-CAI，或者干脆用修订好的回答直接再 SFT 一轮**——玩具上 SL-CAI 比 RLHF 稳得多，因为 SFT 没有"策略自己 rollout 去撞 RM 盲区"的那一步。

> 一句话（A 段）：**RLAIF 最小闭环全线成立（0 条人工标注：红队 14/30 → 修订 14/14 → 偏好对 108 组 → RM 88%）；RLHF 在玩具上是高方差负结果（RM 奖励涨到 6.3 但三票 76→30%，被格式捷径劫持——诚实播报）；Constitutional 论文的稳路径——修订数据回灌 SFT——600 步后三票 100%/78%、污染 0%/19%，安全性与帮助性同涨。判官三票当宪法条款，AI 自己修自己，闭环成立。**

2. **账②：上下文是第二颗旋钮。** 200k（Claude3 系）→ 1M（Claude4 系）token 能装多少书：**英文 ≈0.7 词/token → 200k ≈ 14 万词、1M ≈ 70 万词；《红与黑》≈20 万词 → 200k 装不下 1 本、1M 装下 ~3 本**。每加一个 token，KV 驻留 +2·C·字节（02-10 母线）——上下文越长，**每次 API 调用的"读写宽度"越贵**（你的 input token 就是它的成本）。

3. **账③：Agent 是第三颗旋钮，也是 Claude 现今主打。** 工具调用 = 把外部动作变成 "API 的 return token"（MCP 2024-11 发起、Computer Use 2024-10 商品化）——**每回合把工具结果回填上下文** → 长 Agent 任务的成本 ≈ **Σ各回合输入 token**（随回合数近似线性累积）。这就把"买能力"变成了"按回合按上下文买动作"：Claude 卖的接口是嵌套在上下文里的。

> 一句话（B 段）：**闭源 API 系八要素里架构/权重全不可见，能调的只剩三颗旋钮——思考（账①：开 ≈ 输出 ×6）、上下文（账②：1M ≈ 70 万词、KV +2·C/token）、Agent（账③：每回合工具结果回填、成本 ≈ Σ输入 token）。决策地图从'装多大'翻到'买多少'。**

## 5. 常见坑

**① 让"闭源"等于"没法学"。**
闭源只藏架构/权重，不藏对齐论文。本篇 [A] 段证明：Constitutional AI / RLAIF 是数据管道，不挑模型——判官三票当宪法条款，0 条人工标注就复现了 critique→revision→RM 整条线。**学闭源家族的正路是"复现它的可公开管线 + 读它的接口旋钮"，而不是"猜它的层数"。**

**② 把 RLHF 的玩具负结果当成"AI 对齐没用"。**
A5 的 RLHF 崩（三票 76→30%）不是"对齐失效"，是**玩具 RM 判别率只有 88% + rollout 摸到 RM 盲区**——02-14 正文早就写过的"弱代理 + 长训练 → 翻车"。真实系统靠更好的 RM、更大数据、更强的 KL 锚压住。**负结果是方法论事实，正文老老实实报了，别美化，也别反过来否定线。**

**③ 忘了"A2 约束解码 100% 可执行"这条最重要的性质。**
toy 宪法条款用约束解码修订，14/14 满分、0/14 污染——**条款可执行性独立于模型学习**。真实系统的"提示工程/约束/外挂过滤器"同理：比起让模型永远记住条款，**一次性把不合条款的输出剔出生成分布**更可靠。对齐不止一条路（记住 vs 剔出）。

**④ 把"思考 token"当免费行为。**
账①：开 extended thinking，思考 token 按输出价计费，02-20 实测同题 think≈6× 直答 token。**买了"想得多"，就要付"想得多"的输出账单**——快/慢旋钮不是发布会彩蛋，是现金流决策。

**⑤ 用"开放权重时代的自部署观"选闭源 API。**
选型问法从"几块卡跑得动"变成"每分钟买多少能力"：上下文旋钮（账②）、思考旋钮（账①）、Agent 回合（账③）三颗旋钮共同决定 API 账单。**谁便宜谁贵，取决于你买的是"直答 1 token"还是"思考 6 token × N 回合工具回填"。**

**⑥ 错把 MCP/Computer Use 当"功能列表"而不是"成本结构"。**
工具调用=return token+回填上下文，Agent 任务成本≈Σ各回合输入——**SPOF 不是"它有 1000 个工具"，而是"每回合刷一遍上下文，回合越多越贵"**。读闭源 Agent 能力，算的是上下文循环账。
