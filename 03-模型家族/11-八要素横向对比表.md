## 0. 为什么横着比：一对一拆完了，缺一张"全家福"

0.8 章（00-八要素解构法）给了拆模型的解剖框，01-10 十篇按这个框逐个家族拆到底。但一对一拆完，你会拿到十张互相独立的卡——**Llama 的 GQA、Qwen 的词表、DeepSeek 的 MLA、Mistral 的 SWA、Claude 的 Constitutional…每张卡都成立，但它们之间谁先谁后、谁是借鉴谁是独门，卡上看不出来**。这正是知识地图 §3.11 想补的一格：

> 八要素横向对比表（定性，不迷信参数）——把主流家族按同一批维度并排，看它们"工艺路径"的差异与扩散。

"定性，不迷信参数"不是"不量化"——是**不迷信单一数字**（8B/671B/1T 这种参数量比不出来差异：1T 的 MoE 和你 8B 的 Dense 不是同类的东西）。横向表要回答的是另外三问：

1. **同字段并排后，哪些格子收敛、哪些格子还乱？** 扫一遍会发现 Attention 一格最乱（MHA/GQA/MLA/SWA/交替/未公开六种写法），FFN 一格最收敛（SwiGLU 系或 MoE 呈主流），训练一格 2024 后全部向"多阶段 + RLVR"靠拢——**收敛 = 大家用同一套工艺，乱 = 还在互相抄/试错**。
2. **闭源家族的横向表边界在哪？** 07-Claude、08-Gemini、10c-Doubao 三行大量格子是"未公开"——不是作者偷懒，是**它们的参数本身就未公开**。这本身是个结论：闭源 API 家族的选型维度是能力/生态/成本，不是参数账。
3. **2026 的模型到底长什么样？** §3.12 把它写成一段话（"MoE 或小 Dense + RoPE + SwiGLU + 多阶段训练 + thinking mode + 原生多模态 + MCP"）——本篇 [D] 把它拆成 8 个布尔特征，给每个家族逐格打分，收敛度从"读起来像"变成"算出来的 /8"。

> 一句话（为什么有本篇）：**一对一拆完了缺一张全家福。横向表 = 十一个家族同一批维度并排，靠"哪些格收敛、哪些格乱"读出家族工艺的扩散路径——"收敛"读共性（入门都得会），"差分"读独门（选型看这里）。**

## 2. 怎么构造：五段可重算的跑

- **A 横向表（要素事实非本机实测）**：把 00 章的四家扩到十一个家族 → 14 个代表模型（GPT/Llama/Qwen/DeepSeek/Mistral/Gemma/Claude/Gemini/GLM + 拇家 Kimi/MiniMax/Doubao/Hunyuan/InternLM），每行八列同字段并排。命名的教学意图：14 行走完，你看到的不是"谁大"，是"谁的 Attention 用什么、谁的训练在加什么"。
- **B 跨家族派生账（本机真算 + 如实标未公开）**：复用 00 章的 `count_params` / `kv_bytes_per_layer_token`（Dense/GQA/MoE 结构级推导、MLA 走官方），先跑 00 章的 Llama/Qwen/Mixtral/DeepSeek 四家做**对账基线**（应与 00 章 run1 同数），再加 Gemma2-9B（42 层/256k 词表/交替注意力）与 GLM-4-9B 档两行真算；闭源行（Claude/Gemini/Doubao/Hunyuan）按"未公开"或官方面值处理，不做推测。
- **C 复习链断言**：与 00 章同表同断言（8/8 全非空），证明横向表没有造新词。
- **D 收敛度量化（本脚本新计算）**：把 §3.12 的收敛态拆成 8 个布尔特征（RoPE / SwiGLU / MoE 或小 Dense / 多阶段训练 / thinking / 原生多模态 / ≥128k / Agent），14 个家族代表逐一判分 → 收敛度 /8 + 差分项。**断言：5 家 8/8（GPT/DeepSeek/Gemini/Kimi/Doubao），最低 3/8（Mistral）。**
- **E 决策引擎（规则表 + 断言自校）**：从 00 章的五任务升级到全家族八任务（新增"超长上下文 1M+"→Gemini、"对齐与 Agent"→Claude、"原生全模态"→Gemini、"研究标本"→DeepSeek/OLMo），开源/闭源双路径都进表；每个任务断言锁死，同一输入永远同一推荐。

诚实边界一句话：**本篇最值钱的不是新算力，是把"横向对比"和"2026 收敛态"这两件 00 章只能口头讲的事，变成能跑、能断言、能复现的五段脚本——A/C 复用既有纪律，D 是新的量化（8 特征布尔判分），E 把决策引擎从四家扩到全体。要素取值与剖面全部标非本机实测，闭源参数如实标未公开。**

> 一句话（构造选择）：**五段正好对应"横向对比"的五个动作——并排描述（A）、跨家族算账（B）、复用复习链（C）、量化收敛（D）、全家族选型（E）。全脚本零随机，三遍逐位一致。**

> 一句话（A 段）：**十四行扫完，家族的"工艺路径"就显形了——Attention 一格最乱（六种写法互相竞争），FFN 一格收敛（SwiGLU 事实标准 + MoE 加账），闭源三行"未公开"本身就是选型规则切换的证据。横向表的动作不是背一行数字，是看哪列还在打仗、哪列已经打完。**

## 8. 常见坑 + 衔接下一章

**① 把横向表当"参数排名表"读。**
1T 的 MoE 和 8B 的 Dense 不是同类的东西——横向表按字段并排，比的是"工艺路径"（Attention 用什么、训练加什么），不是"谁参数大"。"定性，不迷信参数"的"定性"是维度，不是放弃量化。

**② 忽略"未公开"格子的信息量。**
07/08/10c 的"未公开"不是留白，是闭源 API 家族的边界声明：参数不给、横向参数量账不成立——选型维度自动切换到能力/生态/成本。闭源的路线不同于开源，等于说"推理方式=闭源 API"这一格改写了整个选型逻辑。

**③ 把收敛度 /8 当权威排名。**
布尔判分是知识地图 §3.x 速写的布尔化（非本机实测），同一标准用于横向，别当榜单。它的正确读法：收敛度读"照抄的部分"（入门都得会 RoPE/SwiGLU/多阶段），差分项读"独门"（选型看这里）。

**④ 对闭源家族强行"推导"参数。**
Claude/Gemini/Doubao 没有公开结构——本篇 B 段如实标"未公开"，不做推测。硬推一个闭源模型的参数量是自嗨，写进文章要有"对账"证据（本篇只对结构完整的六家承诺 ±15% 走廊）。

**⑤ 决策只看收敛度、不看差分项。**
收敛度是"共性"，差分项才是"独门"——中文选 Qwen 靠的是词表账（差分），Agent 选 Claude 靠的是 MCP（差分）。两个 8/8 的模型（GPT vs DeepSeek）在具体任务里的差别，全在差分项里。

**⑥ 忘了"选型不选最优，选匹配"。**
"哪个模型最强"不成立——超长上下文选 Gemini、对齐/Agent 选 Claude、开源推理选 DeepSeek、端侧选 Gemma，都是"匹配"不是"排名"。**没有全能的模型，只有匹配不匹配的任务。**
