## §1 核心机制：扩散做文本，比做图像别扭在哪

**是什么**：扩散模型的核心思想是**"从噪声里一步步变回数据"**——正向不断加噪，反向学习去噪。图像由连续的像素构成，加噪去噪顺理成章；文本是**离散的符号**（token），没有天然"中间状态"。Diffusion-LM 的做法是：先把离散 token **嵌入成连续向量**，再在这个连续空间里跑加噪/去噪，最后把去噪后的向量**量回离散 token**。产出一个核心后果——它可以只迭代几步就得到一句话，而不是自回归地逐 token 预测。

**为什么会出现**：因为**自回归不是唯一的正确答案**。自回归（逐字续写）简单、可控、效果好，但它有两个结构性短板——①生成必须串行（token by token），②没有方便"整体重写"的通道（改一个词很难只重该词）。扩散的"整体去噪"天然能并行、天然能重写。这条路线一直被研究，不为替代，只为保留可能性。

**机制表：自回归 vs 扩散式文本生成**

| 视角 | 自回归（成熟主流） | Diffusion-LM（探索期） |
|---|---|---|
| 生成方式 | 逐 token 串行 + 条件概率 | 整句向量去噪 + 迭代精化 |
| 字符空间 | 离散 token 直接建模 | 嵌入连续空间中间态 |
| 重写能力 | 弱（要改就重生成） | 较强（向量可控语义方向） |
| 当前地位 | 商业主流 | 非主流，研究保留 |

**边界与坑**：别把"扩散做文本"想成"扩散做图像"的简单平移——**token 的离散性与"噪声"的定义**是最大障碍。图像的噪声有物理意义（像素退化），文本没有。因此 Diffusion-LM 实际流程里有一大堆工程补偿（向量量化、逐步退火）。它在跑，但远没有图像扩散那种"天然契合"。

📎 **关联代码**：plan3 标注 **"能算——无"**（知识型篇）。本节用一个确定性判定演示两类生成的差异——同 2 个词的序列，自回归按"下一个 token"展开，扩散按"整句去噪"展开，两种展开步数在固定输入下恒一：

```python
# 内联确定性片段（非探针，纯 stdlib，无随机无网络）
tokens = ["我", "爱", "这", "篇", "文章"]
autoreg = len(tokens)               # 自回归：逐 token 串行，步数 = token 数
diffuse = 3                          # 扩散：迭代去噪固定步（示例固定值，非声称性能）
assert autoreg == 5 and diffuse == 3
print("§1 步数对比：自回归 %d 步 / 扩散固定 %d 步（确定性示例，非性能承诺）"
      % (autoreg, diffuse))
```

## §2 代表工作谱系：Diffusion-LM -> LLaDA

**是什么**：这条谱系的两次标志性实践——**Diffusion-LM（2022，Li et al.）**：首次把扩散框架系统搬到文本生成，提出嵌入空间去噪 + 离散化回读的完整流程，从此"扩散文本"成为可行课题；**LLaDA（2025，ByteDance / 开源）**：把思路升级成大规模预训练的掩码扩散语言模型，在规模上验证了"非自回归也能学到语言能力"，引起学界一波关注。

**为什么会出现**：节奏和世界模型很像——先有**概念验证**（2022 证明能生成），再有**规模验证**（2025 证明能学到真语言能力）。中间近三年它在默默积累"噪声设计、精化策略、扩散步数与质量的权衡"这些工程细节，直到 LLaDA 用规模把关注度拉回来。

**机制表：两次代表实践（要素事实，写作环境无外网、未在线复核）**

| 工作 | 年份 | 关键主张 |
|---|---|---|
| Diffusion-LM | 2022 | 嵌入连续空间扩散 + 量化回读，文本可扩散生成 |
| LLaDA | 2025 | 大规模掩码扩散语言模型，验证非自回归可学语言 |

**边界与坑**：LLaDA 的关注度 ≠ 全面胜利。它证明了"规模够大时非自回归也强"，但**没有证明不付代价**——推理时仍需多次迭代、可控性、长程一致性仍是短板。把这波关注读成"自回归要完"是常见的过度解读。

## §3 与自回归对比：目前不能全面竞争

**是什么**：一句话结论——**这条路线目前不能全面竞争**。质量上，自回归在长文本连贯、指令跟随、事实性上仍是基准；速度上，扩散虽可并行，但迭代步数×每步成本往往抵消优势；生态上，所有成熟工具链（推理引擎、量化、微调框架）都围绕自回归自注意力构建，Diffusion-LM 没有这套基建。

**为什么会出现**："不能全面竞争"是**结构性事实**，不是一时落后。自回归的基建优势是十多年累积的：训练框架、KV 缓存、投机采样、量化器全是它的形状。任何替代架构要竞争，先要重新长一遍这套生态——这就是"替代叙事"的共同处境（Mamba 亦同，见 [15-04](../15-前沿技术/04-SSM-Mamba与混合架构.md)）。

**机制表：竞争维度对照**

| 维度 | 自回归 | Diffusion-LM | 竞争力 |
|---|---|---|---|
| 生成质量 | 基准 | 落后（长程连贯弱） | 自回归胜 |
| 生成方式 | 串行 | 可并行（但步数叠加） | 各有局限 |
| 生态 | 完备 | 缺口 | 自回归碾压 |
| 可控重写 | 弱 | 有独特价值 | 扩散略胜，但场景窄 |

**边界与坑**：别做"维度加总"——虽然 3:1 自回归占优，但**"可整体重写"这一条是自回归给不了的**。单就"要让已有的生成往某个方向整体平移"这类需求，扩散/掩码式天然更有抓手。这条窄路（可控重写、渐进编辑）正是它保留价值的地方。

📎 **关联代码**：知识型，无探针。竞争维度判定规则全部写在正文，确定性可核；与 [15-04 的复杂度账](../15-前沿技术/04-SSM-Mamba与混合架构.md) 对照可看出"生态劣势"是替代叙事的共同主题。

## §4 路线意义：为"非自回归生成"保留一条路

**是什么**：Diffusion-LM 的真正价值不在赢，而在**"不把所有的赌注押在自回归上"**。它保留了第三条生成范式的可能性——非自回归、整体生成、可控重写。这一路可能看起来很窄，但它是"如果自回归撞上墙（长程规划、整体结构控制）我们往哪退"的保险丝。

**为什么会出现**：工程界有句俗话——"手上只有锤子，看什么都像钉子"。若所有生成都被自回归垄断，**"整体结构控制"这类需求就没有出口**：需要渐进编辑场景（改写、风格迁移、语义平移）时会被迫重生成整句。保留一条非自回归路，就是给这类需求留一个工具箱，而不是锁死唯一解。

**机制表：自回归撞墙假想场景 × 非自回归出口**

| 若出现此需求 | 自回归的做法 | 非自回归的做法 |
|---|---|---|
| 把一段话整体温和改写 | 重生成，易漂移 | 在向量空间对齐目标方向去噪 |
| 长文结构（数十段） | 逐段续写，易跑偏 | 全局向量约束 + 分步精化（构想） |
| 风格整体迁移 | 全量重生成 | 语义向量平移（构想） |

**边界与坑**：**可能性 ≠ 现实**。上表"构想"两字不能省——今天这些还大部分停留在论文愿景里。作为读者，理解"它为什么存在"即可，别把它当作今天就能用的生产路径去评估选型。

## §5 学习动作：理解概念即可

**是什么**：本节给出定义清晰的学习姿势——**理解概念即可**：①知道 "扩散用于文本" 是怎么回事（§1）；②记得两次代表工作（§2）；③能说出"为什么不能全面竞争"（§3）；④理解它存在的意义（§4）。在 15-01 的读法矩阵里，这属于探索档的**"该知道"**。

**为什么会出现**：探索档的学习目标是**建立"可重判的基线认知"**，而不是投入时间去复现、调参、做项目。因为成熟度会变（季度回炉时若 LLaDA 之后又有规模验证，很可能升为"该看"），读者需要的是一次性建立"它是啥、它卡在哪、下一次变化往哪看"，从而让季度重判变得廉价。

**机制表：2025 年 11 月的读法（可随时间表更新））**

| 成熟度 | 动作 | 本文给什么 |
|---|---|---|
| 探索（当前标注） | 该知道 | §1~§4 概念 + 谱系 + 卡点 |
| 若升为在途 | 该看 | 跟发布与综述，季度重判 |
| 若升为成熟 | 该学 | 走对照索引开主干正文 |

**边界与坑**：别因为 LLaDA 上了新闻就把它当"该学"。**关注热度不是成熟度**——热度是发布事件，成熟度是可复现的生产价值。本文与 15-01 矩阵一致地把它标为探索，并按"该知道"给读法。这条判断在季度回炉时可重判、可推翻。

📎 **关联代码**：知识型，无探针文件。读法规则与 [15-01 §3 判定逻辑](../15-前沿技术/01-前沿索引页-成熟度矩阵.md) 完全一致（探索→该知道、升档→该看/该学），确定性可核；不另造探针。
