## §1 定位：从"学会说话"到"学会运转"

**是什么**：语言模型学的是**语料里的人类符号**——文字、代码、对话。世界模型的追求是学**世界本身的规律**：物体在空间中如何运动、因果如何传导、一段物理过程下一步会发生什么。它不是"语言的模拟器"，而是"世界的模拟器"。

**为什么会出现**：因为"会说话"远远不够。若一个代理要在真实的房间、真实的机器、真实的生产线上行动，它需要的是**对环境的预测能力**——我推这个杯子它会往哪倒、我拧这个阀门管道压力会怎么变。语言模型只能从文字描述中间接获得这种能力；世界模型想直接从观察（视频、传感器序列）里把它学出来。

**机制表：语言模型 vs 世界模型**

| 维度 | 语言模型（已成熟） | 世界模型（探索期） |
|---|---|---|
| 学习对象 | 人类符号序列（文字/代码） | 环境状态转移（视频/传感器/状态序列） |
| 功能 | 续写、推理、生成 | 预测、想象、模拟 |
| 成熟产物 | 聊天、Agent、RAG 全栈 | 视频生成、（探索中的）具身/决策模拟 |
| 当前状态 | 商业主流 | 离商业主流远（§15.6 原文标注） |

**边界与坑**：不要拔高"世界模型"这个词——它目前**没有公认定义**，Sora 不等于世界模型，视频生成也不等于世界理解。树的边界是：很多被叫作"世界模型"的东西其实只是"视频生成模型"，它学会了像素与镜头语言，不等于学会了物理因果。

📎 **关联代码**：plan3 §15.6 明确标注 **"能算——无"**（知识型篇，不配探针）。本节演示一种确定性判定——"表里的行为是你的数据集里能观测到的，还是需要模型自己推出的"，用 4 种行为样本原样比对差异：

```python
# 内联确定性片段（非探针，纯 stdlib，与正文 §1 一致，无随机无网络）
BEHAVIORS = {
    "续写下文":       "可观测",   # 语言模型：直接学自语料
    "按格式问答":     "可观测",
    "预测杯子倾倒":   "需推出",   # 世界模型：环境规律
    "规划多步物理过程": "需推出",
}
assert sum(1 for v in BEHAVIORS.values() if v == "需推出") == 2
assert all(len(k) >= 4 for k in BEHAVIORS)                     # 4 条行为全部覆盖
print("§1 行为分类：可观测 %d · 需推出 %d （结论恒一）" % (
    sum(1 for v in BEHAVIORS.values() if v == "可观测"),
    sum(1 for v in BEHAVIORS.values() if v == "需推出")))
```

## §2 三条应用岔路：视频生成 / 具身智能 / 决策模拟

**是什么**：世界模型的能力要靠应用落地，当前主要有三条岔路——**① 视频生成**：用学到的"世界规律"生成连贯、符合物理直觉的视频；**② 具身智能**：给机器人一个"环境的预言机"，让动作规划先在心里模拟一遍再执行；**③ 决策模拟**：在虚拟环境里推演多种选择的结果，辅助规划与决策。

**为什么会出现**：三条岔路本质上是同一个需求的三个出口——**不能在真世界里试错，所以先在学到的世界里试**。视频生成卖"想象力"（离钱最近），具身智能卖"安全性"（先在模拟里撞，不在厂房里撞），决策模拟卖"远见"（先推演再下注）。三者共享同一块内核：预测。

**机制表：三条岔路 × 成熟度 × 正交骨架**

| 岔路 | 核心价值 | 成熟度（地图标注） | 正交骨架 |
|---|---|---|---|
| 视频生成 | 想象 / 创作 / 数据 | 探索（Sora 是前沿样本） | 视频主干 [10-06 视频与文本](../10-多模态/06-视频与文本.md) |
| 具身智能 | 先在模拟里验证动作 | 探索（研究热点） | [10-多模态](../10-多模态)、[09-Agent体系](../09-Agent体系) |
| 决策模拟 | 先推演再决策 | 探索（前沿） | [02-核心原理](../02-核心原理)（推理/规划心智） |

**边界与坑**：三条岔路**别并进**。它们用的都叫"世界模型"，但工程栈完全不同——视频要的是扩散/生成栈，具身要的是 RL + 仿真，决策模拟要的就是规划与时序建模。在探索期把它们当成一个方向去学，会同时踩进三个大坑。优先顺序建议：**注意力只留给和你岗位相关的岔路**，其余两条知道存在即可。

📎 **关联代码**：仍为知识型，无探针（plan3"能算——无"）。三岔路与主干骨架的映射只做坐标引用，全部指向 [10-06 视频与文本](../10-多模态/06-视频与文本.md)、[10-多模态](../10-多模态)、[09-Agent体系](../09-Agent体系)、[02-核心原理](../02-核心原理) 等仓库现存文件，无死链。

## §3 代表工作谱系：Sora / Genie / 视频预测

**是什么**：把"世界模型"从概念变成可运行的系统的几条代表工作——**Sora（OpenAI，2024）**：把视频当"序列"建模，给定提示词生成高连贯度视频，被认为是视频方向最接近"世界理解"的样本；**Genie（DeepMind，2024）**：从单张图生成可交互的 2D 世界，玩家能动、世界会回应，是"可玩世界模型"的雏形；更早的**视频预测类研究**（VideoGPT / Video Prediction Network 等思想谱系，2022 年前后）先证明了"让模型预测视频下一帧"这件事本身成立。

**为什么会出现**：这条谱系的节奏很有代表性——先有**研究证明 预测能学**（视频预测），再有 **工程把它卷到可商用质量的生成**（Sora），再有人 **研究把交互性塞进去**（Genie 的可玩世界）。每一代都是在前一代"预测没错"的前提下，往"预测有用"再迈一步。

**机制表：代表工作一瞥（要素事实，写作环境无外网、未在线复核）**

| 工作 | 年份 | 类型 | 核心主张 |
|---|---|---|---|
| 视频预测类研究 | 2022 前后 | 研究 | 视频的自监督预测任务可学习 |
| Sora | 2024 | 产品级 | 视频序列建模 + 大尺度生成连贯视频 |
| Genie | 2024 | 研究 | 单图生成可交互世界（可玩、可回应） |

**边界与坑**：切莫把"生成得漂亮"等同于"理解了物理"。Sora 生成的视频绝大多数情况下**符合外观直觉**，但会在物理细节上翻车（物体数量、刚性、持久性）。这恰恰是探索期的正确定位——它证明了"可学"，还没证明"可信"。

## §4 成熟度判定：为什么"探索档"还没拿到商业门票

**是什么**：按 §15.6 地图原文标注，世界模型 = **探索期，离商业主流远**。判定为探索的理论依据有三条——**① 价值未闭环**：视频生成有商业出口，但"世界理解"本身还没有可持续的付费场景；**② 能力未达标**：可以生成、不可以信赖（物理翻车普遍存在）；**③ 基础设施未齐**：缺少统一评测基准，谁都说不清"世界模型该考什么"。

**为什么会出现**：所有探索期方向长一个样——**研究热度高、工程标准无、商业模式无**。热度高是因为它是"下一代智能"的叙事；标准与商业没有，是因为物理因果还缺一块可靠的、可测量的界碑。这不是坏消息，而是它的真名：探索。

**机制表：三档成熟度的判定特征（与 [15-01 §3](../15-前沿技术) 共用同一套规则）**

| 成熟度档 | 特征 | 世界模型现状 |
|---|---|---|
| 成熟 | 进生产、有稳定解法 | ❌ 尚无"世界理解"的稳定解法 |
| 在途 | 方向明确、格局未定 | ❌ 连"该考什么"都未统一 |
| 探索 | 研究前沿、离商业主流远 | ✅ 正中此档（地图原文标注） |

**边界与坑**：探索 =/= 不重要。不重要的东西不值得跟踪，而世界模型**值得跟踪**（§15.15 的方向簇里也保留了"端侧/具身"等接口）。读法上要区分两件事——**你跟踪它**：读论文、看发布，⏳；**你投入它**：如果你的工作正在具身/机器人方向，它对你就是"成熟·该学"（个人角色覆盖默认档，规则见 15-01 §3）。这篇文章作为默认档给出"看一眼"。

📎 **关联代码**：知识型篇，无探针（plan3"能算——无"）。成熟度特征对照沿用 15-01 的判定规则（[frontier_index_demo.py](../code/notebooks/_tools/frontier_index_demo.py) 账 C 的「角色覆盖优先级」），本节不新建探针文件。
