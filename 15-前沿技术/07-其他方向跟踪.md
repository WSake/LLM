## §1 搜索增强生成（Search-Augmented Generation）

**成熟度：已标配（2024-2025）**。5 分钟讲清楚：给模型挂一个 **web 搜索工具**，把检索到的实时网页/权威内容交给它，模型基于"读到的事实"而非"记忆"作答，显著降幻觉（事实性错误）。**2024-2025 已从"要不要"变成"默认开"**——ChatGPT/Claude/Gemini 全部默认联网搜索；针对"事实型问题"它比纯记忆式 RAG 更全面，针对"个性/开放型问题"仍是 RAG+Agent 的活。

**与主干映射**：
- RAG 基础 = `05-推理与部署` + 检索章（如 `14-应用工程` RAG）；搜索增强是所有 RAG 的"联网版"，两者共用"检索→拼进 prompt→模型作答"的流水线。
- 评测 = `11-评测与可观测/05-RAG评测`（RAG 的评测门禁，搜索增强直接复用 Fact 分）。

## §2 代码执行 / 沙箱推理（验证回路）

**成熟度：在途（2024-2026 快速爬升）**。核心：模型不仅能"说答案"，还能**写代码 → 在沙箱里真跑 → 看跑的结果再改**——形成闭环。可验证答案（`02-核心原理/16-GRPO与RLVR`）是它的机制母章：**凡是能"跑出来验对错"的推理，RLVR/GRPO 就能当训练信号**。

5 分钟讲清楚：代码推理、数学证明、agent 工具调用三处都用"**沙箱执行结果**"当验证信号。它吃下"模型自己感知自己的输出"和"执行是唯一真值"两个约束。

**与主干映射**：
- 机制 = `02-核心原理/16-GRPO与RLVR`（可验证奖励喂合成，代码执行是最强的可验证源之一）。
- 安全 = `12-安全/06-Tool-Agent安全`（沙箱是防"模型执行恶意代码"的第一道防线）。
- 评测 = `11-评测与可观测/06-Agent评测`（Agent 评测依赖沙箱回放）。

## §3 端侧 Agent（手机助理、PC Agent）

**成熟度：快速增长（端侧 SLM 落地 + 硬件加速的合流）**。`15-05 SLM与端侧` 的下一步：小模型不只是"离线也能问答"，而是**在设备上生成动作**（调 app、读屏幕、点按钮）——手机助理（抄日程、回消息）、PC Agent（读文件、跨应用执行）。

**为什么发生**：端侧已经装得下 1-8B 的模型（15-05 装载账），硬件（NPU/MLX）让"跑得动"接近"常驻跑得起"；隐私本地化的需求把"动作"留在端侧。

**与主干映射**：
- 装载/量化 = `15-前沿技术/05-SLM与端侧AI`（本 15 章内直接引用前一站）。
- Agent 框架 = `14-应用工程`（Agent 的编排、工具调用，端侧是它的一个部署形态）。

## §4 模型身份与安全（水印、C2PA、AI 内容检测）

**成熟度：立法/合规驱动（2024 起抬头）**。核心是**“哪个内容是不是 AI 生成的、由哪个模型生成的”可追溯**。三个工件：
- **水印（Watermarking）**：在模型输出里嵌入人类看不见但程序可检测的标记（logits 统计水印）。
- **C2PA**（Content Authenticity）/内容来源标注：在内容元数据里声明"由 X 模型于 Y 时间生成"，链式签名。
- **AI 内容检测**：对已发布内容做"是 AI 生成还是真人"的判别器。

**为什么现在是必答题**：欧盟 AI Act、国内生成式 AI 管理办法都对"合成内容要可识别"做合规要求；同时**版权、"谁在装真人"信任危机**让追溯成为刚需。

**与主干映射**：
- 安全 = `12-安全` 全章（越狱/注入/隐私是"内容在恶意"侧，本篇是"内容来源"侧，同一安全账的另一半）。
- 红队/审计 = `12-安全/11-红队方法`（水印/检测的可信度需要红队视角的对抗评估）。

## §5 长时任务与 Agent 云

**成熟度：早期（2025-2026 刚起）**。给"多 Agent 协作 + 长时背景任务"的愿景：不是单次对话，而是**多个 Agent 编排成一个"云端进程"**，跑小时级任务（市场调研→出报告→等审批→改版），状态落盘、断点续跑。

**为什么早期**：要解决"状态化"（Agent 进程崩溃后从哪恢复）、"记忆持久化"（长任务的上下文不可能都在 prompt 里）、"多 Agent 协作信任"（谁在什么协议下共享什么）。这些都是 2026 年还没有统一答案的开放问题。

**与主干映射**：
- 推理预算 = `02-核心原理/20-推理模型与Test-time-Scaling`（长时任务=test-time compute 的多轮版本）。
- 工程底座 = `13-工程化与基础设施/02-分布式训练基础设施` + `07-可观测性`（Agent 云把模型当作"有状态的云工作负载"来管）。
