# 🧠 预训练：为什么"猜下一个词"能学会知识

> 对应知识点：知识地图 **§17.2.13 预训练（Next Token Prediction）**（🟢 概念 + 🔴 研究者）——"在万亿级语料上自监督学习，目标是预测下一个 token"；前置：Transformer；**论文**：GPT-2(2019)、GPT-3(2020)；**框架**：Megatron/DeepSpeed；**衍生**：CPT、多阶段训练；**关系**：一切能力的来源，对齐的起点；**实践**：小语料训练一个模型并观察 loss 曲线。紧承 Logits 与采样（`11`）。
> 一句话：**预训练整个过程的全部指令只有一条："根据前面已经出现的 token，猜下一个 token 是什么"。这条指令望上去弱得像抄作业，却在一个恐怖机制上运转——每段文本的每个位置，都同时是一个"要预测的答案"和一个"预测后续的依据"（实测：894 个 token 的语料一次错位就给出 893 个训练样本，且一个标注都不用打）。于是"预测下一个"变成了"把文本背后的规律压进参数"：同一个事实换 5 种说法写进语料后，模型能在第 6 种全新句式上把 6/6 个事实续对，随机初始化对照 0/6。这就是"续写学到知识"的全部秘密。**
> 可复现：本文数字全部来自 `code/scripts/pretrain_demo.py` 实验 A1–A4（纯 CPU 训练一个 18 万参数的最小 GPT，约 3 分钟，seed 固定、零下载）。

## 0. 为什么"猜下一个词"就够了

前面 0–11 章讲完了"**一个训练好的模型怎么生成**"：token → embedding → attention/FFN → logits → 采样。现在追问一件更根本的事：**这个会生成文本的"脑袋"是从哪来的？** 答案听起来轻描淡写——

> 训练目标只有一条：给定一句话的前半段，预测下一个 token。

GPT-2/3 论文里那个著名的过程就是它：互联网抓来万亿 token 的文本，逐段喂进去，模型在每个位置都用前文预测下一词，错了就按交叉熵更新参数。没有人工标注、没有标签工程员、没有"正确答案集"。这为什么能行？因为**"预测下一个词"并不真的是"猜下一个词"，它是"把这段文本为什么长这样"学到手**。文本不是随机字符：它是人类对世界的观察、因果链、约定俗成——只要能预测单个词语，你事实上已经把"文本背后可预测的结构"压缩进了参数。本章用一台笔记本 CPU 就能完整演示这条链路。

> 一句话：**预训练 = 省略全部人工标签的"随文预测"。规模拉满时，千亿参数把"人类文本的可预测结构"压缩成了"世界模型"的一部分。**

## 1. NTP 目标长什么样：一个 token、一个答案

`11` 章教过 decode 的最后一跳：模型对"当前位置"吐一个 `logits` 向量（词表大小）。**真实的预训练把这句话反转使用**——不是"给我一个位置，我吐出下一个词"，而是"这里有真实的下一词（语料自己给出的），请让吐出的概率给它最高分"：

```text
训练样本（input → target，一个 token 的答案）：
  "the gravitational acceleration on earth near the" → 下一个是 "surface"
  模型的作业：让 P(surface | the gravitational acceleration on earth near the) 尽量大
  （整段文本在每个位置同时做这件事 → 见 §2 错位）
```

一句话，**NTP 是"最大似然的自回归"**：最大化每个位置"以所有前文为条件、下一 token 被命中的概率"。数学上就是最小化交叉熵 *H*(p*) = −log p(下一个词 | 前文)。这不是"一个特殊 trick"，它就是语言模型的所有。

> 记忆抓手：**NTP 目标的反着读**——训练 = 每个位置都问"下一个是什么"；推理 = 每个位置都答"下一个是什么"。同一个 forward，训练要它答对、推理要它答得自然。

## 2. 错位对齐：一段文本 = N-1 个训练样本（实测 A1）

"每个位置都预测下一个"是怎么一次计算完成的？答案是**错位（shift-by-one）**：把你手头的 token 序列 `t0 t1 t2 … t_{N-1}` 切成两串，input 串拿 `t0…t_{N-2}`，target 串拿 `t1…t_{N-1}`——**target 永远是 input 向右平移一格**。这样 (input, target) 的逐位关系正好是"前一格 → 当格的答案"。一段 N 个 token 的文本，一次前向就给 N−1 个预测位。

`pretrain_demo.py` 的 A1 直接验证这件事：

```text
实测 A1 错位对齐：
  语料：894 个 token（word-level）→ 错位成 893 个 (input, target) 预测位
  句子：the gravitational acceleration on earth near the surface is about 9 . 8 meters …
  input[1:] == target[:-1] 逐位一致（shift-by-one 恒等）：✅
  同一个 (batch=16, seq=48) 的矩阵前向一次，同时算完 16×47 个预测任务 → 数据复用 N-1 倍
```

两个值得带走的事实：

1. **数据复用是不花钱的**：在 (B,T) 矩阵上，目标就是"错位后的同一批 token"——**没有任何 token 需要人工标注**。这是"语料即为标签"的自监督含义（`04-训练体系` 的数据飞轮直接挂在它上面）；
2. **实现细节是唯一的魔法线**：错位那行代码（`data[s+1 : s+T+1]`）写错一格（比如对齐自己、或没对齐），训练就静默地退化成一个"恒等映射泄露"的模型——见 §9 常见坑。

> 一句话：**NTP 的"免费午餐"是一次错位把整段文本变成 N-1 个监督样本；样本没有标签，标签都在前文里。**

## 3. 目标函数：交叉熵与 ln(V) 起手

我们希望 `logits → softmax(概率)` 尽量贴近"真实下一词独热"的分布。交叉熵最小化正是干这个的——而它有两个非常"可感知"的极端：

**起手的下界是 ln(V)**。随机初始化时，模型对任何位置都"不懂"，输出接近均匀分布（每个词概率 ≈ 1/V），此刻的交叉熵 *H* ≈ ln(V)（V 是词表大小）。所以训练开始前的 loss 是一个**可以提前手算的常数**——看到它，你就知道模型起点有多"懵"：

```text
实测 A2 起手：
  词表 V = 354 → 理论起手 ln(V) = 5.869
  全部位置喂同一个 <unk> 输入的实测 loss = 6.110（≈lnV；多出的 0.24 是
  随机初始 logits 不完全均匀 + 同一输入退化造成的首位置偏差）
```

**收敛解读：perplexity = exp(loss)**。`11` 章把 PPL 定义为"每预测一个 token 时的有效候选数"；在这里，`loss=0.06` 意味着模型几乎锁定了下一步。

> 记忆抓手：**ln(V) 是你对 loss 曲线唯一的"免费标尺"——训练拉到 ln(V) 的几分之一，才算模型真正开始有记忆。**

## 4. 训练看懂 loss 曲线：一个能跑的微型 GPT（实测 A2）

现在真训一个模型。为了这儿能在笔记本 CPU 上跑，我们缩到"教学最小"：**18 万参数的单 Block 仅解码器**（LN → 因果 MHA → 残差 → LN → FFN → 残差 → 输出头，与 `01-Transformer` 那套"反向传播已全元素对账 <1e-5"的手写引擎同构），配你已见过的全套零件：Embedding 查表（09）、位置嵌入 + 因果 mask（02/05），decode 阶段则接上 `10` 的 KV Cache 心智与 `11` 的采样旋钮（A4 演示）。

```text
实测 A2 训练（语料 894 token、V=354、模型 183,168 参数、B=16、T=48）：
  step   250  loss 0.087  ppl 1.09
  step   500  loss 0.081  ppl 1.08
  ...
  step  2000  loss 0.045  ppl 1.05
  step  3000  loss 0.060  ppl 1.06
  训练 3000 步耗时 205 秒（15 步/秒，纯 numpy CPU）
```

这条曲线说明了三件事：

1. **收敛极快得到"记忆"**：因为语料只有 894 token，模型到 step 250 就能把"下一个词"猜得相当好（loss 0.087）。**注意这只是过拟合玩具**——一个 18 万参数模型把 894 词的语料背了下来。真正的预训练要靠"背不完的海量语料 + 足够大参数"来抵消这一点（19 章 Scaling Law 接住）；
2. **波动是正常的**：最后几百步在 0.045–0.105 之间来回（ppl 1.05–1.11），因为 batch 很小、相近数据反复刷。曲线不再单降 ≠ 模型坏了，是"玩具在记忆的边界抖动"；
3. **optimizer 是标准件**：50 步 warmup + Adam，这些 `04-训练体系` 会展开；这里只告诉你"训练循环 = 前向 → 算梯度 → 更新参数"，关键观察点是 loss 起于 ln(V)（懵）→ 落于可读区间（懂）。

> 一句话：**loss 曲线是训练的唯一仪表盘——从 ln(V) 起步、往下降、然后平台；玩具上见"背下来"的信号，真模型上见"泛化"的信号（两者靠规模区分）。**

## 5. 知识是怎么进参数的（实测 A3）

"原理"说透了，"知识"到底存哪？做个对照实验：**把 6 个事实各用 5 种句式写进语料（比如重力加速度，写法一"the gravitational acceleration ... is about 9.8..."、写法二"when you drop an object on earth it speeds up at about 9.8..."、……），训练后，用一个语料里从来没出现过的第 6 种句式，问模型"下一个是什么"**。

所谓"没出现过"，具体是：每个测试 cue 都是新句子（不逐字出现在语料里），只是借用语料里学过的局部搭配。结果极其戏剧化：

```text
实测 A3 跨句式事实续写（测试点 6 个，argmax 首 token）：
  知识         cue（全新句式）                                      argmax    期望
  g≈9.8       "when an object falls on earth it speeds up at" →   "9"...     ✅
  π≈3.14      "...circumference divided by its diameter gives" →   "3"...     ✅
  e≈2.71828   "the number e which is about" →                      "2"...     ✅
  光速         "the speed of light in a vacuum is roughly" →        "300000"   ✅
  沸点100      "the boiling point of water at sea level is" →       "100"      ✅
  公转365      "one full orbit of earth around the sun takes" →     "365"      ✅
  训练后 top-1 命中 6/6；随机初始化对照：0/6（≈1/354≈0.3%，纯猜）
```

三个读点：

1. **6/6 不是靠背句子达成的**：它的"知识"（g=9.8、π=3.14159 …）只作为 5 种句式出现过，测试 cue 是新组合；模型把"何时何地出现什么数"浓缩进了**参数**（主要是 Wout 的列 + FFN 的相互作用）——这是"知识 in weights"的最直白演示，`04-训练体系` 里"预训练学到世界模型"的说法就是这件小事放大一亿倍；
2. **对照模型 0/6**：同一个 cue，随机初始化的孪生模型一个都答不对——证明"能答"不是 cue 自带的提示词魔法，而是训练真的写进了规律；
3. **诚实的边界**：这个"知识"只在语料统计上靠谱（同一个数换了 5 种说法反复出现），**换个语料里从没出现的真问题就不会**。预训练学的是"语料的统计规律"，不是"世界真相"——这是它与推理模型（20 章）的界限。

> 一句话：**"知识进参数" = 同一事实的不同句式在语料里反复出现 → 参数把它们压成一条规律 → 新句式能命中。统计强度决定记忆，不是样本量。**

## 6. 为什么"猜下一个"= 学到知识：预测即压缩

为什么"预测下一个词"能在参数里长出知识？直觉是这样的：**一个能持续预测下一个词的模型，本质上是一部"高压缩率的世界编码器"**。要预测"苹果掉下来"后面跟着什么，你得"知道"引力把物体往下拉；要预测"一百摄氏度"后面是"水沸腾"，你得"知道"这个物理事实。预测得准，意味着模型内部必须持有文本背后的**因果与共现结构**——参数就是它的"压缩字典"。

信息论把这件事说得更绝：一种数据如果存在规律，它的**可预测性 = 可压缩性**（Shannon 熵）；能对文本做一次次小预测的模型，正是在逐步逼近"文本的极限压缩"。GPT-2 论文里那句著名的话就落在这："预测下一个 token 的自然语言跨足够多样的语料，就是通用学习任务。"（*Language Models are Unsupervised Multitask Learners*）

```text
教学对照（把 A3 的 6 个 cue 换成"从未配对的随机数"，模型会怎样）：
  它不会"创造答案"：没有统计锚点 → 输出退行为语料常见词 / 模板句（§7 的采样会看到）
  → 再次确认：预训练存的是"统计规律"，不是"编造能力"
```

> 一句话：**预测 = 参数里的压缩；知识 = 压缩留下的结构。这就是"续写"这种弱目标能在参数里种出"世界模型"的机制来源。**

## 7. 把模型把玩起来：自回归采样（实测 A4）

训练完的模型怎么"用"？`10` 章教 decode 的 KV 优化、`11` 章教采样旋钮——这里只需把它们接到刚训好的玩具上，喂一个前缀，观察它续写：

```text
实测 A4 自回归采样（贪心 vs 采样各续 48 token）：
  β 贪心（temperature 0）：
    「the sun is a star」 →
      at the center of our solar system . the moon circles the earth about once every month .
      a year is the time it takes a planet to complete one orbit . gravity pulls every object towa…
  γ 采样（temperature 0.9）：
    「gravity pulls every object」 →
      appears in many growth formulas . light travels in vacuum at about 300000 kilometers per
      second . the speed of light is close to 300000 kilometers per second . …
  bigram 去重率：贪心 0.96 vs 语料对照 0.80 ｜ 采样 0.83
```

三个观察：

1. **真会"续写"**：给你 `the sun is a star`，它顺着天体物理往下接、语法正确、句间主题连贯——这就是手工从 0 训出来的"语言感觉"；
2. **它是"背模板的组合"**：采样那条能看到句与句之间容易"重置"成另一个学过的句子（`appears in many growth formulas` 之后跳去讲光速）——**小模型的联想是模板检索，不是叙事**。这也是真实生成里"重复/绕圈"的根（11 章重复惩罚治的就是它；量级变大后还需要 Decoding strategy 加固）；
3. **温度拨它，多样性就有了**：同一模型，T=0 单调地把学过的句子背一遍，T>0 则开始抽中低频词、句子更飘——`11` 章"熵的杠杆"在真实训练模型的 logits 上完整复现。

> 一句话：**采样把"训练好的先验"变回"一段话"；玩具小模型能不连贯地"重置"，大模型用更大参数与更好的解码策略平滑掉它。**

## 8. 实践任务：玩具到 100M 模型的放大账

知识地图 §17.2.13 的实践题是"小语料训练 100M 模型并观察 loss 曲线"。我们没用 GPU 训 100M（那需要真算力与海量数据，见 §6 的诚实边界），但可以把"放大账"算得清清楚楚——这账直接复用 `09`/`10` 的显存技能：

```text
模型参数账（教科书式估算 ≈ 2·L·d·(4d + V·…) 的量级感）：
  玩具（本章）：183,168 参数 ≈ 0.18M —— CPU 205 秒
  100M 模型：           ~100M ≈ 550× 玩具
  其预训练：
    - 参数量决定显存（fp16 低精度下 ~0.2GB/100M 参数，量级感；BF16 精度账在 04 训练精度章）
    - 数据量决定时间（GPT-3 的 175B 用了 ~570GB 语料；100M 玩具级 ≈ 几十 MB 文本即可看曲线）
    - 一次 epoch 的 token 数 ∝ 语料规模，多次 epoch 提量不提质（数据是更重要的乘法因子）
  关键权衡：100M × 1B token ≈ 0.1 万亿 token 的有效训练预算（19 章 Scaling Law 接住）
```

换句话说，**从 0.18M 到 100M，变的不是"训练循环的写法"，是"参数的容量 × 语料的规模 × 算力的时长"三个乘子**——他们共同决定 loss 曲线会在哪里平台、模型的泛化有多少（这正是 Scaling Law 的章节要展开的核心主题）。

> 一句话：**本章的玩具模型是"显微镜下的预训练原理"；把它放大到 100M ≈ 550× 玩具，乘法因子有三个：参数、数据、算力。**

## 9. 常见坑

| 坑 | 症状 | 修法 |
|---|---|---|
| 错位对齐写错（target 用了自己） | loss 立刻降到 ~0、训练"结束"，但模型是"复读机" | target = `data[s+1:s+T+1]` 而非 `data[s:s+T]`，A3 的自测（换句式能答对）是唯一裁决 |
| 把 `<unk>` 教成"万能词" | 采样里大量 `<unk>` 占位 | 小语料 min_freq=1 全保真；大语料用子词（08 章 BBPE）让词频分布自然 |
| 把 loss 平台当"训练完" | 曲线波动就换超参 | 小 batch → 噪声大，看趋势而非单点；先用 warmup + Adam 沉淀到平台再看 |
| 拿玩具的"知识"当推理能力 | A3 全对就以为"会推理" | 语料里没算过的新问题它答不出（诚实的边界）；推理是 20 章的事 |
| 以为预训练是唯一阶段 | 用完预训练模型直接当助手 | 预训练=续写者；还要 SFT + 对齐（下一章），否则只会"像文本" |

---

## 10. 衔接下一章：从续写者到对话者

预训练教会了模型"像文本一样说话"，但文本不等于"有用"。它不会回答问题——它会顺着你问的问题继续"编下去"（真实 GPT-2 时代的经典现象）。下一步的 **SFT（监督微调）** 做的事是把这团"续写能力"接到"指令 → 期望回答"上：给一段 (指令, 金标准回答) 的小数据，同样做 NTP——不对，预测的是"回答"的那个位置。它把"续写者"变成"对话者"，是预训练到助手之间最关键的一步工程：

> **[`13-SFT-监督微调`](../02-核心原理/13-SFT-监督微调.md)**（下一章）：接住本章"预训练只给出续写能力"，讲"如何用相对小的指令数据把它掰成对话者；以及为什么 SFT 后模型不再只是'背模板'"——同一目标（NTP）只在回答区算账（loss masking），玩具实测：200 步掩码 SFT 把全新问法命中率从 1/6 拉到 6/6、问题区 CE 从 0.34（在背问题词）变成 16.6（不学问题词）；同预算下 5 句式多样数据 6/6 vs 1 句式重复数据 3/6。一条链路串起：预训练(NTP) → SFT(对齐到指令) → 对齐(RLHF/PPO)，正是 `04-训练体系` 那条流水线的第一步。

> 一句话带走：**预训练 = 用"猜下一个"把文本规律压进参数（0.18M 玩具上：6/6 跨句式事实命中、随机对照 0/6、能续出连贯段落）；它的弱目标在"统计足够强"时变成"知识"，在"统计缺席"时退化回模板——规模、数据、算力三个乘子决定它通向知识还是模板。**
