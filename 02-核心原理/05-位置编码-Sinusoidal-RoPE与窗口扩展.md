## 0. 顺序去哪了：注意力的排列不变性

把序列"今天下雪"和"下雪今天"给同一个注意力层，它看到的打分完全一样——因为 `att(Q,K,V)` 只做 **token 之间的点积（配对相似度）+ 加权求和**，不包含"谁先谁后"这个信息。这个性质叫**排列不变性**（permutation invariance）：你把位置打乱，注意力权重一一对应地打乱，但数值不变。

LSTM/RNN 时代根本没有这个问题——位置是"一步步走过去"时自然带上的。Transformer 把顺序感拿掉了，就必须**显式地重新注入位置**。这就是"位置编码"要做的唯一一件事：

> 一句话：**给每个位置的 token 打上一个"我在第几位"的记号，让注意力能区分"词"和"词的顺序"。**

---

## 1. 第一代解：可学习绝对位置编码

最朴素的做法（原始 Transformer `01-Transformer` 就是这么干的）：**引入一张可学习的 `W_pos`（max_len, d），每个位置一个向量，加到 token 上**。

$$x'_t = x_t + \mathrm{PE}_t,\qquad \mathrm{PE} \in \mathbb{R}^{\text{max\_len}\times d} \text{ 可学习}$$

优点：简单，任何深度都能学到任何位置模式。问题有两个：

1. **绝对位置感**：模型只能看每个 token 的"自己是第几个"，位置配对的相关性要自己从两个绝对记号里悟出来——不是不给，是给的"间接"。
2. **没有外推**：`max_len` 定死的，测试想超过训练窗口就没有 `PE` 可用（要么截断，要么重新训）。

这两个问题，更彻底的解法是在"相对位置"上做文章。下一篇（RoPE）之前，Sinusoidal 是过渡方案，但它的思路已经指向"用连续函数表达位置"。

## 2. Sinusoidal 绝对正弦：给频率，不给你

原始论文（Vaswani 2017）正文里其实用的就是 **Sinusoidal 位置编码**——把位置 `t` 编码成一组固定频率的正弦/余弦：

$$
\mathrm{PE}_{t,2k} = \sin\Big(\frac{t}{10000^{2k/d}}\Big), \qquad
\mathrm{PE}_{t,2k+1} = \cos\Big(\frac{t}{10000^{2k/d}}\Big)
$$

频率从 `10000^0=1`（慢）到 `10000^{-(d-2)/d}≈1/10000`（快）**几何铺开**：慢频率负责"大概在靠前还是靠后"（长程），快频率负责"精确到第几位"（短程）。三角函数的好处是：

- **参数零**：`PE` 完全由公式给定，不占一个可学习参数；
- **归一稳定**：每个位置的向量范数恒为 1（两个平方和恒为 1），注入不改变幅度；
- **假设子线性外推可行**：没训到的位置也能用公式生成——但注意，这只是"能算出个向量"，**算得出 ≠ 模式成立**（第 2.2 的对照实验就是证明）。

但它仍是一次"相加式、绝对式"编码：注意力打分里，位置差要靠正弦的和差积化出来，模型学这一步要花参数，也更难以外推。真正把"相对"做进几何的，是 RoPE。

## 3. RoPE：把位置差变成旋转角差

RoPE（RoFormer, 2022）换了一种注入方式：**不用加法，用乘法——把每个 token 的 Q、K 向量旋转一个"位置角度"**，旋转角差恰好是位置差。

### 3.1 公式：每对维度是一个“角度”，位置 m 对应“m 倍角度”

把向量每两维看成一个复平面分量 `(x_{2k}, x_{2k+1})`，位置 `m` 的旋转角是：

$$
\theta_k = 10000^{-2k/d},\qquad
(x'_{2k},\, x'_{2k+1}) = \big(x_{2k}\cos m\theta_k - x_{2k+1}\sin m\theta_k ,\ x_{2k}\sin m\theta_k + x_{2k+1}\cos m\theta_k\big)
$$

同样的频率表（`θ_k` 几何铺开），但这次位置直接进角度：**位置 m 的 token，就是逆/共原点转 m 步**。Q 与 K 各自转，然后点积：

$$
\langle q_m,\, k_n\rangle
= (R_m q)^{\!\top} (R_n k)
= q^{\!\top} R_{n-m}\, k
$$

最后一步用的是旋转矩阵的合成律 `R_mᵀ R_n = R_{n-m}`——**两个位置的旋转角之差，就是它们的位置差**。于是打分只依赖 `(n-m)`，不依赖 n、m 各自多大。

### 3.2 一句话直觉

> 正弦编码靠“两串三角函数叠出位置差”，RoPE 干脆**把位置变成角度**，点积里天然合成出“角度差=位置差”——相对位置是几何上必然的，不是学出来的。

这就是“RoPE 叫相对位置编码”的全部秘密。`apply_rotary` 的实现就是按公式一行旋转一对维度（`rope_demo.py` 里 10 行内可读）。

## 4. 三个性质实测：保范、可逆、平移不变

`rope_demo.py` 实验 A/B 的实测（seed 固定，可直接复跑）：

### 4.1 实验 A：纯旋转——保范、可逆（正交变换）

```text
原向量 |q| = 4.223411  旋转后 |q_r| = 4.223411
范数偏差 = 0.00e+00
再旋 -37° 回到原向量的最大偏差 = 4.44e-16  → 旋转可逆
```

RoPE 只旋转不缩放（正交变换），所以：

- **数值稳定**：注入位置不改变 Q/K 的模长，点积大小不会被“位置旋转”扭曲；
- **可逆**：信息没有丢失——这对后面“位置插值”能想成“把同一张表读密一点”很重要。

### 4.2 实验 B：平移不变——打分只依赖相对距离

把位置对 `(3,10)` 整体平移成 `(10,17)`（相对距离都还是 7），RoPE 打分不变：

```text
位置对 (3,10) 的 QK 打分: 2.967798
整体平移 7 → (10,17) 打分: 2.967798
平移前后打分差 = 2.22e-15  → 只依赖相对距离 (j-i)=7
```

对比例子：“绝对正弦相加”的位置编码在过去完整的同样平移下，打分会变：

```text
[对照·绝对Sinusoidal] 平移前打分 6.458161，平移7后 6.832192，差 = 0.3740
```

这一个数字（0.3740 vs 2.22e-15）就是“绝对”与“相对”的差距：绝对编码里 token 往右挪 7 位，语义配对的相关性被重新洗牌；RoPE 里完全不受影响。**这也是真实模型里"同一句话放在长上下文的第 1000 个 token"和"第 10 个 token"语义一致的物理保证**。

## 5. 为什么 RoPE 是事实标准

综合下来，RoPE 碾压前代的原因很清楚：

| 维度 | Sinusoidal 绝对 | 可学习绝对 | RoPE |
|---|---|---|---|
| 位置感来源 | 公式注入（绝对） | 学到（绝对） | **旋转角差（相对）** |
| 平移不变（实测） | 差 0.3740 | 同属绝对型（平移会变） | **2.22e-15** |
| 长度外推潜力 | 弱（绝对） | 训练窗口死 | 相对 → 只有“打分曲线”需要保真 |
| 参数量 | 0 | max_len×d | **0** |
| 数值 | 恒模 1 | 需控制 | 正交保范 |

“外推潜力”那条最值钱：《大模型知识地图》把 RoPE 定位为**长上下文与多模态的共用基石**——视频/长文档天然是长序列，而长文本能不能越过训练窗口，考的就是“打分曲线在窗外还是不是原样”（下一节）。

## 6. 长上下文的第一道坎：窗口外打分失态

RoPE 让打分只依赖相对距离 `Δ`，于是“一个模型在长度 4096 上训练的注意力”本质上就是**一张"Δ → 打分"的曲线** `s(Δ)` 只对 `Δ ∈ [1, 训练窗口]` 保真。问题是：真实模型训练时就是这么学的（比如学到"近处 1~20 步给高分“就近、远处给低分”）——一旦把序列加长，`Δ` 超过窗口，`s` 就**走出了它自己见过的自变量区间**。

`rope_demo.py` 实验 C/D 把这个机制做成了最小可复现实验：在窗口 `[1,32]` 内用真实的 q、k 拟合出就近核 `s(Δ)≈exp(−Δ/8)`（衰减、有界、可实现的 RoPE 打分函数）：

```text
窗内拟合 RMSE = 0.0000（真实 q,k 实现，打分 |s|≤137.39 全程有界不爆炸）
窗内就近峰 s(Δ=1) = 1.000；窗尾 s(Δ=32) = 0.021（应≈exp(-31/8) 贴近 0）

直接外推 2×：窗前峰 1.000@Δ=1；窗外又冒一个峰 4.559@Δ=64
  窗外峰/窗前峰 = 4.6  → 窗口外打分被三角函数形态接管，就近注意失效
```

两个要点：

1. **打分不会“爆”**：RoPE 是正交旋转，`|s(Δ)|≤|q||k|` 保底（这里 137.39），所以长上下文失败不是“数值爆炸”，而是**形态错位**——窗外那段落在哪峰值、多高，由三角函数组合的几何决定，而不是模型学到的意思。真实模型的表现就是：长距离 attention 乱序/对不上，记忆像是“看过但想不起”。
2. **4.6× 是软max 级别的抢**：窗外伪峰比窗前最近邻强 4.6 倍，在 softmax 里意味着那一格的注意力权重被远处 token 拿走——就近注意直接失守。这就是为什么"把 max_len 调大继续生成"通常直接烂掉。

## 7. 位置插值 PI：把窗外拉回窗内

解法思路很朴素：**测试时把绝对位置都除以缩放因子**（2× 外推就除以 2）。RoPE 只看相对距离，所以“位置÷2”等于“相对距离÷2”——把窗外的 `Δ` 全部拽回训练段 `[0.5, 32]` 再打分：

$$
s_\text{PI}(\Delta) = s\!\Big(\frac{\Delta}{2}\Big)
$$

实验 D 加了这一行后的实测：

```text
位置插值 PI：峰回到 Δ=1（相邻位置依旧最高分）；窗外峰/窗前峰 = 0.14
  → 窗外/'就近'：直接外推 4.6 → PI 0.14，就近优先级保住
```

**4.6 → 0.14**：窗外伪峰从"4 倍强于最近邻"被压到"不到 1/7"，注意力重新聚到该聚的地方。原理一句话——**RoPE 学的是“相对距离→打分”曲线，只对她见过的距离段保真；PI 把窗外距离缩回训练段再打分，曲线形态照旧成立**。

代价（诚实的另一面）：PI 让所有相对距离缩水一半，“就近”的粒度变粗（原本距 1 的语义现在出现在距 2），**高频信息会有损失**——所以社区总是“插值 + 几千步微调”配着用。真正更顺滑的出路是下一节的衍生族。

## 8. 衍生脉络：YaRN / NTK / LongRoPE / M-RoPE

位置插值是“一刀切线性缩放”。它的改进都在调整"缩放不均匀"或"不同频率缩放不同"，`17-长上下文` 会完整展开，这里只需建立坐标：

- **NTK-aware Scaling**（2023 中文改名里的"有点修改频率"派）：不动角度，改 θ 的频率基数 `base`——高频格不动、低频格拉开，尽量保住短程分辨率；
- **YaRN**（2023）：结合 NTK 与位置插值，还修正 ROPE 高频维的“范数膨胀”问题——是 LLaMA 长上下文生态最常用的缩放之一；
- **LongRoPE**（2024）：更精细的逐维"非均匀插值"，挖出插值还能压多少；
- **M-RoPE**（2024，DeepSeek-V2 同源）：把 RoPE 维度拆成 m（图像）/r（行）/c（列）三组，让 2D 图像也能旋转——**多模态那章的挂载点**（×上是长上下文、横上是图像位置）。

> 记忆抓手：**一条曲线 s(Δ) 只对她见过的区间负责——外推像"把谱抄出窗"，PI 像"把坐标折回窗"，NTK/YaRN/LongRoPE 是"折的同时按频率分配误差"。**长上下文公式永远回到"Δ 是否还在见过区间"来验。

## 9. 常见坑

| 坑 | 症状 | 修法 |
|---|---|---|
| 以为 RoPE “自动外推” | 调大 max_len 期望 PPL 不掉 | RoPE 只保证"打分由相对距离决定"，**曲线保真只发生在训练窗口内**（实测 4.6× 失态） |
| 以为长上下文失败是“数值爆炸” | 检查有没有 overflow | 旋转保范、打分有界（`|s|≤|q||k|`）；真正的病是**形态错位** |
| 把位置插值当“零成本” | 插值完不微调 | PI 会损失高频/短程分辨（分辨率减半），一般需配几千步微调；NTK/YaRN 是它的更优口 |
| 把“绝对正弦”和 RoPE 记混 | 以为它们都“只给频率” | 两者都用 θ 频率表，但**绝对正弦是相加式绝对编码**（平移会变打分，实测差 0.3740） |
| 混淆 M-RoPE 与其他缩放 | 以为 M-RoPE 是“再插值一次” | M-RoPE 是**维度分工**（m/r/c），专为 2D 多模态；调长用的是 NTK/YaRN/LongRoPE |
