## 0. 为什么单独一章：规模化是三问，不是一门手艺

`12` 章收尾时说过，预训练唯一的真相是"下一 token 预测"；`18` 章问过"同样算力的模型怎么做得更大"（MoE）。本章再进一步，把**要不要涨规模、涨哪个方向**这件事本身变成一门可测的学问：

- 参数多一倍，loss 掉多少？
- 数据多一倍，loss 掉多少？
- 算力（参数 × 数据）预算固定，预算该放参数还是放数据？
- 以及最要紧的——**数据如果有一天不是"多一倍就能更便宜地拿到"了，会怎样？**

这四个问题在 2020–2022 被 Kaplan 和 Chinchilla 两篇论文彻底改写成了幂律（power law）：在 log-log 坐标里，loss 对参数、对数据都是直线。它们合起来是"规模化经济学"的地基：**要预测未来模型的表现，先量它的标度律；要不撞墙，先知道墙在哪里。**

本章把这两件事都做掉：用 `12` 章同款 1-block 引擎，把 5 个尺寸 × 5 档数据量跑成一个早停网格，量出玩具自己的两条幂律；再做一个对抗实验——**同一段有限语料，循环喂 vs 无限新样本**——把"数据墙"这一 2025–2026 的真实争论，在 8K/16K 语料池、最高 1M token 预算的规模上先撞一次。关键是把墙的位置变成**一个可解析预测、可实测对照的量**（§D 的池地板）。

知识地图给这一章的定位是 🟢 概念，论文只有 Kaplan/Chinchilla 两篇，实践是"画一条自己小模型的 loss vs 数据量曲线"。本章照办，但把"画曲线"升级成"画完曲线之后，还量得出墙的位置"。

## 1. 核心事实：幂律的三个词，和它们的玩具对应物

先把三个词钉死。后面每一个实测数字都挂在它们下面：

**① 幂律（power law）**：loss 与规模的关系在 log-log 坐标里是直线。Kaplan/Chinchilla 的写法：

```text
L(N, D) = E + A/N^α + B/D^β        （Hoffmann 参数化）
  N=参数、D=训练 token 数、E=不可约损失的上界之下的地板
  α, β=幂指数（幂律的"斜率"，越小=该维度越"够用"）
```

**② 等算力预算（compute budget）**：真实训练的成本是"算力 × 用掉的 token"，模型体积与训练数据量的乘积被算力账单绑在一起：预算 C 固定时，`N × D ≈ C`。所以"涨规模"不是单一方向，而是**在一条等算力曲线上选点**——模型大、数据少，还是模型小、数据多。Chinchilla 的核心发现是：给定算力，存在一个"参数/数据最优配比"（约 20 tokens/参数），2020–2022 的豪强（GPT-3、Gopher）全在"参数过于大"的一侧。

**③ 数据墙（data wall）**：幂律假设"数据想要多少有多少"。一旦数据是真有限（自然语言就这么些、版权/隐私/去重后再打折），把已有的数据翻来覆去地喂，loss 就不按 D⁻ᵝ 走了——它**撞到一个由数据本身决定的平台**。2025–2026 年这套争论（自然文本总量估算、合成数据能不能续命、数据许可市场）的全部经济学，就是这一个"墙"字。

玩具对应物（本章实测的全部前提）：

```text
数据      阶 2 马尔可夫源，V=16 符号，转移 Dirichlet(0.2) 高峰态
          平稳分布 π(a,b) 可解析（power iteration）→ 过程熵 H=1.5802 nats（< lnV=2.7726）
模型      1-block 仅解码器（`12` 章同款引擎），概念层 C=32/48/64/96/128
          → 参数 14,336 ~ 204,800
评测      eval loss = 模型对【真实转移分布】的期望条件 CE（分布级、无采样噪声）
          喂 <a,b> 读下一符号 logp，按 π(a,b) 加权 —— 训练/评测同一符号映射
网格      5 尺寸 × 5 数据量（57K/114K/229K/458K/917K token）× early stopping
          （每格 M 步评测一次，保最优 eval 与到达该值的 token 数——抑制过训练反弹）
```

> 一句话（为什么有本章）：**Kaplan 说"loss 沿参数和数据是幂律"，Chinchilla 说"等算力下存在最优配比"——前者让 2020 年的行业敢把模型快速做 100×，后者按住了 2022 年的参数狂热。本章在你自己的电脑上把这两张图各画一遍，顺便画出它们都回避不掉的那堵墙。**

## 2. A 参数量幂律：D 固定，N 翻倍 loss 掉多少

固定数据档 D₀=229K token，五个尺寸各训练一次（early stopping），得到"只动参数"的一条曲线：

```text
C     参数 N        eval CE（L）
32    14,336       2.3936
48    30,720       2.0349
64    53,248       1.9380
96    116,736      1.9072
128   204,800      1.8387
```

log-log 直线拟合（首尾各带实际 token 数偏移，正文用脚本输出的完整精度拟合）：

```text
log L = 1.679 − 0.090 · log N      →    L ∝ N^-0.090   （R² ≈ 0.83，5 个点）
```

两个读法，都重要：

1. **方向对了，但斜率很缓**。参数翻 8 倍（C32→C128，14,336→204,800），loss 只从 2.39 掉到 1.84——每多一份参数买到的 loss 越来越少。而对比 §3 的数据幂律（D⁻⁰·¹⁶⁴，斜率约两倍陡），**在这档数据量下，数据比参数更"能打"**。这是后面 §5 "预算往数据挪"的第一个证据。
2. **N 幂律在数据不足时会提前压平**。C96 在这一档只用了 222K token（early stop 在了 223K 前）就刷不出更低了；C128 的 1.8387 离数据能撑住的极限不远。真实世界的同一现象，就是 Chinchilla 说的"参数过余（over-parameterized）"——**参数再多，数据不够就白搭**。

> 一句话（A 的账）：**同样的 229K token 下，参数翻 8 倍只买来 0.55 个 nats——幂律是真的，但斜率只是 -0.090；玩具的 N 端已经开始进入"数据不够撑参数"的区了。**

## 3. B 数据量幂律：N 固定，D 翻倍 loss 掉多少（实践曲线）

这一节就是知识地图实践项的"**画一条自己小模型的 loss vs 数据量曲线**"。固定 C=96（N=116,736），只动数据量：

```text
D 计划（K token）   D 实际（early stop 后）   eval CE（L）
57                 54                        2.6114
114                115                       2.3444
229                223                       1.9072
458                432                       1.7556
917                917                       1.6984
```

```text
log L = 2.731 − 0.164 · log D      →    L ∝ D^-0.164   （R² ≈ 0.93，5 个点）
```

三个读法：

1. **数据端这条线明显更陡（-0.164 vs -0.090）**。同一预算面前，D 幂律的斜率是 N 的近两倍——在玩具这个量程里，"再多喂点数据"的边际回报比"再加大模型"大。这不是玩具的怪癖，是 Chinchilla 在真实世界观测到的同一个相对关系（§6 参照表）。
2. **曲线逼近 H=1.5802 但始终在它上面**。数据从 54K 涨到 917K（17×），loss 从 2.61 掉到 1.70——离过程熵 1.58 还差 0.12。这条曲线最后一定**弯向 H**（无限数据时 loss 只能停在不可约熵），这正是机制段（§4）的地板。
3. **early stopping 是这条曲线能画成的必要条件**：C=128 在 D=917K 那格如果硬跑完 917K token，eval 反而从 1.70 附近反弹到 1.7123（§2 矩阵里 C128@917K=1.7123 > C96@917K=1.6984）。**训练 loss 继续降、eval 开始升** = 过训练的回吐，scaling 曲线必须用"刷最好的 eval"而不是"跑满预算"来画。

> 一句话（B 的账）：**C=96 不动、数据翻 17 倍，loss 沿一条 D^-0.164 的直线掉了 0.9 个 nats——这就是知识地图要你亲手画的那条曲线，斜率 -0.164、天花板 1.5802，一画就能对照。**

## 4. 机制：为什么是幂律，E 地板是什么

三段推理，把"为什么 log-log 上是直线"从经验规律变成可拆的机制：

**① 幂律的源头是"容量不够 → 残差按容量衰减"。** 对一棵固定结构的网络，多给一倍的参数，等价于给逼近函数多分了一块"形状自由度"。对一阶平滑的目标分布，逼近误差按 ~(自由度)⁻ᵃ 衰减——这就是 N⁻ᵅ 的来历；α 具体多大由架构与任务决定（Transformer 换 CNN、语言换图像，指数会漂）。数据项同理：多一倍的样本，把每个条件分布 P(c|a,b) 估得更准，误差按 D⁻ᵝ 衰减。**两条幂律都来自同一个词：边距（diminishing returns）随维度单调收窄。**

**② 联合拟合把两件事拆开，E 是"地板"。** 把 25 个网格点一起做 Hoffmann 联合拟合（自由 E、五参数）：

```text
L(N,D) = E + A/N^α + B/D^β         （25 格 RMSE=0.097）
  E = 0.6825 · A = 133.74 · α = 0.642 · B = 43.56 · β = 0.288
```

这个拟合里最有信息量的有两处。第一处是 δ 项：**数据过程本身有个可解析计算的熵 H=1.5802 nats**——那就是真 · 不可约损失。25 个网格点里最优的 C96@917K 是 1.6984，比 H 高 0.12：**模型还没够到地板，这正是幂律还有得走的意思。** 第二处是必须照实交代的坑：**拟合 E=0.68 跑到了 H 之下**。量程只有 N 14×/D 17× 时，E 与 α、β 三个参数互相补偿（E 低一点、α/β 小一点，拟合面不变），E 不可辨识——Hoffmann 原论文是在 4000 个跨多个数量级的点上才把 E 钉到合理值的。所以本章把 H 当"地板概念"用，拟合 E 我们只当形状参数，不当"模型够得到的熵"来宣称。

**③ D 幂律必须在 D→∞ 处弯掉。** 公式 L=E+B/D^β 在 D→∞ 时趋于 E——数据这一支最终必被地板挡住。里程问题在于"在哪个 D 弯"：玩具里 D 到 917K 还没弯（因为 Markov 源的统计量很浓），而下方数据墙实验（·D），就是把"弯"这件事**提前人造出来**看它长什么样。

> 一句话（机制）：**幂律 = 逼近误差按容量衰减的边距；E = 数据过程自己熵出的地板（本玩具可解析：1.5802）；而'数据这一支永远不会弯'是幂律最脆的假设——墙，就在下一小节（·D）亲手撞。**

## 5. C 等算力配比与数据墙：同预算，参数还是数据，池子凝固后训练白给

前三节回答了"单独加参数 / 单独加数据各掉多少"。现在把两件事用账单绑起来问：**算力预算固定（参数 × 训练 token ≈ 常数），这一份预算该买参数还是买数据？** 用两条腿答——先从网格里直接挖同样预算档的三胞胎，再上拟合面做数值 argmin。两条腿都不靠任何"常数"假设，跑完会看到玩具自己的答案。

**实测腿：同预算档，把预算从参数挪给数据，loss 全部更小。**

```text
预算≈4.8–5.2×10¹⁰（N·token）：
  (C64, D917K)  L=1.7051  ·（tokens×参数预算 5.00e10）
  (C96, D458K)  L=1.7556  ·（5.16e10）
  (C128, D229K) L=1.8387  ·（4.81e10）
预算≈1.3–1.4×10¹⁰：
  (C32, D917K)  L=1.7402  ·（1.31e10）
  (C96, D114K)  L=2.3444  ·（1.36e10）
```

两档里都是**模型越小 + 数据越多的那一颗，loss 更低**（1.7051 < 1.7556 < 1.8387；1.7402 < 2.3444）。读直白点：在玩具等算力线上，把参数省下来全换成数据，永远更划算。

**拟合腿：argmin L(N, c/N)，最优钉在下界——数据的收益还没吃完。**

```text
预算 c（N·token）      N*（最优参量）      D*（最适 tokens）   D*/N*      位置
1e9                    14,336              69,754              4.9        下界 Nmin
3e9                    14,336             209,262             14.6        下界 Nmin
1e10                   14,336             697,540             48.7        下界 Nmin
3e10                   14,336           2,092,621            146.0        下界 Nmin
1e11                   20,116           4,971,179            247.1        内部
```

拟合面的最优解在预算一路上涨时**一直贴着 N 的最小值**（参数压到极限、预算全喂数据），直到预算冲过 1e11 才开始往"参数大一点"挪。D*/N* 从 4.9 一路暴涨到 247，**它不是 Chinchilla 说的那个常数**——而这恰好是最诚实的结果：

- 玩具的 **D 这一支还没饱和**（§3 数据曲线还在往 H 冲），所以等算力下"数据便宜无限"，配比自然随预算涨；
- Chinchilla 的"约 20 tokens/参数"常数，来自**数据端开始撞墙**的那个真实经济区——预算再涨，数据不再便宜（有限的语料池），于是参数重新变得划算。**"配比是常数"这个命题，本身就预设了数据墙的存在；墙不会出现时，配比奉旨膨胀。**

> 一句话（C 的账）：**等算力预算是个漏斗：在玩具里它把每个子都喂给数据（N* 钉下界、D*/N* 随预算暴涨）；在真实世界它把这道理画到 20 tokens/参数就停——因为真实数据墙，把"数据无限便宜"这条假设戳穿了。**

### D 数据墙：把语料池钉死，越过墙后训练白给

现在把幂律最脆的假设亲手撞掉——**数据是有限的，同一个池子翻来覆去地喂**。构造两个世界，其余完全一样（同 C=96、同预算 k×P0、同 early stopping）：

```text
池世界     固定一段语料池 P0（同一颗 Markov 源采一次，之后再不变）
           训练时从池子里随机滑窗抽样本——同一批 token 反复出现，越到后面重复越多
新样本世界 每次训练都从 Markov 源现采新样本——数据永不重复（§3 的同款逻辑）
对照       k 轮循环：预算 = k×P0；k=4/16/64/128，池子 P0 取 8K/16K 两档
```

**墙的位置不是拍脑袋，可以从池子的统计分辨率直接算出来**：模型把这池子记到极致后，对【真实过程】的期望 CE ＝ `CE(真实转移分布 ‖ 池的经验分布)`——池子只是母体的一次采样，它的经验频率天然带噪声，这个噪声就是墙的高度。玩具把它精确量化成"池地板"（对『真实转移 vs 池经验频率』的期望 CE 直接数值求解，配 Laplace-1 平滑）：

```text
P0    解析墙位（池地板）    距过程熵 H=1.5802    读法
8K    1.809                +0.229              池太小，墙清晰可见
16K   1.709                +0.129              池翻倍，墙约减半
```

实测（C=96，全部 early-stopped eval CE；新样本列两池共用）——P0=8K：

```text
k     预算        池世界 best CE       新样本世界 best CE     池 − 新
4      32K token  2.6873              2.6834               +0.0039
16    128K token  2.3145              2.2715               +0.0430
64    512K token  1.9203（@324K）     1.7377               +0.1826
128  1024K token  1.9171（@567K）     1.6918               +0.2253
```

P0=16K：

```text
k     预算        池世界 best CE       新样本世界 best CE     池 − 新
4      64K token  2.6004              2.5871               +0.0133
16    256K token  1.8732              1.8265               +0.0466
64   1024K token  1.7810（@675K）     1.6918               +0.0892
```

读表四层：

1. **池世界先跟着掉，然后弯向墙、平死**。P0=8K 那列：k=4→16 时池世界还从 2.69 掉到 2.31（模型还在吸收池子里的统计）；到 k=64 掉速骤停，**预算再翻倍到 k=128，best eval 只动 0.003（1.9203→1.9171）——一样的 flops 从头到尾是白给**。墙不在模型这一侧：模型不是不想学了，是 4096 个条件概率已把 8K token 的统计榨干。
2. **新样本世界沿 D 幂律继续降**。同预算下从 2.68 一路到 1.6918（≈§3 网格 C96@917K 的 1.6984），没有墙的形状。两列并排 = 墙的完整定义：**同一台机器、同样的算力，唯一差别是数据从哪来。**
3. **墙的高度 = 池的统计分辨率，可算可测**。两个池实测平台 1.92/1.78，与解析预测 1.809/1.709 只差 ~0.07–0.11（Adam 的软输出让模型记不到 Laplace-1 那种理想的完美程度）；池翻倍，墙高约减半（+0.23→+0.13），就是 Fisher 信息的 1/n̄ 标度。**想拆墙，只有把池子本身做大（新材料），或降低模型的统计胃口（小模型 / MoE / 蒸馏，见 `22`）——在同一池子上加预算没用。**
4. **墙在池子的分辨率配得上模型胃口时，不存在**。同一个玩具把池换成 P0=224K，解析墙位变成 1.590（距 H 只有 +0.010）——落在模型收敛线之下，肉眼不可见（§3 里 C96@917K 都才 1.698）。真实世界 2025–2026 为什么集体撞墙：模型涨到 ≥10⁹ 参数、胃口约 10¹² token，自然文本的统计分辨率（总量 ~数十 T、去重/版权再打折）第一次**配不上**这个胃口。墙不是"数据没了"这种抽象表述，是**"语料池的统计分辨率 vs 模型的统计需求"这个不等式**第一次真正咬人。

> 一句话（D 的账）：**同一台机器，一边（新样本）幂律还在跑、另一边（凝固池子）弯向可解析的墙位后平死——8K 池预算翻倍 best eval 只动 0.003；墙的高度 = 池的统计分辨率，可以解析预估、可以实测对照；越过墙后『更多训练』当场白给，拆墙只能靠新材料或降低胃口。**

## 6. 真实模型参照（非本机实测）

下面是真实模型的幂律参数与数据墙时间的参照表。**运行环境无外网、写作时未能逐项在线复核，精确值以原论文/官方为准**——本章只拿它们做"方向参照"，玩具的数字才是本机可复现的东西：

```text
Kaplan et al. (2020)    参数幂律 N^-0.076 · 数据幂律 D^-0.095 · 算力幂律 C^-0.057
                        结论：且慢涨参数，先涨数据（compute-optimal 曲线）
Chinchilla (Hoffmann 2022)  400 个模型的网格拟合，最优配比 ≈ 20 tokens/参数
                        结论：70B ↔ 1.4T token；Gopher 280B/300B token 是"参数过余"
2023–2026 过训练浪潮    Llama-3-8B ≈ 15T token（≈1875 tok/param）、Qwen2.5-7B 同量级
                        现象本身：数据端壁（token 预算）把"20 常数"推进了 90 倍——
                        参数因推理/显存成本被锁死，数据却越来越便宜（开源语料+合成）
数据墙争论（2025–2026）  自然语言高质量文本估计 ~"数十 T token"量级、且增速放缓；
                        后续主力=合成数据（自训练自蒸馏的续命）、数据许可市场（News/Reddit 协议）、
                        以及本仓库 §17.3.2 前沿线（合成数据 / 预训练后训练 CPT / 蒸馏）
```

三条要带走的方向参照：

1. **玩具意外的窄**：本玩具 N 幂律 -0.090 离 Kaplan 的 -0.076 近得让人安心，但 D 幂律 -0.164 是 Kaplan 数据支（-0.095）的近两倍——玩具处于"数据极饿"区。**方向（先补数据）一致，陡峭程度因量程而异。**
2. **"20 tokens/参数"不是物理常数**：Chinchilla 的 20 是"以当时代价算最优"的点估计；到 2023 年后 1875 tok/param 的 Dreamboat，是"参数被推理成本锁死、数据近乎免费"的经济区换了位置。**配比随经济条件漂移——这就是 §5 拟合腿那个"随预算暴涨"在真实世界的慢动作。**
3. **数据墙不是 2026 才有的**：Chinchilla 论文自己就训练在 4000 亿 token 的语料上、要去重再训练；到 2025–2026，墙从"我们语料库太脏"变成"全球自然文本用没了一半还多"，合成数据成为填墙的第一候选。**本章数据墙小节（·D）的池世界，就是这个争论的最小可控实验。**

## 7. 诚实声明：哪些是玩具量到的，哪些只是方向

按本仓库规矩，把"本机实测"与"方向参照"切干净：

**① 两条幂律与指数的数值——真。** 5×5 早停网格 + 幂律拟合是本机实测、run1==run2 逐位一致（斜率 -0.090 / -0.164、N 扫描 R²≈0.83、D 扫描 R²≈0.93）。但限定词必须带走：**玩具只采了 N 14× / D 17× 的量程，指数是 log-log 上的局部切**；真实模型在百倍量程外量，且 α/β 随架构-数据组合漂移。**形状是"幂律"，指数是"玩具的指数"。**

**② 等算力"预算往数据斜"——机制真、绝对配比假。** 同预算档网格三胞胎（1.7051<1.7556<1.8387）与拟合 argmin 钉下界（D*/N* 4.9→247）都是本机实测；"数据未饱和 → 预算喂数据"的机制通用。但 Chinchilla 的 20 tokens/参数、Llama3 的 1875 tok/param 都是 非本机实测——**把玩具的 D*/N* 拿去跟真实常数比等于拿米尺量纽约**。

**③ Hoffmann 联合拟合——拟合真、E 的物理含义假。** 五参数拟合（E=0.68 / α=0.642 / β=0.288 / RMSE=0.097）是本机实测；但拟合 E 滑到过程熵 H=1.5802 之下，我在 §4 已照实交代——**量程不够时 E 与幂次纠缠不可辨识**，所以本章用 H 当地板概念、不把拟合 E 当"模型够到的熵"。这是"E=不可约损失"这句话最诚实的一种措辞。

**④ 数据墙（池世界平台化）——机制真、墙位可算、绝对高度假。** 池 vs 新样本对照（同预算、同尺寸、只差数据来源）是逐位一致的本机实测，且墙位有解析预测（池地板）并与实测平台只差 ~0.1——这是玩具真量到的。但真实世界的墙在池地板之外还叠着分布漂移、版权/去重、合成回灌；玩具墙的绝对高度（1.92/1.78）是玩具尺度的，真实墙离 H 多远由真实语料的统计分辨率决定——**方向相同、数值不可外推**。

**⑤ 一件玩具测不出、必须留给真实模型的事**：真实模型在足够规模上出现的"涌现行为"（量变到质变的拐点，如思维链/工具使用）与家族差异（不同架构-数据组合的 α/β 不同）——1-block 玩具里只有一条幂律直线，没有突变的可能。§8 放大账会说清楚的边界。

> 一句话（诚实）：**A/B/C/D 各自的数字都是可复现的本机实测，且每一条我都标了它的量程边界与"到哪里就变成方向参照"；凡是"配比常数""涌现拐点"这类横跨多个数量级的论断，玩具一律只给方向、不给数值。**

## 8. 放大账：全仓路线上的三条规模化决策线

把 `18`/`21`/`22` 三篇合成规模化组的完整决策面（与 PLAN §2.2 对齐）：

```text
规模化决策线            问题                    本篇/相邻章的回答
────────────────────────────────────────────────────────────────────────
同样算力做更大      "预算写死，怎么让模型更大？"   18-MoE：激活稀疏，推理成本↔总参数解耦
要不要涨规模        "往上堆参数/数据，值不值？"    21（本章）：先量幂律（N^-α·D^-β），
                     再找配比（§5），再认清墙（·D）
低成本获得能力      "预算有限，怎么抄近路？"       22-蒸馏与CPT：把大模型的能力蒸进小模型、
                     用合成/后训练数据续命——墙的正面解法
```

用本章的账走一遍这三条线（玩具版）：

1. **先量幂律，再决定"要不要涨"**。N 幂律只有 -0.090、D 幂律 -0.164 时，"涨模型"是豪掷；"涨数据"才有肉。真实世界 2022 年 Chinchilla 对 Gopher 的教训，就是这套账第一次公开打脸。
2. **等算力的漏斗把预算倒向数据**。§5 实测腿告诉你：在"数据便宜、参数不便宜"的经济区，任何预算下配比都指向数据侧。唯一让参数重新值钱的时刻，是**数据端撞墙**——也就是数据墙小节（·D）的平线。
3. **墙后面有两条出路**（都是 `22` 章的前沿）：**CPT/合成数据**（·D 池世界里"往池子里塞合成 token"的对应物）、**蒸馏**（把大模型从大池子里学到的稠密表示蒸进小模型，绕过"小模型配小数据"的墙）。三者并起来，规模化组的教学闭环才算关合。

> 一句话（放大）：**本章把"涨规模"从豪言变成工程：先量斜率、再找配比、最后认墙——玩具的斜率/配比/墙是局部量，但这条"先量再涨"的纪律是全仓无条件的。**

## 9. 常见坑

| 坑 | 症状 | 对策 |
|---|---|---|
| **评测 id 映射与训练不一致**（本批次 run1 实地踩过） | 训练符号 s_k→id k（0..15），评测却给 unk=0、符号→id k+1 → eval CE 病态上升（模型越练越自信地错，直到比均匀 2.83 还差） | 训练/评测共用一个映射对象（`VOC=V`、无独立 unk/pad）；写分布级 eval 先自检"喂回去的符号就是训练看见的符号" |
| 用"训练 CE"当 scaling 曲线横轴 | 训练 loss 一路降、eval 早已反弹（C128@917K：跑满预算 L=1.7123 vs 早停保住 1.6984） | 每格 early stopping 盯分布级 eval，保最优 eval 与 token 数；scaling 曲线画 eval 不画 train |
| 用采样级 eval（有限集平均） | 采样噪声淹没幂律斜率（幂律本来只在 log-log 上差 0.05） | 对真实转移分布求期望 CE（分布级、确定性，run1==run2 开箱一致） |
| 把拟合 E 当"模型够到的熵" | E 拟合到 0.68 < 过程熵 H=1.58 | 量程窄时 E 与幂次纠缠、不可辨识；把 H 当地板概念做对照，E 只当形状参数（§4 照实交代） |
| 拿玩具 D*/N* 与真实"20 常数"比 | D*/N* 从 4.9 涨到 247，直接说"玩具违背 Chinchilla" | 常数在数据未饱和区不成立（§5 拟合腿钉下界的机制）——真实常数成立的"数据饱和"假设正是墙；对照只做方向，不做数值 |
| 拟合 D 轴用"计划的 token 数" | early stopping 让每格实际 token ≠ 计划 token（C96@229K 实际 222K），D 轴错位 | 幂律/联合拟合一律用 `best_tok`（早停保留的最优点时刻），计划数只当网格坐标 |
| 不设单线程 BLAS / 固定种子 | 同样脚本跑两次，拟合参数第 4 位浮动，run1≠run2 | os.environ 单线程锁 + 生成器/init/训练各一个固定 RandomState；分布级 eval 无 RNG，天然逐位一致 |
| 只报"新样本世界"不报"池世界" | 数据墙实验失去了对照（没有对照就分不清"涨预算没用"还是"我训练坏了"） | 池 vs 新必须同 C、同 k×P0、同 early stopping；墙的读数永远是一个差值（池−新）而不是单边数字 |
| 池规模选太大、k 选太小 | 池地板距 H 只有 +0.01 时墙肉眼不可见（P0=224K×k≤4 那版就白跑了），看起来"循环训练没问题" | 先用池地板方程估墙位：要让墙可见，池的统计分辨率噪声必须落在模型收敛线上方——本例 P0 缩到 8K/16K、k 拉到 64–128，墙立刻现形 |
| 网格末格大尺寸模型把引擎 C/DH 留在高位，池世界没复位 | §D 第一格 reshape 崩（CANNOT RESHAPE…），因为 C=128 的 DH=32 还在 g.DH 里 | 跨尺寸实验切换大小前显式 `set_c(C0)` 复位引擎的 C/DH/mask；train_pooled 与 train_cell 都依赖它 |

## 11. 衔接下一章：蒸馏与 CPT——墙的正面解法

本章把两条路都铺到了门口：**涨价（参数/数据/算力各一条幂律）与撞墙（数据墙小节·D 的池世界）**。下一章 `22-蒸馏与CPT` 接的正是墙的正面解法——低成本获得能力：

- **蒸馏**：把大模型的稠密表示/偏好（R1 的思考轨迹、Qwen 的教师 logits）蒸进小模型。这是"数据墙"下的偷渡：大模型已经在大池子上把结构吃干抹净，小模型不必再把自己的墙再撞一遍。
- **CPT（continue pre-training）**：在有限新数据（领域语料、合成数据）上继续预训练，让"冻结的池子"重新有一份新水——·D 池世界的"往池子里塞合成 token"的对应物。

往前的水是 `18-MoE`（同样算力做更大的另一半答案）、`20-推理模型`（思考 token 与蒸馏的原料）、`12-预训练`（引擎与 loss 同源）。这一组三篇（18/21/22）合起来，规模化组的"做大 / 决策 / 抄近路"闭环才算真正关合；**墙后的世界，`22` 章门口见。**

> 一句话（下一章预告）：**本章量完斜率、钉完配比、撞完墙——下一章给你墙后逃生的两条隧道（蒸馏把大模型的能力偷渡进小模型、CPT 给凝固的池子换新水）；规模化这条线，终于在"数据见底"处学会了不靠奇迹活。**
