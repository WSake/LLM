> 对应知识点：知识地图 **§17.2.7 FFN 与 SwiGLU**（🟢 掌握）——"每 token 独立的非线性变换与知识存储，占模型 2/3 参数"；前置：Transformer（`01-Transformer`）。这是 MoE（专家网络）的物理载体。

## 0. 谁在干重活：注意力挑货，FFN 消化

阅读一个模型的结构卡，注意力（attention）占了所有眼球：Q/K/V、多头、RoPE……但参数账不是这么说的——**MLP/FFN 才是一个 Transformer 里最大的那块**：

- **参数量**：LLaMA-2-7B 里，注意力投影约占 1/3，**FFN 占约 2/3**；
- **算力分布**：FFN 的矩阵乘在推理时的占比同样高（每层每 token 都对 3~4 张 C×N 大矩阵做乘法）；
- **语义分工**：注意力是"决定谁和谁交互"（路由），FFN 是"把被选中的信息消化成新表示"（处理）。`01-Transformer` 那篇的形状链（token→x→logits）里，中间那步 `x @ Wf1 → 激活 → @ Wf2`，就是 FFN。

> 一句话：**注意力决定"看什么"，FFN 决定"怎么想"。占着 2/3 的模型预算，干的是每 token 独立的基础变换。**

---

## 1. 结构：两片矩阵夹一个激活

FFN（feed-forward network，也叫 MLP 块）的网络结构极其简单，一个 token 的向量 `x ∈ R^C` 走一条直路：

$$
\mathrm{FFN}(x) = \underbrace{\Big(W_2^{\top}\big(\ \sigma(\ W_1^{\top} x\ )\ \big)\Big)}_{(C\to N) \to \text{激活} \to (N\to C)}
$$

- 第一片 `W1`：`(C, N)`，把 `C` 维**升维**到中间维 `N`（经典 `N = 4C`）；
- 激活 `σ`：逐元素非线性（ReLU / GELU / SiLU……）；
- 第二片 `W2`：`(N, C)`，再**降回来**。

它"每 token 独立"——同一层里，位置 `t` 和位置 `t+1` 用**同一套** `W1/W2`，但各自算各自的，互不交换信息。交换信息是 attention 的活。所以 FFN 本质是一张"**输入组合 → 输出组合**"的函数表，表达能力全靠中间维 `N` 够不够大、激活非线性够不够狠。

---

## 2. 参数账：4C 为什么被改成 8/3C

经典 FFN（ReLU 时代）：升 4 倍再降回来，两层矩阵，参数 `2 × C × 4C = 8C²`。

SwiGLU 需要**三张**矩阵（多一张门控投影），如果中间维还保持 `4C`，参数会变成 `3 × C × 4C = 12C²`——贵 50%。论文的解法：**把中间维砍到 `8/3·C`，让总参数刚好回到 `8C²`**：

```text
A1 参数账（hidden C=512）：
  ReLU-FFN   中间维 2048   2×512×2048   =  2,097,152
  SwiGLU     中间维 1365   3×512×1365   =  2,096,640   （预算差 -0.0%）
```

`1,365 ≈ 8/3 × 512`，三张矩阵乘上更窄的中间维——**总预算几乎分毫不差**。这就是你看 Llama 系结构卡时看到的"`intermediate_size` 为什么是 `C × 8/3 附近"的答案：它是为了"加一个门控、预算不变"刻意选的。

> 记忆抓手：**SwiGLU 是"多买一张门控矩阵，用缩窄中间维来买单"**——3 块 8/3C 换 2 块 4C，总参数一回事，能力表述更细。

## 3. 激活一：ReLU，掐死负半轴

ReLU：`σ(x) = max(x, 0)`。特性是**精确掐零**：负输入一律输出 0，梯度也同步归零（`relu'(0)=0`）。

```text
A3 单点映射（x = -4 … 4）：
  ReLU = [0. 0. 0. 0. 0. 1. 2. 3. 4.]      ← 负半轴平板一块
```

代价有两个：

1. **死区**：训练中若大量单元的输入长期为负，这些单元的梯度恒为 0，它们的参数再也不更新——叫 **dying ReLU**；
2. **非光滑拐点**：在 `x=0` 处不可导，优化器（特别是高阶）会被这一个小棱角绊一下。

所以大模型逐渐弃用 ReLU。但"掐零"仍然是个重要的形态特征（第 6 节的指纹实测里它独占一档）。

---

## 4. 激活二：GELU/SiLU，软泄漏

GELU 与 SiLU 是 ReLU 的**光滑替代**，允许一点负向"泄漏"，而不是彻底掐死：

$$
\mathrm{GELU}(x) = x \cdot \Phi(x), \qquad
\mathrm{SiLU}(x) = x \cdot \sigma(x) = \frac{x}{1 + e^{-x}}
$$

实现里 GELU 常写成 tanh 近似（10 行内可读）：

```text
A3：
  GELU = [-0.   -0.   -0.05 -0.16  0.    0.84  1.95  3.    4.  ]
  SiLU = [-0.07 -0.14 -0.24 -0.27  0.    0.73  1.76  2.86  3.93]
```

看 `x=-2`：ReLU 给出 0，GELU 给出 **−0.05**、SiLU 给出 **−0.14**——负输入不再是"一票否决"，而是带着一点信息继续流通。光滑性（处处可导）与软泄漏，正是训练稳定性和表现力的来源。GPT-2 用 GELU、Llama 用 SiLU，都是这个逻辑。

---

## 5. 激活三：SwiGLU，门控相乘

SwiGLU 不只是一个激活函数，它把 FFN 中段改成了**两路并行的乘积**：

$$
\mathrm{SwiGLU}(x) = \underbrace{\sigma(W_g^{\top}x)}_\text{门控} \odot (W_u^{\top}x) \qquad \text{（逐元素相乘）}
$$

第三张投影 `Wg` 产生一个"门控"（0~1 的软开关），去乘以另一路的线性变换结果。`W2` 再接这乘积降维。相比 ReLU 的"硬通断"，门控是"按元素给每条特征一个 0~1 的软权重"——理论上表达能力更强，实践中 Llama/Qwen/DeepSeek 全家都在用。

## 6. 实测 A2/A3：三种激活的形态指纹

`ffn_norm_demo.py` 实验 A2 用同一批输入、同一分布初始化，统计了三种激活中段的形态（`N=2048` 样本）：

```text
A2 形态统计：
  ReLU    近零比例 49.97%      负值比例  0.00%   |h| 均值 0.160
  GELU    近零比例  0.00%      负值比例 49.97%   |h| 均值 0.159
  SwiGLU  近零比例  0.00%      负值比例 50.04%   |h| 均值 0.051
```

- **ReLU 的"近零"刚好等于一半**：输入对半为正/为负，负的那一半被精确掐成 0——这就是死区的形态指纹；
- **GELU"负值比例≈一半"，但没有精确 0**：替代 ReLU 的"非正则化"没有被浪费，而是一个连续小量流过去；
- **SwiGLU 的 |h| 均值 0.051 ≈ 其他两种的 1/3**：门控把中段输出幅度整体压小——"软开关"带来的不是额外死区，而是**幅度压缩**。

再把整条 FFN 的输出比一比（同一输入、RandomState(9) 初始化，`C=512`）：

```text
整条 FFN 输出（mean|y| / std）：
  ReLU-FFN   0.2258 / 0.2831
  GELU-FFN   0.1774 / 0.2225     ≈ ReLU 的 78%
  SwiGLU-FFN 0.0670 / 0.0842     ≈ ReLU 的 30%（幅度小 3.4×）
```

一个很有用的直觉：**广义的 SwiGLU 输出尺度天然更小**，这在堆深网络时帮了"激活别爆"的忙——下一篇（`07-归一化`）会看到，控制尺度恰恰是归一化的核心职责之一，两者是配套的。

## 7. 为什么叫知识存储（和 RAG 的关系）

注意力是"快速查表"，FFN 才是"慢速记忆"——这一点在一年多的研究里被反复验证：模型微调后学到的"事实"，编辑/定位在最有效的是 **FFN 的第二层权重（`W2` 的某几个单元）**。这也是"模型容量=FFN 能塞多少输入组合"的由来。

回到本仓库的主线：`07-检索增强生成-RAG` 里做的"把记忆外挂到库"没有颠覆这个事实——**RAG 是把"记不住"的实体级事实放外部**，FFN 仍然承担"组合、推理、语言形式"这类不能外挂的变换。理解 FFN=知识存储，才能理解"模型召回你训过的组合"与"检索召回文档里的实体"是两种互补的记忆。

## 8. 衍生：MoE 就是把 FFN 切成专家

知识地图把 MoE 标注为 FFN 的**衍生**，原因很直接：MoE 就是"一个路由 + 一堆 FFN 专家"。

$$
\mathrm{MoE}(x) = \sum_{k} \,\mathrm{g}_k(x)\ \mathrm{FFN}_k(x)
$$

路由 `g(x)` 每 token 挑几个专家激活（稀疏），其他专家只是"占着参数但不算"——于是**总参数量可以很大（记忆多），但每次前向算的少（省算力）**。读模型卡时那个"70B 总参数，激活参数 13B"就是在说这件事。FFN 的几个关键性质在这里全部复用：专家=独立的 FFN、中间维=专家的容量、激活=专家内部的非线性。`23-MoE` 会展开，本篇只需立住"专家就是 FFN"这一个坐标。

## 9. 常见坑

| 坑 | 症状 | 修法 |
|---|---|---|
| 以为注意力主导参数量 | 估算模型内存按 Q/K/V 算 | **FFN 占 2/3**（Llama-7B 类结构卡），注意力只约占 1/3 |
| 背死"中间维都是 4C" | 看 Llama 结构卡对不上 | SwiGLU 用 **8/3C**（=Ic 表格里的 `intermediate_size`），为门控腾参数 |
| 把 SwiGLU 当"另一个激活函数" | 以为只换了一行 | SwiGLU 是**三段结构**（Wg·gate × Wu·up 再 W2 降维），参数量变了、形态变了 |
| 以为 ReLU 训练毫无问题 | 深层/大模型 epoch 数下性能差 | dying ReLU 死区；GELU/SiLU 软泄漏在下游更稳 |
| 认为 SwiGLU 输出应该"更大" | 看 |h| 均值 0.051 vs 0.160 很困惑 | 门控=软开关在**压幅度**，输出尺度小 3.4× 是设计特征不是 bug（实测 A2） |
| 把 FFN 与"知识"对立 | 以为知识全在检索里 | FFN 存"组合/推理型"记忆；检索存"实体型"事实（`07-RAG` 关系） |

## 10. 衔接下一章

FFN 铺好了"非线性 + 参数"，但别忘了第 6 节的最后一句话：**幅度控制**。中段 `|h|` 从 0.16 到 0.05、整条 FFN 从 0.28 到 0.08——激活尺度差 3 倍，deep 网络里就会差出训练稳定性。把尺度和分布重新拉回"可见档"的东西，就是归一化：

> **[`07-归一化-LayerNorm-RMSNorm-QKNorm.md`](07-归一化-LayerNorm-RMSNorm-QKNorm.md)**（下一篇）：LayerNorm 强制通道零均值（实测 1e-15 量级）、RMSNorm 省一次均值归约（实测快 ~2×）、以及更热的 8-bit 训练（FP8）为什么把"归一化"当前置条件——归一化立在每个注意力与 FFN 的残差接口上，是"深层能不能稳住"的最后一层保险。

> 一句话带走：**FFN 占模型 2/3 参数，用"升维→激活→降维"把每个 token 独立变换成新表示；激活从 ReLU 的死区（近零 49.97%，实测）到 GELU/SiLU 的软泄漏、再到 SwiGLU 的门控相乘（输出幅度小 3.4×，实测），而参数账始终在 ≈8C²（中间维 4C → 8/3C）；FFN 是知识存储与 MoE 专家的物理载体。**
