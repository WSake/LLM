## 0. 为什么要归一化：deep 网络的两只恶龙

`05-深度学习` 那篇讲过：反向传播是链式法则，网络一深，梯度就是一大堆相乘的积——于是有两个经典的"恶龙"：

1. **梯度爆炸/消失**：一样的相乘累积，多层之后幅值要么上天（overflow → NaN）要么入地（underflow → 0）。经典的 Sigmoid 深层网络一训就僵，就是这个；
2. **内部协变量移位**：每层输入分布随训练漂移，上一层稍微变了，下一层就得重新适应——像在会动的靶子上瞄。

归一化（normalization）的思路很朴素：**在每层入口（或出口）把激活的分布拉回到一个"恒定的基准"上**——不要求比 0 大或小，只要把尺度和中心钉住，后续优化器面对的就是一个"前后一致"的界面。Transformer 里有三处这种操作：注意力里的 softmax（对 logits 归一）、两个残差子层接口上的 LayerNorm/RMSNorm（本文），以及 FP16/FP8 计算前的 scale（`09` 的关系件）。

> 一句话：**归一化干的是"给每一层一个恒定的坐标基准"，让训练既不会因为尺度爆掉，也不必每步都重新摸。它是 deep 训练稳定的地基，不是某个花哨 trick。**

## 1. LayerNorm：公式与逐元素账

对 token 特征向量 `x ∈ R^C`（C=通道/维度），LayerNorm 做两步：

$$
\mathrm{LN}(x) = \frac{x\;-\;\mu}{\sqrt{\mathrm{Var}(x)+\varepsilon}},\qquad
\mu=\frac{1}{C}\sum_i x_i,\ \ \mathrm{Var}(x)=\frac{1}{C}\sum_i (x_i-\mu)^2
$$

- **居中**：减去本向量均值 `μ` → 输出每个维度和为零；
- **缩尺**：除以标准差（+ε 防除零）→ 输出方差 ≈ 1。

它和 BatchNorm 的根本区别在**归一化作用的轴**：BN 对一批样本的"同一维"统计（需要跨 batch 的均值和方差），LN 对**单个样本、单个 token 的全部维**统计（不需要 batch）。Transformer 里 token 长度不定、batch 大小训练中又会被砍，BN 的统计不稳定；LN 是显式设计给**样本内（intra-token）**的归一化，输入一位一位算，天然适配 RNN/Transformer 的"每 token 独立"哲学（上一章 `06` 的 FFN 也是这个哲学）。

```text
逐元素账（一个 C 维向量）：
  求均值 μ ≈ 归约  →  减均值（逐元素）  →  求方差（再归约）  →  开方+除（逐元素）
```

这是 B2（第 4 节）计时实验的前半张账——记住它，RMSNorm 就是从这个步骤里"删一行"。

## 2. RMSNorm：不居中的「半套」

RMSNorm（2021）的观察很尖锐：**LN 逼出来的"零均值"那一刀，对稳定训练真的必要吗？**实验结论是"不必要的"——真正在扛起稳定作用的是那个**均方根缩放**，于是它直接把居中扔掉，只除 RMS（root mean square）：

$$
\mathrm{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{C}\sum_i x_i^{\;2} + \varepsilon}}
$$

差在哪里，一眼看穿：

- LN：输出每维方向被"居中+缩尺"双重修正 → 输出分布**牢牢钉在零均值、单位方差**；
- RMSNorm：**不居中**，只把向量的范数拉回单位尺度 → 输出**保留了均值信息**（实测 B1 里它输出的通道均值≈0.30，LN 被压到 1e-16）。

好处就是省计算：均值归约是一次全维扫描，RMS 那条平方归约省不掉的次数少一次（详细账见第 4 节 B2）。而且因为"只调尺度、不调中心"，它比 LN 多保留了"某通道整体偏正"这类信息，训练评估上论文报告与 LN 持平或更好。

> 当前事实标准：**Llama 全家、Qwen、DeepSeek 用的都是 RMSNorm**——精度不降、算力省、实现更简单，三个理由一起把你往那边推。

## 3. 实测 B1：两者差在哪（0.1 量级）

`ffn_norm_demo.py` 的 B1 用一个**带偏置**的输入（每行均值≈0.24）同时过 LN/RMS，直接量输出差异：

```text
B1 数值差异（输入带偏置, 4096×1024）：
  输入通道均值（前 3 行）≈ [0.24 0.22 0.23]
  LN  输出通道均值 max|·| = 7.63e-17   ← 强制居中, 均值被压到机器精度
  RMS 输出通道均值 max|·| = 0.303      ← 不居中, 均值原样保留
  两者输出 max 差 = 0.442,  mean 差 = 0.1965
```

- **LN 是硬居中**：输入均值 0.24 的向量，LN 输出逐通道再平均，偏差只剩 `7.63e-17`（浮点精度级别的 0）；
- **RMS 留着均值**：同样输入，RMS 输出通道均值还有 `0.303`；
- **两套输出差 0.1 量级**：max 差 0.442、平均差 0.1965——这一"刀"正是"去均值"贵出来的部分。

差 0.1 不小，但它没带来"谁更准"的系统性红利（论文实测持平），所以没必要为了居中付那一次全维归约。**RMS 的价值不是"更准"，是"更省 + 一样稳"。**

## 4. 实测 B2：省一次均值归约（快 ~2×）

B2 在 CPU 上对 8192×2048 的矩阵跑同一份实现、中位数计时：

```text
B2 计算代价（CPU median-of-3, 8192×2048）：
  LN  216.00 ms
  RMS 111.69 ms  → RMS 快 93%
```

速度接近翻倍的来源就一句话：**LN 比 RMSNorm 多一次均值归约 + 一次逐元素减法。**归约（reduce）是内存带宽敏感操作，大数据量下就是那 ~50% 的差距。而且这账是"每层每 token"都在付的——一个 7B 模型 32 层、每层两个子层各一次，几十亿个 token 训练下来，93% 的差距乘以全量训练次元，就是实打实的预算。

> 记忆抓手：**LN = 居中 + 缩尺（两次归约）；RMS = 只缩尺（一次归约）。省掉的那"一刀"正是居中。**这也是"RMS 更稳更省"在数字上的全部来源。

## 5. 反向：norm 也要反传（dnorm）

归一化不是只干前向，它也要把梯度传回去——而这个反向才是实战里最容易写错、最容易把训练搞挂的地方。LN 的精确反向是：

$$
\frac{\partial \mathrm{LN}(x)}{\partial x} = \frac{1}{\sqrt{\mathrm{Var}(x)+\varepsilon}}\Big(dy - \mathrm{mean}(dy) - \frac{x_c\cdot \mathrm{mean}(dy\cdot x_c)}{\mathrm{Var}(x)+\varepsilon}\Big),\qquad x_c = x - \mu
$$

（`code/scripts/ffn_norm_demo.py` 里的 `dnorm()` 就是它。）这个式子为什么长这样：LN 里 `x` 同时出现在减均值、除方差两条路上，反向要把这两路都算上——第二项 `mean(dy)` 是"均值那一路"，第三项是"通过方差的梯度"。

我们给自己的实验定的纪律是**每条反向都必须过中心差分对账**。`dnorm` 对账 maxerr ≈ 3e-10；整个子块（norm + MLP）对账 ≈ 1e-8；多层端到端 ≈ 4e-10。写进这个纪律的原因也在这篇：**B3 里 pre-norm 一看只有两三条曲线值崩了，如果你反向公式本身就错，你会把"规范的 bug"当"实验结论"写进文章。**先自洽，再下结论。

## 6. 位置之争：post vs pre，论文 vs 玩具（B3 训练曲线）

归一化放哪有两种主流构型（常量都是"残差 + 子层函数 f"）：

- **post-LN（2017 原文）**：`h ← LN(h + f(h))`——norm 在**残差求和之后**，两块残差都被钉在单位尺度；
- **pre-LN（2019 起主流）**：`h ← h + f(LN(h))`——norm 在**块首**，残差主干不被 norm 触碰，直接身份累加。

教科书（以及多数论文标题）会说"pre 更稳"。知识地图的实践题恰好是"在 mini 模型上对比 post/pre-norm 训练曲线"——我们就照做了。`ffn_norm_demo.py` B3 的玩具：**同架构同 seed**（hidden 96，depth 4 或 12，数据 std≈1 与真实 embedding 同量级），精确反向，只动 norm 放法和 lr：

```text
B3 梯度尺度（初始化反向, depth=12, 无训练）：
  post-norm  反向逐块 |g_h|  最深 0.025 → 最浅 0.025  → 放大 1.0×
  pre-norm   反向逐块 |g_h|  最深 0.066 → 最浅 0.470  → 放大 7.2×

B3 训练曲线（同架构同 seed, eval-MSE, 每 500 步采点）：
  post-norm depth= 4 lr=0.01   终值  0.0243   | 0:0.29   500:0.041  1000:0.0322  1500:0.0282  2000:0.0258  2499:0.0243
  pre-norm  depth= 4 lr=0.01   终值   NaN     | 0:3.12   500:nan    …
  pre-norm  depth=12 lr=0.01   终值   NaN     | 0:4.67e+05  500:nan  …
  post-norm depth=12 lr=0.01   终值  0.4392   | 0:0.314  500:0.839  1000:0.492   1500:0.514   2000:0.554   2499:0.4392
  pre-norm  depth= 4 lr=0.001  终值  0.0460   | 0:0.594  500:0.0661 1000:0.0565  1500:0.052   2000:0.0485  2499:0.046
  post-norm depth=12 lr=0.001  终值  0.0584   | 0:0.318  500:0.156  1000:0.0927  1500:0.0732  2000:0.0639  2499:0.0584
  pre-norm  depth=12 lr=0.0003 终值  0.0631   | 0:1.03   500:0.0896 1000:0.0748  1500:0.0686  2000:0.0648  2499:0.0631
```

读表，先看**梯度的机制**，这是全部现象的源头：

- **post-norm 主干梯度不积累**：从最深块反到最浅层，|g_h| 一直是 0.025，放大 1.0×——因为"求和后归一"把每块输出scale钉死了，身份路径上的梯度不被放大；
- **pre-norm 主干梯度累积**：同 depth，|g_h| 从 0.066 涨到 0.470，放大 7.2×——norm 缩在线性函数 f 的输入侧，残差主干不加抑制地累加，浅层收到的梯度更大。

于是**同一个 lr 下，pre 的有效步长天然比 post 大 ~7×**。训练曲线把这个机制翻译成了两句话：

1. **lr=0.01 时，pre 直接崩**。depth=4 的第一步 eval 就 3.12（相对基线 0.3 约 10×），步 500 起 NaN；depth=12 更凶，第一步 eval 直接 4.67e5。**不是公式错，是梯度过大推离收敛域**（我们曾两度误判为反向错误，见第 5 节纪律）；
2. **post 在 lr=0.01 能训**：depth=4 稳稳到 0.0243；depth=12 不 NaN 但抖动剧烈（0.439），也算"位置×深度"给了限制。**把 lr 同等缩小后，四条曲线全部收敛，且终值接近**：pre d4 lr=0.001 → 0.0460，post d12 lr=0.001 → 0.0584，pre d12 要更小 lr=0.0003 → 0.0631。

诚实结论：**在我们的玩具里，post 能直接用大 lr，pre 得把 lr 缩 10–30 倍才等价地稳。norm 位置决定的是"优化器的 lr 窗口"，不是非黑即白的好/坏。**这恰好是知识地图实践题想让你亲手看到的东西。

## 7. 工程现状：为什么主流是 pre-LN + 小 lr/预热

那么问题来了：论文和事实标准都是 pre-LN（GPT-2/3、Llama、Qwen……），我们的玩具却告诉 post 更容易训。**为什么不矛盾？**

- **正式训练有 warmup / 小 lr / schedule**：LLM 训练本来就把 lr 压得很小并逐步预热（0 到峰值爬几百上千步）——这恰恰把我们 B3 里"pre 需要更小 lr"的约束变成了训练流程标配，pre 的"梯度偏大"被 warmup 消解掉了；
- **post 的深层代价**：post 在输出侧归一，会把"表示幅度"和"参数更新"耦合在一起，残差主干的绝对尺度被 norm 钉死，深层堆叠时更受限（我们的 depth=12 抖动 0.439 就是它的影子）；
- **pre 的浅层梯度红利**：身份主干不动，深层直接享受"无尖峰"的梯度回传，深堆时更顺。

所以工程真相是：**pre-LN +（小 lr + 预热）是一套搭配**。你问"为什么 LLM 用 pre"，一半答案是它的深堆行为，另一半答案是"它的缺陷早就被 lr 配置治着"。**读到这里你可以把"pre vs post"改造成"lr 窗口 vs 深堆行为"两个可量化的维度**——这就是把一个被玄学包裹的话题变回写论文时能实测的东西。

## 8. 衍生：QK-Norm、DeepNorm

知识地图把 QK-Norm、DeepNorm 标为 LayerNorm/RMSNorm 的**衍生**，方向正好一左一右：

**QK-Norm（往注意力内部伸）**——在 `Q·K^T` 打分之前，对 Q 和 K 各做一次 RMSNorm。作用是**钉死 logit 的尺度**：打分变成"归一化向量之间的余弦式内积"，不再随 head 维度、缩放系数漂移，注意力分布就不会只剩下几个尖峰（尤其是 FP8 训练里，logit 过大会卡量化）。LLaMA-3 及之后的模型几乎都标配。就算你只读 transformer 配置里的 `qk_norm=true`，也该知道它是什么。

**DeepNorm（往残差接口伸）**——给 post-LN 一个"深层续命"：把残差系数放大到 `α≈√(2L)`，同时把层内参数初始化按比例缩小，让 post 构型也能堆几百上千层。它是"post 深不了"的工程补丁，也是今天 ultra-deep 模型文件里"应缩放几个单位"这类系数的出处。

> 一左一右看便容易记：**QK-Norm 修 attention 的尺度，DeepNorm 修残差主干的尺度——两个都是"更早/更彻底地把尺度钉住"。**

## 9. 关系：FP8 训练以「尺度稳定」为前提

知识地图把 FP8 训练标为本知识点的**关系**。FP8 只有 4 个指数尾数位，能表示的动态范围（~256 级）远小于 FP16/BF16——**训练里激活稍微爆几个数量级，FP8 就直接卡精度或溢出**。恰到好处的归一化恰好是它的地基：

- 每层激活经 LN/RMSNorm 回到 ~单位尺度，才是 FP8 能安全表示的范围；
- 训练早期用统计**观测 scale**（如 MS-AMP/DeepSeek 的 per-tensor scaling），本质上就是"实时感知每一层的归一化尺度"；
- MMP（多模型并行，DeepSeek-V3）全局 scale 方案之所以必要，正是因为归一化只保证"相对稳定"，还差一个"全局绝对值"——FP8 逼出来的两件事都在低头把尺度管好。

所以 `04-训练体系`（训练精度 · BF16/FP8）那一章会有个前置依赖：**想省那点显存/算力，先把归一化做对。**这篇文章就是那个前提。

## 10. 常见坑

| 坑 | 症状 | 修法 |
|---|---|---|
| 把 LN 当 BN 用，按 batch 统计 | 长度不同的序列、小 batch 下训练抖动 | LN 是按**单个样本全部通道**统计（Transformer 标配）；BN 不适用这里 |
| 以为 RMSNorm"更弱" | 看到它不居中就怀疑精度 | 实测差 0.1 量级、论文持平；它省的是归约（实测快 ~2×），不是精度 |
| 手动算 LN 反向写错 | pre-norm 训练比 post 崩得离谱，怀疑反向 bug | 每个反向都过中心差分对账（我们 dnorm 3e-10、整块 1e-8）
| 背死"pre 稳、post 差" | 玩具实验对不上 | 位置决定的是**lr 窗口**（玩具：post 直训 0.01，pre 缩 10–30×）；工程上 pre 配小 lr/预热是一套 |
| 把位置争议当玄学 | 答不出"为什么 LLM 用 pre" | 把问题翻译成"norm 主干梯度放大（pre 7.2× vs post 1.0× 实测）→ lr 配置"两个可量化维度 |
| 忽略 FP8 与归一化的耦合 | FP8 训练精度莫名崩 | 先确认每层激活确被钉在单位尺度；QK-Norm + lr warmup 都是配套件 |
| 只记"RMS 更快" | 说不出快哪 | 省的是**均值归约 + 逐元素减**（LN 两次归约 vs RMS 一次）——那是带宽命门 |

## 11. 衔接下一章

归一化、激活、残差——这一路的主题始终是"**让深层的数值待在安全区间**"。但还有一个地方，层的"形状"和模型行为无关、却和预算强相关，它就是模型最前端的人机接口：**分词（Tokenizer）**。

> **`08-Tokenizer（BPE/BBPE）`**（下一章，规划）：文本 ↔ token 的双向映射，决定词表、压缩率与语言适配——BPE 怎么把中文切得更省、词表膨胀如何影响 embedding 显存（一条 700M 的 128k 词表 embedding 就要 ~9GB）。它接在"深层数值稳定"之后，因为**你训练/推理的每一步 token，都是这一个接口定型的**。

> 一句话带走：**LayerNorm 把每个 token 向量"居中 + 缩尺"钉在单位分布（输出通道均值 7.63e-17，实测），RMSNorm 只留缩尺、省一次均值归约（CPU 实测快 93%），成为 Llama 系事实标准；norm 放残差内部还是外部决定优化 lr 窗口——mini 深残差网实测 post 直训 lr=0.01（0.0243）而 pre 一步崩 NaN、缩 lr 10–30 倍后全收敛（0.046/0.058/0.063），机制在梯度放大 1.0× vs 7.2×（实测）——工程上 pre-LN 配小 lr/预热即为此。衍生 QK-Norm/DeepNorm 把「钉尺度」推进到 attention 与残差主干；FP8 训练则把归一化列为硬前置。**
