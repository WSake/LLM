## 0. 为什么单独一章：规模化组的收尾，墙后的两条隧道

`21` 章把数据墙修到了门口：幂律假设"数据想要多少有多少"，一旦语料真是有限的，训练就撞墙停摆。`18` 章回答过"同算力怎么做得更大"（MoE）。本章回答规模化组的最后一问——**算力没变、数据也不多了，还能从哪里捞到能力？**

答案在 `21` 章的门口就铺好了两条隧道，正是本知识点的名字：

- **蒸馏（distillation）**：大模型已经在"巨大数据池子"上把结构吃干抹净，把它学到的分布/文本漏给一个小模型，小模型不必把墙再撞一遍。这是"偷渡"——能力不走参数体积，走监督信息。
- **CPT（continue pre-training）**：在有限的新数据（领域语料、合成数据）上继续预训练。这是"换水"——把 `21` 章 D 节那个凝固的 P₀ 池子，倒进去一份新水。

知识地图给这章的定义是 🟢 概念，论文是 MiniLM + CPT 综述两篇，**关系**一栏写的是"领域模型与端侧模型的两种主流来源"——翻译成决策语言：**你想要一个便宜的端侧模型？走蒸馏。你想要一个某领域（医疗/法律/代码）的专用模型？走 CPT。** 这是 2023–2026 年每一家下游公司真正在做的事。

本章的玩具实验在三块真实量表上各给一个读数：蒸馏的收益什么时候最大（A1/A2）、软硬监督和温度各值多少钱（A3/B）、CPT 遗忘多少、回放能按住多少（C）。

> 一句话（为什么有本章）：**21 章把墙的位置量化了；本章量化墙的两条出路的卖价——蒸馏把"大模型的密度"折成小模型的监督信号，CPT 把"新领域"塞回一个老模型，而它们各自的代价（温度糊平、黑盒丢分、灾难性遗忘）也一起上秤。**

## 1. 核心事实：蒸馏的两条通道、CPT 的回放机制，和玩具对应物

### 1.1 蒸馏：软标签的信息多一点，还是多很多

`13` 章 SFT 的学生监督是一个 **one-hot**：每个位置只告诉你"下一个 token 是 c₀"，其它 15 个候选的答案被抹成 0。Hinton 2015 年的主张是：这个 one-hot 把信息扔掉了——**教师模型输出的 16 维软分布里，藏着"哪些符号在行为上相似"**（真实数据里"猫/狗"的概率远大于"猫/汽车"）。蒸馏让学生去拟合教师软分布：

```text
Hinton 蒸馏损失（KL(t_soft ‖ s_soft)：
  q_t(c) = exp(z_t(c)/τ) / Σ exp(z_t(·)/τ)     教师的预测，温度为 τ 软化成"课程"
  q_s(c) = exp(z_s(c)/τ) / Σ exp(z_s(·)/τ)     学生自己的预测
  L = τ² · Σ_c q_t(c) · log (q_t(c) / q_s(c))   梯度 = (q_s - q_t)/τ
```

温度 τ 是 Hinton 递给学生的高温："先把教师分布糊得松一点，类间相似度更容易渗过来；学完再降回 τ=1"。这条公式 2019 年在 MiniLM/DistilBERT 被验证成工程事实。**本章 A 段要把"软标签到底多值钱"在玩具上量一量。**

### 1.2 黑盒蒸馏：拿不到 logits 怎么办

闭源教师（GPT-5、Claude、DeepSeek 的 API）只吐文本。R1-Distill 就是这么干的：DeepSeek-R1 生成 80 万条带"思考过程"的文本，小模型在文本上硬学。信息口径就小了——**教师嘴里的句子是它分布的一次采样，软分布的完整形状没了**。本章 B 段量化这一步损失。

### 1.3 CPT 与回放：补了知识，就会丢掉知识

在领域数据上继续预训练，领域 eval 会涨；但全量更新权重会让通用能力回退——**灾难性遗忘（catastrophic forgetting）**。公式级的解药是回放（replay）：每步训练数据里掺一部分通用语料（如 9:1），让旧知识被反复"回忆"。**本章 C 段就是 CPT 三臂对照：纯通用续训（什么都不丢的对照）、纯领域（遗忘基线）、领域+通用回放 9:1（解药）。**

### 1.4 玩具对应物

```text
源          两个阶 2 马尔可夫源，V=16：P1=通用（Dirichlet(0.2) 高峰态），
            P2=领域（Dirichlet(0.05) 更尖=领域风格更单调）
            过程熵 H1=1.5802 / H2=0.8098 nats（随机 init≈ln16=2.7726）
模型        1-block 仅解码器（12 章同款引擎），C32→14,336 参数 / C96→116,736 参数
数据流      预训练教师 C96@917K（大预算吃透通用源）→ 学生 C96/C32 各预算 hard CE
            或软监督蒸馏；B 段黑盒=教师自回归生成 114K 文本语料
CPT     基座 C96@229K（eval(P1)=1.8752），各续训 114K：纯 P1 / 纯 P2 / 90%P2+10%P1
评测      eval = 模型对【真实转移分布】的期望条件 CE（分布级、无采样噪声）：
            喂 <a,b> 读下一符号 logp，按 π 加权 —— 训练/评测同一符号映射
预设      "领域"是第二个分布，模型没喂过 → 教师 eval(P2)=4.1027 = 知识的领域边界
```

> 注：本章教师不是凭空多了"知识"，它是"看过更多数据"（917K vs 学生的 57-229K）。所以蒸馏的本质读作：**把"刷更多数据才攒下的分布"漏给一个只配小预算的学生。** 真实世界里教师还有 RL 出来的推理、更大参数攒出的结构，但玩具里信息差就这一个——extra data。这个口径 B 段黑盒的推导直接能用。

## 2. A1 白盒蒸馏·同容量：软标签比硬标签多知道什么

先做最干净的对照：**学生和教师同容量 C96**（容量不是墙，预算才是墙），同一预算下两条监督通道各训一臂：

```text
预算      hard CE（拟合真 token one-hot）   distill τ=1（拟合教师软分布）   蒸馏增益
57K      2.6587                           2.6520                        +0.0067
114K     2.5113                           2.1318                        +0.3794
229K     1.8752                           1.7399                        +0.1353
（教师 C96@917K 的天花板照：eval(P1)=1.6984）
```

三个读数，各讲一件事：

1. **114K 处软标签一手交了 +0.3794 个 nats。** 同一份"预算"，hard 臂到 2.51，distill 臂到 2.13——**教师把 917K 数据压缩成逐位置的 16 维软分布，学生每步看到的监督信息比一个 one-hot 多得多**，这就是 Hinton 实验最直接的数字版。注意预算档在这件事里是关键变量（看下一点）。
2. **57K 处没有增益（+0.0067，两臂都贴地）。** 这不是"小预算没优势"，是"小到还没开始学"：57K 只有约 66 步，而学习率的前 200 步是线性预热，走到 66 步时 lr 才到峰值的 1/3，两臂都趴在起跑线、暂时分辨不出来。**软标签的收益要在"走出预热、开始真正分条件分布"之后才兑现。**
3. **229K 处增益收窄到 +0.1353。** hard 臂自己也跑到了 1.8752，正在逼近教师水平，软监督的相对优势自然缩水。所以增益曲线是 **0.007(没学) → 0.379(能学又不够)→ 0.135(都快会了)** ——**软标签最值钱的是"数据足够用到开始学、又不够自己学全"的中段**，不是简单地"预算越紧越大"。这是玩具量出来、教科书文案里不太会写的一句实话。

> 一句话（A1）：**同容量下，蒸馏能赢不是因为它让模型变大，而是它把"already 刷过更多数据的教师"的分布当课程——收益峰值在预算中段（+0.38），两端都被"还没学/都快会"盖住。**

## 3. A2 白盒蒸馏·参数偷渡：8× 参数墙被收回多少

A1 证明了软监督信息多。但知识的搬运对象是**更小的模型**——这才是"端侧模型"的来源。固定预算 229K，C32（14,336 参数）直接学、或者喝教师软分布，对照它离 C96（116,736 参数）直接学这堵参数墙有多近：

```text
C32  direct  @229K   2.4477
C32  distill @229K   2.0754   （软监督净赚 +0.3723）
C96  direct  @229K   1.8752   （8× 参数的墙）
```

参数墙的跨度是 2.4477→1.8752（0.5725 个 nats）；C32 学生喝了教师软分布，站到 2.0754——**收回了 35% 的距离**。换句话说：8× 的参数差距里，**超过三分之一是可以"买"到的，只要你付得起教师的 logits**。

这一节的真实世界对应太明显了：R1-Distill 把 671B 参数武装成的推理能力蒸馏进 1.5B 的小模型（参数约千分之二），端侧用户在 2025 年用上了参数小三个数量级的模型还保有主模型的多数推理表现。玩具给这组"偷渡"一个量级直觉：**参数缩得越狠，软监督能补回来的比例越大；但墙还是墙，C32 到 C96 的那 0.2 个 nats（1.8752 vs 2.0754）是 8× 参数实打实的容量主权。**

> 一句话（A2）：**参数墙的 35% 可以被教师软监督"偷渡"补回来——端侧模型不是白拿小参数，它拿的是"大教师刷过 917K 数据的浓缩液"。**

## 4. A3 温度：为什么 τ=1 最优（Hinton 处方在无结构符号表失效）

指令是 Hinton 招牌：**蒸馏时把温度调高（τ>1），让教师分布的"类间相似度"渗给学生，学完再降回 τ=1 推理。** 我们的随机符号表有没有"类间相似度"？——**符号之间没有语义层级**，c=3 跟 c=4 在"相似度"上与 c=7 跟 c=11 没有任何不同。学生只会从教师这里拿到"哪个 next 概率高"，而高温摊平的主要是概率的尾差——那是噪声。

实测（C32 学生，预算 114K）：

```text
τ=1   distill eval(P1)=2.5831   （direct 同预算 2.6230）
τ=3   distill eval(P1)=2.6112
τ=5   distill eval(P1)=2.6255
```

**τ=1 最优，τ 越高平滑劣化**：同一个蒸馏训练，唯一的区别是软化程度。这个坏消息指向 Hinton 处方的一个重要前提：**高温值得，当且仅当类别间有真实的"相似结构"可渗（ImageNet 的"猫/狗"、语义相近词表、语法角色的近邻）。随机符号表没有，所以高温只是把监督糊平了。**

> 一句话（A3）：**τ>1 不是蒸馏的默认配置，它的收益前提是"类间结构"；当数据没有结构可渗时（我们的随机符号表），τ=1 就是最优，高温只会把教师给学生的信号糊平。**

## 5. B 黑盒蒸馏：只有教师文本时，丢了什么

闭源 API 只吐文本。B 段把教师 C96 接一个自回归链：**一次 batch forward 抽出教师整张条件分布 M[a,b,c]（喂全部 256 个 <a,b> 读下一符号 logits 软化），再走 M 采样一条 114K token 的"教师课文"**——数学上等价于教师自回归生成，但省掉了 116K 次 forward。学生在这段课文上做 plain hard CE：

```text
学生 C32，预算 114K，只用教师课文（无 logits）：   eval(P1)=2.6655
同预算对照：direct 真文本                     2.6230
           distill τ=1（完整软分布）          2.5831
```

两个排序，一进一出：

1. **白盒 > 真数据 > 黑盒。** 白盒（软分布）最强；更意外的是黑盒比真文本还差（2.6655 > 2.6230）——教师课文是"教师的嘴"，信息是**教师分布的一次采样**：它在尖峰处偏 argmax（比真数据更硬、更少熵），还代代相传了教师的剩余错误。真数据（玩具里的"自然语料"）反而更干净。
2. **黑盒丢了什么？** 丢的是 A1 那个 +0.38 的来源本身——**学生再也看不到"候选符号之间的相对概率"，只看得到教师吐出的那一条轨迹**。R1-Distill 在真实世界"能用"，是因为教师的思考轨迹里藏着单靠瓶颈数据拿不到的新信息（RL 出来的推理过程）——**黑盒的硬伤（丢 soft 分布）被"教师内容本身是新增知识"这一条压了过去，而不是消失了**。玩具里教师没有额外知识，只有"多刷过数据"，所以黑盒的损失原形毕露。

> 一句话（B）：**黑盒蒸馏的上限是"老师嘴里的话"，白盒蒸馏的上限是"老师脑中的分布"——后者每步多给你 16 维相对概率；R1-Distill 能 work 靠的是教师内容新增，不是黑盒没损耗。**

## 6. C CPT：领域续训、灾难性遗忘、回放按住

训练一个 C96 基座在通用 P1 上刷 229K（eval(P1)=1.8752），然后三臂各续训 114K：

```text
臂               训练源                  eval(P1)（通用）       eval(P2)（领域）
基座             刷 P1 229K             1.8752                3.5523
纯通用续训        继续 P1                1.7703                3.8352
纯领域 CPT        只刷 P2                3.8913（崩）          1.0592
领域+回放 9:1     90%P2 + 10%P1         2.6992（被按住）       1.2317
（源头熵：H1=1.5802, H2=0.8098；领域源 P2 为 Dirichlet(0.05)，比 P1 尖；
 基座/纯通用臂的 eval(P2) 由独立探针在同一引擎同一 seed 下实测，端态口径）
```

四条读数，每条一句话：

1. **纯通用续训 1.8752→1.7703**：基座还没到极限（对照 `21` 章数据幂律仍在降），且**什么都不丢**——这是"遗忘"对照臂必须满足的底线：不是续训本身伤通用，是"只喂新领域"伤通用。它还附赠一个诚实发现：**继续贴 P1 并不会顺手帮你领域**（领域 eval(P2) 从基座 3.5523 反而略升到 3.8352）——领域知识是"换分布"换来的，不是"更熟一个分布"顺出来的。
2. **纯领域 CPT：领域 eval(P2) 从基座 3.5523 一路落到 1.0592（学会了，距 H2=0.8098 只差 0.25），但通用 1.8752→3.8913（崩了）。** 灾难性遗忘在玩具里就是这么干净：**把权重照本宣科改写到只认识领域源，通用源判成有序噪声。**（对照：教师把 P1 刷到 917K 时对 P2 的 eval(P2)=4.1027——越贴一个分布、对另一个分布越敢错。）
3. **回放 9:1：领域 1.2317（比纯领域只多付 0.17），通用只退到 2.6992（遗忘少 1.19 个 nats）。** 10% 的通用预算把灾难性遗忘压掉了一大半——**回放每步"重背一遍通用"，权重就每步把旧知识挪回来一点。**
4. **权衡曲线可调：** 把 9:1 改成 5:5，通用更稳但领域更慢；改成 19:1，领域更快但遗忘更深。**"领域涨 vs 通用不忘"就是一根滑块，回放比例定位置**——这正是 `13` 章 SFT 那个"行为 vs 知识"的延续：CPT 决定"懂什么新领域"，回放决定"还记得多少旧世界"。

> 一句话（C）：**CPT 的领域收益（+2 个多 nats）与灾难性遗忘（通用崩 2 个 nats）是同一枚硬币；回放 9:1 用 10% 预算，把遗忘折掉 1.19 个 nats、领域只多付 0.17——这是"换水"的工程配方。**

## 7. 机制小结：蒸馏弯的是学习曲线，CPT 挪的是数据分布

把 A/B/C 三段的机制画成一页：

```text
蒸馏：学生拟合教师的分布（软监督）
      → 每步监督信息 >> 一个 one-hot → 同样的模型/预算，学得更快更深（A1 中段 +0.38）
      → 参数量墙还能被软监督"借力"收回来一部分（A2 的 35%）
      → 但监督质量受两处限制：温度（A3 高温=糊平）、黑盒（B 无 soft 分=漏信息）

CPT：在领域数据+回放上续训
      → 领域 eval 直落（C 纯领域 1.06）
      → 不回放则通用被遗忘（C 纯领域 1.88→3.89）
      → 回放 = 每步混一点旧世界，遗忘折半上秤（C 回放 9:1 后 2.70）
```

一句话水平上：**蒸馏是"能力的搬运"（弯的是同一个分布上的学习曲线，省预算），CPT 是"知识的更新"（挪的是训练数据本身的分布，换领域）；它们互补不互斥——先蒸馏拿到端侧版本，再 CPT 换到领域版本，就是知识地图"领域模型与端侧模型两种主流来源"的完整生产线。**

## 8. 真实模型参照（非本机实测）

本节全部为公开论文/公告数值，**非本机实测，精确值与口径以原文为准**；玩具在 §2–§6 的结论与它们对照使用：

- **DistilBERT（Sanh et al.，EMNLP 2019）**：学生从 BERT-base 的 12 层压到 6 层（参数 -40%，推理 -60%），在 GLUE 上保留教师 97% 的分数。这是"同容量 vs 预算"权衡在真实语言模型上的最著名归档（我们的 A1/A2 给它一个 toy 版本的数量级）。
- **MiniLM（Wang et al.，EMNLP 2019）**：12 层→6 层，加入**深层自注意力蒸馏**（对齐每个头的注意力矩阵、每个层的 value 关系）——比只对最后一层 logits 更强。对应我们 A 段"教师 logits 当课程"的强化版。
- **R1-Distill（DeepSeek，2025）**：拿 DeepSeek-R1（估计 671B 激活）的**思考轨迹文本**（约 80 万条 SFT 样本），文本-only 蒸馏到 Qwen2.5-1.5B、Qwen-32B 等。Qwen2.5-32B 版 AIME 2024 到 72.6%（教师 R1 为 79.8%）、Qwen2.5-1.5B 版到 28.9%——**黑盒蒸馏（B 段的现实境况）在"教师内容=新增推理"时是一个可观的上限**。
- **Llama 3.2 1B/3B（Meta，2024）**：从 Llama-3.1-8B 蒸馏的官方小模型——端侧模型走蒸馏路线的工业标准动作。
- **OpenAI Distillation API / function calling**：把"文本-only 蒸馏"产品化成"教师 logits 给你"的在线 API——白盒蒸馏（A 段）的现实商品形态。
- **Meditron（2023，CPT 医学领域）**：把 LLaMA-2+ 在医学语料上继续预训练（Meditron-70B），是对 CPT 在专用领域的标准案例（C 段的现实版）。CPT 综述口径：**Gupta et al.（2023）"Continual pre-training of large language models"**，系统对比了回放、正则、渐进解冻等防遗忘手段（我们的 C 段玩具给了回放臂一个精确读数）。
- **框架映射**：transformers（`DistilBertForSequenceClassification` → `Trainer` 的 logits 接口）与 LLaMA-Factory 的 `--stage kd` 是白盒蒸馏的工程入口；Textbooks（synthetic，`21` 章的"新水"）→ CPT 是数据/蒸馏之外第三条（合成）通道。

## 9. 诚实声明：哪些是玩具量到的，哪些只是方向

1. **量到的是"相对增益"，不是"绝对水平"**：A1 的 +0.38、A2 的 35%、C 的遗忘 2 个 nats，全都在**同一个 1-block 引擎 + 同一对源**内部对照，方向与相对大小可搬；绝对 eval 值没有真实语言的意义。
2. **A1 没有复现教科书"预算越紧增益越大"的单调曲线**——实测是 57K 贴地/114K 峰值/229K 收窄。诚实读法见 §2 第 2、3 点：**"能开始学又不够学全"的中段最大，两端被启动阶段与收敛阶段盖住**。课本把它讲成单调，玩具捅破了这层光滑。
3. **教师没有"额外知识"**：B 段黑盒之所以比真数据还差，正因为玩具教师只含"多刷过数据"的信息；真实 R1-Distill 的教师另有 RL 推理这种真正新增的信息，所以黑盒在现实仍划算——**差异是真正的"教师新增能力"，不是黑盒是否损耗**。本章把黑盒的原生损失与教师新增拆开讲，避免"黑盒遥遥领先"的复述误读。
4. **τ>1 的失效是"数据无结构"的特例**：随机符号表没有类间语义，所以高温只有糊平；真实词表有（近义词、语法角色），Hinton 高温在真实数据仍大概率有用。§4 的"τ=1 最优"是"该前提不满足时"的证据，不是对 Hinton 的全盘否定。
5. **CPT 的回放增益是"内部源"结果**：领域/通用是同一套符号、同一个引擎、纯增量关系（几乎正交的任务），回放 9:1 恰好压住——真实世界里领域与通用重叠更多（知识型续训往往更好），这里给出的是**一个能被回放这样的简单机制显著改善的坏情形**，工程上仍乐观。
6. 所有实测数在真实语言模型上一般大两个数量级；玩具的意义是**把机制在单机分钟内跑给你看，趋势可搬、绝对值不搬。**

## 10. 放大账：规模化组三条线，与合成数据/LoRA 的位置

规模化组三篇（18/21/22）——**做大 / 决策 / 抄近路**——在 `21` 章门口合拢：

- `18-MoE`：等算力预算下的另一个"做大"答案——**参数总量可以大，单 token 激活小的（稀疏）。**
- `21-Scaling-Law与数据墙`：参数/数据/算力三条幂律 + 等算力配比—预算有限的决策表。
- **本章 `22`**：数据墙的正面解法——**蒸馏（能力偷渡）与 CPT（领域换水），加上黑盒/温度的限制。**

它与下一批（§17.3 训练体系）的接口：**合成数据（§17.3.2）是 CPT 的"新水"上游**（ReST/教科书数据/自生成循环）；**LoRA（§17.3.4）是"低成本微调"的工程化**，与蒸馏/CAPT 并行的另一个"低成本"维度（不动全量权重）。三者合起来，2026 年的主流范式基本齐了：**distill 出端侧版本 → CPT 换到领域版本 → LoRA 在自家数据上低成本精调。**

## 11. 常见坑

1. **对照臂的"什么都不做"最容易写歪**：`cpt_arm` 的纯通用臂原本写的是 `src = P2 if (P_mix is None or ...) else P1`——None 分支恒真，把"纯通用续训"喂成了纯领域数据，出现 eval(P1)=3.82 的荒谬红旗。修复后"纯通用=纯 P1 续训"才成立（1.87→1.77）。**科学上，失败对照（无遗忘臂）错得再漂亮也是失败实验。**
2. **单实例引擎的尺寸错配**：`train_distill` 里教师前向必须 `set_c(teacher_C)`、学生前向再 `set_c(student_C)`——否则引擎停在教师尺寸、用学生的 32 维 head 解教师 96 维 logits，直接蹦出高度错误。**任何跨尺寸实验，改尺寸前全局 reset `set_c`**（`21` 章已记一次，本章再犯一次）。
3. **黑盒语料不要逐 token 自回归 forward**：116K 次 forward 是不可用的墙钟。一次性抽出教师整张条件矩阵 M（一次 batch forward 覆盖全部 256 个 <a,b> 上下文），再走 M 做链式采样的成本是 O(n)，数学上与自回归等价——B 段的 249s 实现全靠这招。
4. **把"容量"和"预算"两个变量一起扰动**：A 段第一版学生用 C32（容量墙先于数据墙），小预算下蒸馏收益完全被容量墙盖住（+0.01），误读了"小预算无效"；拆成 A1（同容量 C96，纯数据/预算变量）与 A2（固定预算，纯容量变量）才各自清晰。
5. **early stop 会把"终点态"藏起来**：CPT 的读数必须用**训练终点 eval**（遗忘是"退回到哪"，不是最优值），与 `21` 章早停曲线的用法要区分开。文中明确标注。

## 12. 实践任务

1. **换领域源再试一次**：把 P2 的 Dirichlet 浓度改成 0.2（与 P1 同尖）或 0.005（更极端），重跑 C 段——看遗忘幅度与回放压缩比如何随之变化。
2. **动回放比例**：把 9:1 改成 5:5 / 19:1，画出"领域 eval(P2) vs 通用 eval(P1)"的权衡曲线（一根滑块）。
3. **换学生容量**：C32 换成 C48/C64，重跑 A2——看"参数墙被收回 %"随容量增大的走向（预期容量越大收回比例越小，因为你自己也在变强）。
4. **温度密扫**：τ=2/4 补点——验证"平滑劣化"还是"某处有个凹谷"。
5. **接 §13 的 SFT 版本**：用 `sft_demo.py` 的问答数据集，改从教师 logits 蒸馏——把"蒸馏 500 条数据训个 0.5B 模型并对比"搬到玩具问答上。
