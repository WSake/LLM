## ✨ 这是什么

你想系统地进入大模型世界，但市面上的教程要么是"收藏夹吃灰"的散装链接，要么是只能看不能跑的旧课程。这个仓库把这两件事一起解决：

| | 这仓库提供 | 解决什么问题 |
|---|---|---|
| 🗺️ **一份知识地图** | 《大模型知识地图_完整版.md》：1977 行、19 章、89 个知识点，每个点都有掌握度标记（🔵了解/🟢掌握/🔴深入） | "我该学什么、学到什么程度、查漏补缺" |
| 📇 **一张对照索引** | [对照索引.md](00-知识地图/对照索引.md) 把 89 个知识点与仓库目录一一映射 | "知识点在哪、写到哪了、你能帮什么忙" |
| 🧪 **能跑的实验** | 87 个纯 stdlib 可复现探针（每篇正文配 1 个）+ 6 个可一键运行 notebook | "看完就手不痒，边学边跑" |
| 🛤️ **双路线规划** | 算法/研究员路线 + 应用/工程路线，从入门到专家 | "下一站往哪走" |

**不是又一份论文清单**，而是告诉你"为什么要出现 → 解决什么问题 → 怎么跑起来 → 怎么看结果"。

## 🚀 Quick Start（三步开始）

1. **先看地图** → [`00-知识地图/大模型知识地图_完整版.md`](00-知识地图/大模型知识地图_完整版.md)，花 1 周通读建立坐标
2. **挑路线** → 打开 [对照索引](00-知识地图/对照索引.md)，按"总览表"逐目录推进；算法线见 [16-01 路线-算法工程师](16-学习路线与里程碑/01-路线-算法工程师.md)（六支知识树 × 四级里程碑 + 十二行寻址表），应用线见 [16-02 路线-应用工程师](16-学习路线与里程碑/02-路线-应用工程师.md)（六支应用树 × 四级项目形态 + 四项目章节清单），双线总览见下方「🗺️ 学习路线总览」
3. **动手指** → 打开 [`code/notebooks/`](code/notebooks/) 里已有的 6 个 notebook 一键运行（Colab 环境，免费可用；`009-中文RAG全管线.ipynb` 是 RAG 检索+评测可复现基线，`010-RAGAS评测一个RAG系统.ipynb` 是 RAGAS 式三层评测，`011-父子分块与元数据过滤.ipynb` 是父子分块与元数据过滤）；零到一打基础，先跑 `code/scripts/python_basics_demo.py`（Python 工程实测，纯 CPU 可跑），再看评估口径 `ml_eval_demo.py`

> 💡 想先查漏补缺？打开 [对照索引](00-知识地图/对照索引.md)，逐条打勾，标出你的空缺——**表里那些 ⬜ 也是本仓库的贡献清单**，欢迎 PR。

```
【路线 A · 算法/研究员】

      → 专深方向（对齐/RL / 训练效率 / 多模态数据）

【路线 B · 应用/工程】
01-基础(轻量) → 06-应用开发 → 07-应用框架 → 08-RAG → 09-Agent
```
