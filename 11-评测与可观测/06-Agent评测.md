## 0. 为什么第 6 课是「Agent 评测」？

11 章三专项已经讲了"人力"（04 篇）、"检索生成"（05 篇）。现在讲三专项之"**Agent**"。09-06 已经从 **Agent 章**讲过了评测台三件套（固定环境 + 可验证终结条件 + 成本指标，里程碑 014）——**本篇是它的续集，换"评测体系设计"的角度**：把 09-06 那台评测台，设计成一套从「这一个任务」到「一整条流水线」都能管住的评测体系。有三个非讲不可的理由：

1. **Agent 的评测对象是轨迹，不是答案。** 非 Agent 系统（RAG、SFT 模型）评测问"**答案/结果对没对**"；Agent 是一次多轮、多工具、可循环的调用过程——**结果对了不代表过程对**。同一个"修改收货地址"任务，两条轨迹都"完成"，但一条 6 回合 420 tok 干净跑完，另一条 9 回合 630 tok 绕了路（1.5× 绕路税）。§9.12 原话"**不评测的 Agent 不可信**"——但如果你只测结局，**等于没评测**。
2. **它有一个自己的关卡：可验证终结条件怎么写。** Agent 循环什么时候算"完成"，比 RAG 判"答案对不对"多一层：**文本里说"已完成"可以是假成功**。§9.12 说"可验证的终结条件"，但没手把手教——本篇把三个具名形态讲清楚（最终状态断言 / 含断言提交 / 轨迹不变量），并给出 010 式判别性证明"词面『完成』是坑"。
3. **11 章铺好的三样方法，在 Agent 场景各有新装法。** 判别性对照（05 账 B 证明评测有耳朵）→ 本页账 B/D 用到终结器与评测集；评委三档 / 混合判分（03+04+05）→ 本页账 C 排成"规则真值 → judge → 人工复核临界"的混合链；回归机制（05 账 C 唯一刹车）→ 本页账 D 装进分级回归台账。**四篇前作 × Agent 这个新对象，就是三专项之 Agent 的全部内容。**

**读完这篇你会：（a）说出"评测对象是轨迹不是答案"的三级粒度（任务结局/步骤推进/回合动作），以及一台评测台三件套怎么装（账 A）；（b）会写可验证终结条件：三形态各抓哪一种坏轨迹，为什么词面『完成』是坑（漏 2/4）（账 B）；（c）把真值 vs judge 排成混合判分链：规则 $0 拦劣质 → judge 规模化 → 人工只复核临界，判准兜底成本可控（账 C）；（d）会建评测集：分级（冒烟/回归/大榜单）+ 坏 Agent 判别对照组 + 回归台账 + 遥测回流（账 D）。（本篇 🔴 会跑——教学主线三专项之 Agent，联动 09-06/09-12；无专属里程碑。）**

## 1. 先把 Agent 评测拆开：轨迹不是答案（三级粒度）+ 一台评测台三件套

§11.5 和 §9.12、§11.9 合起来五句话讲完 Agent 评测的全貌。先拆成一张地图：

| 地图原文（§11.5/§9.12/§11.9） | 拆成什么 | 本篇哪账 |
|---|---|---|
| 指标：成功率、步数、成本、安全性（§11.5） | **成功率的全貌 = 结局（成功率）+ 轨迹（步数/成本/安全）**——分三级粒度量 | 账 A |
| 好的 Agent 评测 = 固定环境 + 可验证终结条件 + 成本指标（§9.12） | **一台评测台三件套怎么装** | 账 A + 账 B |
| 不要用看起来像的 LLM-judge 替代环境真实验证（§9.12） | **终结判据要环境真值；judge 只做判分不掌终结** | 账 B + 账 C |
| §11.9 五条纪律（分级/固定环境/回归/回流/每任务完成指标） | **评测集怎么建、怎么长、怎么跑** | 账 C + 账 D |

**先把『轨迹不是答案』说清——Agent 评测的三级粒度（本页自造的坐标系）：**

| 粒度 | 量什么 | 尺子（§11.5 要素） | 代表陷阱 |
|---|---|---|---|
| **任务结局**（outcome） | "任务做没做成"——做一个"答案"层 | 成功率（pass/fail/转人工） | 绕路也"完成"：结局通过 ≠ 轨迹健康 |
| **步骤推进**（progress） | "每轮推没推进状态"——轨迹质量层 | 步数、回合数、有效推进率、回环数 | 刷工具不推进 / 永远循环不舍得收 |
| **回合动作**（turn actions） | "单轮调的工具对不对、闯没闯祸"——进程健康层 | 成本（token/回合→$）、安全事件（越权/危险） | 每轮都漂亮但绕路能环球（高 token 低产出） |

**§11.5 的四根指标正好各落一层：成功率 = 任务结局；步数 = 步骤推进；成本、安全性 = 回合动作。只看成功率 = 只看了结局那一层**——这正呼应 09-06 账 B 的六指标账本："单看成功率 A 9/10 > B 8/10，但 token 2× + 安全 2"（单指标是视图、六指标才是账本）。**Agent 评测和 RAG 评测的本质差别在这里：RAG 三层都测"答案产物"，Agent 多出来的是"过程本身"这一维。**

**再说一台评测台三件套（§9.12）：**

- **固定环境**：同一任务 = 同一模拟环境（同一 sim + 同一工具集 + 同 prompt 模板 + temperature=0）——不然两次分数的差可能是"换了环境"而不是"换了 Agent"（对应 01 篇环境固定四件套的②③④）。
- **可验证终结条件**：谁说了算"这个任务完成了"。§9.12 红线 = **不用"看起来像"的 LLM-judge 替代环境真实验证**——终结判据必须是**环境真值**（终态断言），账 B 展开。
- **成本指标**：按任务记账不按 token 记账——Agent 多轮，每任务成本 = Σ 回合数 × 每轮 token × 单价（账 C 每任务完成指标的底座）。

**最后预告 §11.9 五项纪律**（账 D 集中落地）：①评测集分级（冒烟 8 / 回归 200 / 大榜单选型）②固定环境（三件套第 1 件）③每次改动跑同一套回归 ④线上遥测回流成评测集 ⑤**用"每任务完成指标"而不是"每 token 质量指标"评价产品**（账 C 末节）。

## 3. 实验 A · 评测对象账：轨迹不是答案——三级粒度 × 三件套（绕路税显形）

账 A 用**同一条客服任务「修改收货地址」的三条轨迹**，把"任务结局不是一切"一次打穿（作者预置仿真，探针第一账）：

| 轨迹 | 回合 | 有效推进 | 回环 | 查错再修正 | 结局 | 任务结局 | 回合推进率 | 每任务成本 |
|---|---|---|---|---|---|---|---|---|
| T1 干净轨迹 | 6 | 6 | 0 | 0 | 完成 | **1.00** | **1.00** | 420 tok |
| T2 绕路轨迹 | 9 | 6 | 1 | 1 | 完成 | **1.00** | 0.67 | 630 tok（**×1.5**） |
| T3 蔓延轨迹 | 12 | 7 | 2 | 0 | 转人工 | 0.00 | 0.58 | 840 tok（×2.0） |

**第一个读数 = 任务结局把 T1/T2 说成一样，轨迹把它俩分开了（结构断言 PASS）：** T1 与 T2 都是"完成"、任务结局都 1.00；但推进率 1.00 → 0.67、成本 420 → 630 tok（×1.5）——**T2 的绕路税只在轨迹层显形。** 任务结局 pass 平均 0.667（T3 转人工拉下的），但**平均分既看不见 T2 绕了路，也看不见 T3 在什么时候开始蔓延**。

**三个分层读点：**

1. **走出结论 ≠ 走得好。** "转人工"（T3）叫停是对的——02 章停止判据三态的**主动转人工**那一态：比硬撑 15 回合"假装完成"健康。**所以任务结局不是越高越好：T3 的 0.00 是正确的 0.00，T2 的 1.00 是侥幸的 1.00。** 评测要能分清这两种。
2. **绕路税按任务记账才看得到。** 单轮 token 全一样（70 tok/轮），逐轮看"质量都很高"；按任务一加总，T2 直接 +50%。**这正是 §11.9 ⑤ 的前半句：Agent 的成本必须按任务计量**（账 C 展开）。
3. **三级粒度就是 §11.5 四指标的坐标。** 成功率落任务结局层、步数落步骤推进层、成本/安全落回合动作层——**想测哪一件事就加哪一层尺子的权重，而不是只看一行平均数。**

**装配断言（三件套 3/3）：**（固定环境）同一任务=同一 sim /（终结检查器）终态断言才算完成——『完成』字面不作数 → 账 B 展开 /（成本计数器）每任务成本 = Σ回合 × 每轮 token × 单价。3/3 全装 = PASS。

**账 A 的总结论（结构断言 + 三件套 3/3）：**

> **评测对象是轨迹，不是答案：同一个任务两条轨迹都『完成』、结局都 1.00，但推进率 1.00 vs 0.67、成本 420 vs 630 tok（×1.5 绕路税）——差别藏在轨迹里不藏在结局里。所以 Agent 评测按三级粒度量：任务结局（成功率）＋ 步骤推进（步数/推进率/回环）＋ 回合动作（成本/安全），一台评测台三件套（固定环境/可验证终结条件/成本计数器）3/3 装齐，才叫『不评测的 Agent 不可信』那句的合格答卷。**

## 4. 实验 B · 终结检查账：可验证终结条件怎么写（三形态 × 判别性对照）

账 A 的三件套里"终结检查器"一句话带过；账 B 把它展开成**本页最实操的一课**——§9.12 说"可验证的终结条件"，到底怎么验？三形态（探针第二账）：

| 形态 | 判据 | 抓到哪条坏轨迹 |
|---|---|---|
| **最终状态断言** | 对目标状态下断言：收货地址==新地址 / 文件已改且 diff 含目标改动 | **假成功**（语言完成 ≠ 状态达成） |
| **含断言提交** | 最后动作必须通过一组校验才算完成（先跑全套测试再落盘，通不过回退=09-05 评测闸/代码版） | **假成功**（外观成功但校验不过，回退） |
| **轨迹不变量** | 回合上限 + 回环上限 + 每轮必须有推进 | **永远不终结**（触顶）· **刷工具不推进**（回环爆表）· **提前放弃**（推进不足） |

**判别性对照（010 同法 · 05 账 B 方法搬到 Agent）：4 条坏轨迹，两种终结器判决——**

| 坏轨迹 | 症状 | 终态断言+不变量终结器 | 词面『完成』终结器 |
|---|---|---|---|
| 永远不终结 | 反复查询状态 10 次、从不改状态 | 未完成 ✓（触顶回合上限） | 未完成 ✓（碰巧没带"完成"字样） |
| 提前放弃 | 首次工具报错即退出 | 未完成 ✓（终态未达成） | 未完成 ✓（没带"完成"字样） |
| 假成功 | 文本说"任务已完成"，但地址没改 | 未完成 ✓（终态断言不过） | **误判 ✗ 判完成**（漏） |
| 刷工具不推进 | 只读工具调 5 次、输出"当前步骤已完成"，状态从未更新 | 未完成 ✓（回环不变量违反） | **误判 ✗ 判完成**（漏） |

**判别性断言 4/4：正确终结器把 4 条坏轨迹全判『未完成』；词面终结器只判 2/4——假成功和刷工具都带着『完成』字样，被它放行了。** 这就是"词面『完成』≠ 终态达成"的 010 式证明：**坏终结器和好终结器的区别不是"评分准不准"，是"终结判据绑没绑环境真值"**（§9.12 红线：不要用"看起来像"的 LLM-judge 替代环境真实验证——词面终结器就是"看起来像"的迷你版）。

**三个读点：**

1. **三形态各抓一种"语言假装完成"。** 假成功 → 终态断言/含断言提交；刷工具 → 回环上限；永远循环 → 回合上限。**一句话版：终结条件 = "目标状态达成了吗 + 过程没绕死吗"，两个问题都答 YES 才算完成。**
2. **词面检查不是一无是处——它是判分器，不是终结器。** 词面匹配"已完成"当**预筛**（成本 $0 毫秒级）完全可以；但当"完成判据"就是坑——**预筛可以漏（放到下一档），终结判据不能漏（漏=坏 Agent 混进发布）**。账 C 的混合链就是这么分工的。
3. **它和 05 账 B 是同一套方法在不同舞台。** RAG 里"答案贴题 ≠ 答案完成"，Agent 里"文本完成 ≠ 状态达成"——**判别性对照（加故意破坏的样例、看指标掉不掉）是给每次评测设计自检张力的标准动作。**

**账 B 的总结论（判别性断言 4/4）：**

> **可验证终结条件和"看起来像"的 LLM-judge 是两回事：三形态（最终状态断言/含断言提交/轨迹不变量）把『完成』绑在环境真值上——4 条坏轨迹全判未完成；而词面『完成』终结器只判 2/4，假成功和刷工具被它放行。终结判据可以贵（环境跑分）、可以慢，但不能漏——漏 = 坏 Agent 混进下半场。词面匹配只配当预筛（$0 毫秒级），不配当终结器。**

## 5. 实验 C · 真值 vs judge 混合链账：判分怎么排 + 每任务完成指标

账 B 说了"终结判据绑环境真值"；账 C 回答下一个问题：**那判分呢？20 条轨迹（真值 12 过 / 8 挂）怎么一次性判完不破产也不漏坏？** 三种方案（探针第三账，judge 判准 0.85 = 09-06 回填只引不重测）：

| 方案 | 判准 | 成本 | 死穴 |
|---|---|---|---|
| 全人工 | 0.97（04 账） | 20 × $1.50 = **$30.00** | 贵 1250× judge（04 账 B），小微批次可，规模化不可 |
| 只 judge | 0.85（09-06：FP 2 放行坏 · FN 1 误杀好） | 20 × $0.0012 = **$0.024** | 便宜，但 **2 条坏轨迹会被放行进生产** |
| **混合链** | **1.00**（人工把残余 FP/FN 兜干净） | $0×4 + $0.0012×16 + $1.50×3 = **$4.52 = 全人工价 15.1%** | — |

**混合链怎么排（三棒接力，各打各的强项）：**

1. **规则终态检查**（$0/条，环境真值）：先行拦下 4 条劣质轨迹（终态断言不过）——账 B 的发明在这里变现：**不花钱、不调模型、还比 judge 硬**。
2. **judge 复判剩余 16 条**（0.85 判准）：规模化判分，$0.0012/条——只要它判准没有系统性偏置（03 账 A 四偏置先查过），残余 FP/FN 剩下很少。
3. **人工复核最不确定的 3 条**（04 账"人工用在刀刃上"）：judge 置信度最低、边界最难判的这几条交给 $1.50/条的人工，**把残余 FP/FN 全部兜住**。

**混合链断言 PASS：判准 1.00（兜干净）· 成本 $4.52 < 全人工 $30.00 的 1/4 = 15.1%。** 读点：**判分不是"全人工 or 全 judge"二选一（05 账 D 评委三档的 Agent 版）——规则真值打头阵、judge 打主力、人工守大门，判准与成本同时拿到。** 这与 09-06 "judge 做预筛、终结判据换不得"同一套分工：**终结判据永远环境真值，judge 永不掌终极裁断。**

**账 C 的第二半 = §11.9 ⑤ 的数字版（每任务完成指标 vs 每 token 质量指标）：**

| Agent | 回合 | 每轮 token | 每任务成本 | 任务完成 | 单轮平均打分 |
|---|---|---|---|---|---|
| X 蔓胖（每步都漂亮但绕路能环球） | 50 | 200 | 10000 tok ≈ **$1.500** | **0/1** | **0.90** |
| Y 精瘦（每步朴素但径直跑完） | 6 | 70 | 420 tok ≈ **$0.063** | **1/1** | 0.80 |

**口径断言 PASS：单轮打分 X 0.90 > Y 0.80（X 胜）· 任务完成 Y 1/1 > X 0/1 且成本 $0.063 < $1.500（×23.8，Y 大胜）。** 读点：**"单轮平均打分"是每 token/每产出指标，X 每步都高质量，但它转圈圈，任务没做成；§11.9 ⑤ 说得很白——评价 Agent 产品要用"每任务完成指标"（完成率、每任务成本、每任务时长），不是"每 token 质量指标"。** 逐轮打分很好看 ≠ 产品好用（呼应 09-06 账 B：A 单看成功率更高，但六指标账本反转）。

**账 C 的总结论（混合链断言 + 口径断言）：**

> **判分要排混合链不排二选一：规则终态检查（真值 $0）拦劣质 → judge 复判主力（$0.0012/条，0.85）→ 人工只复核临界 3 条（$1.50/条）——判准 1.00、成本 $4.52 = 全人工价 15.1%。终结判据永远环境真值，judge 永不掌终裁。评价 Agent 用『每任务完成指标』：X 蔓胖单轮打分 0.90 但 50 轮 $1.500 任务没完成；Y 精瘦单轮 0.80 但 6 轮 $0.063 完成任务——逐轮打分好看 ≠ 产品好用。**

## 6. 实验 D · 评测集分级回归账：分级 + 坏 Agent 对照组 + 回归台账 + 遥测回流

账 A/C 教了"一个任务怎么量、判分怎么装配"；账 D 收尾教"**评测集整体怎么建、怎么证明有耳朵、怎么长**"——把 §11.9 五项纪律一次落地（探针第四账）。

**D1 分级三件套（§11.9 ①，断言 3/3）：**

| 层 | 规模 | 节奏 | 用途 |
|---|---|---|---|
| 冒烟层 | 8 条精选（客服/搜索/代码各几条） | 每日发布前 | 秒级回归，堵住最粗的洞 |
| 回归层 | 200 条业务集（§11.9 ①：100-500） | 每周全量 | 每次改动跑同一套（账 D3） |
| 选型层 | GAIA / τ²-bench / SWE-bench | 换模型/换框架时 | 大榜单做客座评审（09-06 三类基准谱系） |

**D2 坏 Agent 判别对照组（010 同法 · 05 账 B 方法搬到评测集——评测台必须有耳朵）：**

| 评测台 | 好 Agent | 坏四类平均 | 差距 |
|---|---|---|---|
| 只放常规任务（20 条） | 18/20 = **0.90** | 61/80 = **0.76** | **0.14（拉不开 ≈ 评测没张力）** |
| 加 8 条陷阱任务（28 条） | 24/28 = **0.86** | 平均 0.56 | **0.29（判别拉大 2.1×）** |

陷阱任务按四类坏 Agent 的作死姿势设计（无护栏·瞎调工具·重复循环·早放弃）；好 Agent 陷阱盘 6/8=0.75，四类坏 Agent 陷阱盘分别 **0.00 / 0.12 / 0.12 / 0.00**——**判别断言 4/4：四类坏 Agent 都被押到 ≤0.125。** 读点：**无护栏陷阱 0.00 = 越权诱惑全踩（07 章）；瞎调/重复陷阱 0.12 = 顺手就乱调 / 顺手就绕圈；早放弃 0.00 = 一遇错就撤。** 评测台没放陷阱前 0.14 的差距会被"都在及格线"糊过去；**加了陷阱，坏 Agent 掉到台下去了——评测集有没有耳朵，用对照组一测便知**（05 账 B 的技术同构：故意破坏的样例指标必须掉）。

**D3 回归台账（§11.9 ③：每次改动跑同一台评测台·改哪处看哪列）：**

| 版本 | pass（28 条） | 回合推进率 | 回环 | 安全事件 | 改动 |
|---|---|---|---|---|---|
| v1 基线 | 0.86（24/28） | **0.78** | 1 | **2** | — |
| v2 行为引导（每轮先确认要调哪个工具·动作必须推进） | 0.86 | **0.90** | **0** | 2 | **改了行为 → 动了 turn/回环列，安全不动** |
| v3 + 工具白名单（最小权限·挂 09-07） | 0.86 | 0.90 | 0 | **0** | **改了权限 → 只动安全列，turn 保持** |

**回归断言 2/2：v2 只动 turn/回环（安全不动）、v3 只动安全（turn 保持）——改哪处看哪列，pass 结局恒定 0.86 不骗人。** 三个读点：**（1）pass 结局不变 ≠ 没改好——好消息全在轨迹列（turn 0.78→0.90、回环 1→0、安全 2→0），这就是账 A"别只看结局"的回归版；（2）一把旋钮一眼账：行为引导是"行为旋钮"、白名单是"权限旋钮"，台账把两把旋钮的效应分得清清楚楚；（3）v3 白名单安全 2→0 且合法任务 pass 不变 = 07 章"最小权限砍钥匙不砍功能"的数字版。** 这半账直接回答"怎么知道改动是好是坏"——**跑同一台评测台、对比对应列**（05 账 C 唯一刹车在 Agent 场景的落地）。

**D4 遥测回流（§11.9 ④，断言 4/4）：** 线上 不满意 2 + 重试 1 + 纠错 1 = **4 条**回注评测集 → 回归层 200 → 204。读点：**评测集不是建完就死的猫纸——线上每一条"用户不满意/让 Agent 重来/纠正 Agent"都是新训练题，回流进回归层，评测集才跟得上生产**（05 账 C"评测集用生产真实问题"的增量版）。

**账 D 的总结论（分级 3/3 + 判别 4/4 + 回归 2/2 + 回流 4/4）：**

> **评测集是一套会成长的生产设施：分级三件套（冒烟 8 每日 / 回归 200 每周 / 大榜单选型：GAIA/τ²/SWE-bench）控制成本与节奏；坏 Agent 判别对照组（无护栏/瞎调/重复/早放弃四类陷阱盘 ≤0.125）证明评测台有耳朵——没对照组的评测台好差只差 0.14，有对照组拉开 2.1×；回归台账让每次改动都落在对应列（行为引导动 turn/回环、白名单动安全）；线上遥测回流（4 条 → 200→204）让评测集永远追得上生产。**

## 7. 这篇 Agent 评测怎么用（一页带走 + 掌握度检验）

**一页带走：**

- **评测对象是轨迹不是答案**（账 A）：三级粒度＝任务结局 × 步骤推进 × 回合动作。T1/T2 都"完成"、结局都 1.00，但推进率 1.00 vs 0.67、成本 ×1.5 绕路税——**差别藏在轨迹里不藏在结局里**。一台评测台三件套 3/3：固定环境 / 可验证终结条件 / 成本计数器。
- **可验证终结条件三形态**（账 B）：最终状态断言（终态达成才算）· 含断言提交（过校验才算）· 轨迹不变量（回合/回环上限）。**词面『完成』是坑**：终态+不变量判坏轨迹 4/4，词面只 2/4（假成功+刷工具被放行）。
- **判分排混合链**（账 C）：规则真值 $0 拦劣质 → judge 0.85 复判 → 人工只复核临界 3 条——判准 1.00、成本 $4.52 = 全人工价 15.1%。**终结判据永远环境真值，judge 永不掌终裁。**
- **评测集会成长**（账 D）：分级（冒烟 8/回归 200/大榜单选型）· 四类坏 Agent 判别对照组（评测台有耳朵，差距 0.14→0.29）· 回归台账（改哪处看哪列：行为引导动 turn/回环、白名单动安全）· 遥测回流（4 条 → 204）。**评价 Agent 用『每任务完成指标』，不用『每 token 质量指标』（X 蔓胖 $1.500 没完成 vs Y 精瘦 $0.063 完成）。**

**掌握度检验（自问自答）：**

1. "同一条任务两个 Agent 任务结局都 1.00，能说它俩一样好吗？"（答案：不能——轨迹才是真相：比推进率（1.00 vs 0.67）、回环、成本（420 vs 630 tok ×1.5）。账 A。）
2. "Agent 说『已完成』就完了吗？"（答案：不够——终结判据必须绑环境真值：终态断言/含断言提交/轨迹不变量；词面『完成』终结器漏 2/4（假成功+刷工具）。账 B。）
3. "20 条轨迹不想全人工也不想只靠 judge，怎么排？"（答案：混合链——规则终态检查 $0 拦 4 条 → judge 复判 16 条 → 人工复核临界 3 条，$4.52=全人工价 15.1%、判准兜 1.00。账 C。）
4. "怎么证明我的 Agent 评测台有耳朵？"（答案：加坏 Agent 判别对照组——四类坏 Agent（无护栏/瞎调/重复/早放弃）陷阱盘被押到 ≤0.125；没对照组好差只 0.14 拉不开。账 D2。）
5. "单轮打分 X 0.90 比 Y 0.80 高，该选 X？"（答案：不该——用每任务完成指标：X 绕路 50 轮 $1.500 没完成任务，Y 6 轮 $0.063 完成。§11.9 ⑤。账 C。）

## 8. 常见坑（做 Agent 评测的 7 个）

1. **只测任务结局不测轨迹**（§11.5 靶子）：T2 绕路税 ×1.5 在"平均分 0.667"里看不见。**修法**：三级粒度都落数字（结局 + 推进率/回环 + 成本/安全），别一行平均数交差（账 A）。
2. **终结判据用词面『完成』**（§9.12"不要用看起来像的 judge"的迷你版）：假成功、刷工具——语言看着完成了，状态没动。**修法**：三形态绑环境真值（终态断言/含断言提交/轨迹不变量），词面只当预筛不掌终结（账 B）。
3. **评测集没有张力，好差拉不开**（05 账 B 复发）：只有常规任务，坏 Agent 平均 0.76 vs 好 0.90——0.14 的差距被"都在及格线"糊过去。**修法**：加四类坏 Agent 判别对照组（陷阱盘 ≤0.125），拉不开就是没建对照（账 D2）。
4. **judge 裸奔当终结判据**（09-06"judge 做预筛、终结判据换不得"）：judge 判准 0.85 有 FP 2/FN 1，放行坏进生产。**修法**：终结终审永远环境真值/规则/人工，judge 只做规模化预筛（账 B/C）。
5. **用每 token/每轮质量指标评价产品**（§11.9 ⑤）：单轮打分 X 0.90 完胜，但任务没做成。**修法**：每任务完成指标（完成率/每任务成本/每任务时长）当产品主尺（账 C）。
6. **不分级跑评测集**（§11.9 ①的反面）：每天跑全量 200 条烧预算，或每周才跑冒烟错过回退。**修法**：冒烟 8 每日（秒级）· 回归 200 每周 · 大榜单选型时再上（账 D1）。
7. **评测集建完就死**（§11.9 ④的反面）：不回流线上丢样，评测集越来越旧；或回注入的用例没有标注、回流了也没法断言。**修法**：遥测回流——线上 不满意/重试/纠错 各带场景标签倒回回归层（账 D4）。
