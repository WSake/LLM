## 0. 为什么第 0 课是「通用到行业演化链」？

路线 B（应用/工程）走完了：06 应用开发 → 07 应用框架 → 08 RAG → 09 Agent → 11 评测 → 13 工程化。现在手里握着**一套通用的、评测过的、工程化过的能力栈**。第 14 章的题不再是"还能造什么"，而是：

> **把它装进哪个行业？行业自己的资产从这里加。**

这就是为什么它有 8 站：00 演化链（地图）→ 01 医疗 → 02 金融 → 03 代码 → 04 法律 → 05 企业知识库 → 06 行业 Agent 形态 → 07 领域评测与合规（收站）。**每一行业一章，用的是同一个四栏模板**（数据可得性 / 知识表示 / 流程改造 / 合规约束）——因为 14 章的教学法约定就是：**每行业一章，一个"领域资产拆解模板"，并标注会用到 08/09 的哪几章。**

**开篇必须先立两件事：**

1. **一句话公式（§14.0）**：垂直模型 = 通用模型 + 领域资产（数据 / 知识 / 流程 / 合规）。这四个资产才是行业壁垒——模型能力可买，资产余额难造。
2. **一幅演化链（§14.1）**：从通用底座到产品化的七段链，每段"补什么、载体是什么"。所有行业方案都在这条链上选段，不是每条都要走完。

垃圾 vs 垂直化的分界线：报告里写"我们微调了个行业模型"不叫垂直化；只有当你答得出"通用模型缺哪样、哪类资产是行业自己的、哪段演化链该上、哪条红线不能碰"——才叫会做行业大模型。

## 1. 先把垂直化拆开：一句话公式 × 七段演化链（§14.0/§14.1）

### 1.1 核心公式：垂直模型 = 通用模型 + 领域资产

§14.0 给的不是"训练配方"，而是一句资产观：

```
垂直模型 = 通用模型
          + 领域资产① 数据     （难点在治理：脱敏/清洗/FHIR 结构化）
          + 领域资产② 知识     （RAG 语料：指南/台账/私有库/判例）
          + 领域资产③ 流程     （Agent 工作流：检索+调用内部系统+编排）
          + 领域资产④ 合规     （责任边界：不能替代执业判断/不得荐股/引用可溯源）
```

**关键认知**：通用模型（Qwen/Llama/闭源 API）是"可以买/可以下载"的；真正稀缺的、行业通用的根本买不到的，是①②③④这四类**资产**。这也是 14 章每行业一篇的拆法——每篇都回答"这一行业，四栏里哪栏最难"。

### 1.2 七段演化链（§14.1 · 本篇的"图"）

```
通用底座（Qwen/Llama/闭源API）
  → 领域 CPT（领域语料：医学教材/财报/代码库/法条）—— 补知识
  → 领域 SFT（问答对/报告模板/专家改写）—— 补行为
  → 领域 RL（专家打分/可验证标准）—— 补偏好
  → RAG（实时知识：指南/台账/私有库）—— 给实时
  → Agent（检索+调用系统+流程编排）—— 接流程
  → 产品化（权限/审计/人审/评测/合规）—— 收合规
```

读法：**越靠前越贵（训练）、越靠后越工程；不是每步必走，是按需求跳段**（账 C）。

> 关键区别（为什么不是 04 章训练体系 / 08 RAG / 09 Agent 的重复）：**04/08/09 讲的是"每一段的通用机制"；14 章讲的是"挑哪几段装成一个行业方案"。** 04 讲 SFT 怎么做，14 讲"医疗该不该 SFT 还是只上 RAG"。

## 3. 账 A · 造账：七段链怎么画（§14.1 会画架构）

**一句话：先会默写七段链，再谈行业方案——链都没有，选段无从谈起。**

运行结果：
```
A1 七段链 7/7 排序正确（通用底座→产品化）： 通用底座 → 领域CPT → 领域SFT → 领域RL → RAG实时知识 → Agent工作流 → 产品化
A2 三补映射 3/3： 补知识(领域语料) | 补行为(问答对/报告模板/专家改写) | 补偏好(专家打分/可验证标准)
A3 工程双段+产品化五件套 5/5： RAG→实时知识(指南/台账/私有库) · Agent→检索+调用内部系统+流程编排 · 产品化=权限/审计/人审/评测/合规
A4 五需求判型 5/5： 病历语料→CPT · 问答对→SFT · 专家打分→RL · 私有库更新→RAG · 流程→Agent
```

**A1 七段排序 7/7**——把 §14.1 的七段链按"越靠前越重"的顺序钉死：通用底座 → 领域 CPT → 领域 SFT → 领域 RL → RAG 实时知识 → Agent 工作流 → 产品化。**这七段就是一张架构图的中轴线**：任何行业方案都能标在上面某几个位置。

**A2 三补映射 3/3**——训练三段各补一样东西，载体不同：

| 段 | 补什么 | 载体 |
|---|---|---|
| CPT | 补知识 | 领域语料：医学教材/财报/代码库/法条 |
| SFT | 补行为 | 问答对/报告模板/专家改写 |
| RL | 补偏好 | 专家打分/可验证标准 |

> 教学点：**CPT 补"知道"（术语、常识），SFT 补"会做"（输出格式、流程动作），RL 补"取向"（该给专家看的 vs 给用户看的）**——三段不是都要，是缺哪样补哪样。

**A3 工程双段 + 产品化五件套** ——RAG 补"知识的新鲜度"（指南/台账/私有库，见 08-RAG 全家）、Agent 补"动作的自动化"（检索+调内部系统+编排，见 09-Agent 全家）；收尾的**产品化五件套 = 权限/审计/人审/评测/合规**，是任何行业大模型"能上生产"的闸（与 13-06 注册中心 7 件套、13-09 高可用最后防线同源）。

**A4 判型 5/5（先判型再动手）** ——给一个需求描述，判断它主要落在哪一段：病历术语密度高→CPT；标注问答对/报告模板齐→SFT；可验证标准→RL；私有库持续更新→RAG；要调内部系统/流程编排→Agent。**这是"会画架构"的实操动作：先看症状落到哪一段。**

**B2 四行业难度表**（每栏 1-3，越大越稀缺）：

| 行业 | 数据 | 知识 | 流程 | 合规 | 总分 |
|---|---|---|---|---|---|

- 领域 SFT 行为 → **04-06 全参 / PEFT**

## 5. 账 C · 选择账：该不该为行业重训（跳步决策 + 成本档）

**一句话：七段链不是都要走完——能工程先工程、能 SFT 不 CPT；引用校验是工程，不是重训。**

运行结果：
```
C1 五行业需求→方案组合 5/5： 医院助手→CPT/SFT/合规 · 客服答疑→RAG · 信贷审核→SFT · 法律检索→RAG · 代码助手→工程/合规
C2 三档成本级： 纯工程×1 · 领域SFT×10 · 领域CPT×100 —— 能工程先工程，能SFT不CPT
C3 五需求成本档 5/5： 医院助手→CPT级×100 · 客服答疑/法律检索/代码助手→工程级×1 · 信贷审核→SFT级×10
```

**C1 五需求→方案组合 5/5**——同一"造 RAG 还是训模型"问题的五种答案：

| 需求 | 方案 | 为什么 |
|---|---|---|
| 医院助手（病历术语·报告模板·禁止替代诊断） | **CPT + SFT + 合规** | 术语密度高要 CPT 补知识；报告要 SFT 补行为；诊断红线要合规盯 |
| 客服答疑（产品手册实时更新·FAQ） | **RAG** | 手册天天变，训进权重里第二天就过期——RAG 才是对的 |
| 信贷审核（报表结构化·反洗钱留痕） | **SFT** | 主要是输出格式/行为对齐，不需要新知识 |
| 法律检索（法条更新·判例可溯源） | **RAG** | 引用可溯源是检索的活儿，不是重训的活儿 |
| 代码助手（模型已强·仓库索引+CI） | **工程 + 合规** | §14.4：不重训，重工具链与审查 |

**教学点**：**最贵的不总是最对**——医院助手因为"术语密集+专业报告"才够格 CPT；客服/法律/代码都不该为"知识更新/引用溯源/工具对接"去重训。

**C2 三档成本级**（教学层数量级，真实取决于算力与语料量）：纯工程 ×1 · 领域 SFT ×10 · 领域 CPT ×100。**记住一张梯子：能工程先工程、能 SFT 不 CPT**——这直接对抗"行业大模型 = 必须重训"的直觉。

**C3 五需求成本档 5/5**：医院助手 CPT 级 ×100（十万元级）、信贷审核 SFT 级 ×10、客服/法律/代码全部工程级 ×1。**法律检索的结论最有教学价值：只知道"判例更新快"，以为要重训——真相是引用校验（GraphRAG）是工程，一条训练代码都不用写。**

## 6. 账 D · 合规与评测账：红线 + 评测四件套（§14.8 点到）

**一句话：行业大模型先守住的不是效果，是红线；评测集本身就是商业资产。**

运行结果：
```
D1 领域评测集四件套 4/4： 通用基准/领域真题/专家盲评/安全用例
D2 合规五动作 5/5： 数据来源合法/脱敏/模型备案·审计/输出留痕/人审+风险评估
D3 危险动作→红线拦截 4/4： 医疗→不能替代执业判断 · 金融→不得主动荐股·数值不许编 · 法律→引用必须可溯源 · 代码→变更过测试+安全审查
```

**D1 领域评测四件套 4/4**——§14.8：通用基准 + 领域真题 + 专家盲评 + 安全用例。**"领域评测集本身就是商业资产"**：谁攒出了高质量领域真题，谁就掌握了定义"好用"的尺子（挂 11-01 评测三层定位：领域题 = 任务层尺子）。

**D2 合规五动作 5/5**——数据来源合法 / 脱敏 / 模型备案·审计 / 输出留痕 / 人审+风险评估。这就是 14 章每行业都要做的"合规约束栏"的清单版。

**D3 危险动作→红线拦截 4/4**——探针用确定性函数把四个行业的"危险动作"拦进红线：

| 行业 | 危险动作（探针注入） | 红线 |
|---|---|---|
| 医疗 | 模型直接输出确定性诊断结论 | **不能替代执业判断 → 强制升人工确认**（§14.2 辅助+人工确认） |
| 金融 | 给用户荐股说这只会涨 | **不得主动荐股 → RAG+校验+落库留痕**（§14.3 数值不许编） |
| 法律 | 引用判例但追踪不到原文依据 | **引用必须可溯源 → GraphRAG+引用校验**（§14.5 判例/法规引用可溯源） |
| 代码 | 跳过 CI 直接合并代码 | **变更过测试+安全审查 → CI+审查门禁**（§14.4 安全审查） |

**教学点**：拦截 ≠ 绝人工审核——医疗的"辅助+人工确认"、金融的"留痕"、法律的"可溯源"都是**升人工而不是拒绝人**；红线是把"模型自己拍板"变成"模型提建议、人来拍板"。

## 7. 这篇行业演化链怎么用（一页带走 + 掌握度检验）

**一页带走：垂直化 = 造链（A）→ 盘资产（B）→ 选段（C）→ 钉红线（D）。**

```
先画链：通用底座 → CPT(补知识) → SFT(补行为) → RL(补偏好) → RAG(给实时) → Agent(接流程) → 产品化(收合规)
再盘资产：四栏模板（数据/知识/流程/合规）× 目标行业 —— 哪栏最高就是主战场
然后选段：能工程先工程(×1) · 能SFT不CPT(×10) · 真缺知识才 CPT(×100)
最后钉线：评测四件套 + 合规五动作 + 行业红线（不能替代执业/不得荐股/引用可溯源/过了测试再上）
```

**掌握度检验（不看代码，答得出才是真会）：**

1. 一句话说出垂直模型公式？（答：垂直模型 = 通用模型 + 领域资产（数据/知识/流程/合规））
2. 默写七段演化链，并说出每段补什么？（答：CPT 补知识 · SFT 补行为 · RL 补偏好 · RAG 给实时 · Agent 接流程 · 产品化收合规）
3. 四类领域资产是什么？为什么比模型难？（答：数据（治理难）/知识（RAG 语料）/流程（Agent 工作流）/合规（责任边界）；模型可买资产难造）
4. 用四栏模板拆一个行业，指出最难资产（医疗→数据？法律→知识？代码→流程？）——这就是 14 章每篇的训练方式
5. 客服答疑为什么不该重训？（答：手册天天更新，训进权重第二天过期；RAG 才是对的）
6. 法律检索为什么不重训？（答：引用可溯源是检索/GraphRAG 的工程，不是重训）
7. 推倒重来：一个"要重训"的需求，什么条件下才够格 CPT？（答：领域术语密度高、知识不会快速过期、有高质量语料——否则 SFT 或 RAG 更便宜）

## 8. 常见坑（行业垂直化的 7 个）

1. **把"垂直化"当"微调"**——微调只是七段链的一段；行业壁垒在资产四栏，不在参数量。
2. **不做判型就重训**——"先 SFT 一把再说"是没有 A4 判型；先看症状落到哪一段。
3. **知识频繁更新却去 CPT**——手册/判例/台账天天变，训进权重 = 两天过期（客服/法律该走 RAG）。
4. **以为最贵最对**——医院助手 CPT 是三条件（术语密度+报告格式+知识稳定）齐了才够格；否则 SFT/RAG。
5. **资产四栏只看数据**——代码行业数据栏只有 1，主战场在流程（3）；看错栏 = 全盘做错。
6. **红线当装饰**——医疗"辅助+人工确认"不是文案，是升人审的强制流程（D3 四条都是强约束）。
7. **只堆评测分不攒领域题**——领域真题是商业资产；拿通用基准当行业验收 = 尺子不对。
